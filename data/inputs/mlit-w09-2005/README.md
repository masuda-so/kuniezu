# 既存比較湖の公式原本

国土交通省「国土数値情報 湖沼データ W09-05_GML.zip」を2026-11-07に通常HTTPSで取得し、改変せず保持した。8,082,201 bytes、SHAは `e5d0f1bc77427c8c44a855ff361d3b9d94b76fe3c5e31a423ab9abc570950787`。原本は556レコード。HTML本文やメニューは保存しない。

[個別ページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-W09-2005.html)の使用許諾リンクは[旧国土情報利用約款準拠版](https://nlftp.mlit.go.jp/ksj/other/agreement_02.html)を指定する。商用可の区分と、出典・加工者表示、原典由来の空間/時間誤差、目的への適合性、権利の所在等の継承条件を保持する。一般ページのPDL1.0だけをこのデータの条件としない。配布する比較データにも出典URL・加工表示・規約URL・適用限界を含める。原典の誤差や2005年という時期を無視して測量・航法・戦国期の実測岸線として扱わない。

座標系はメタデータXMLの `JGD2000 / (B,L)`。SHPはlongitude/latitude、DBFはcp932。ZIPにはPRJ・CPGがない。JGD2000地理座標としてEPSG:4612へ対応させ、PyProj 3.8.0/PROJ 9.8.1の標準操作でOGC:CRS84へ移行した。経度先行、ballpark禁止、ネットワーク無効。選ばれた操作の公称精度1mは座標変換の値であり、地形や史実の位置精度ではない。

原本の同一性はZIPのSHAとレコード番号の組で保持する。これらの範囲は既存 `lake-baselines.js` の小数6桁座標とも全て一致した。独立担当は5湖とも原本と編集正本の形状一致を確認した。CODHの合成参照陸では5湖の面積のほぼ全てが陸となるため、移行で既存湖を消さないための補完である。

編集正本は `kuniezu/map/physical/water.geojson` 内の同じ5 ID。初回の独立ファイル `lakes-reference.geojson` は重複を避けて統合し、[移行記録](../vector-map-migration/README.md)に旧Git版とSHAを残した。初回の原本照合と、以後の直接編集は区別する。通常の配信は正本のバイト複写だけで、ここにある原本から編集正本を再生成しない。
