# 街道の編集GeoJSONへの初回移行

2026-11-08。編集正本は `kuniezu/map/physical/roads-reference.geojson`。現行実装で採用していた85路線・136,778頂点を事前に固定した。地物IDは対象カタログと同じ道路名由来の安定ID、座標は `[経度, 緯度]`（OGC:CRS84）である。

この移行で道路の史実確認の格付けは上げない。分類は近現代比較80路線、混合比較2路線、既存折線3路線。いずれも個々の史料精度を保持する。日本の戦略地図用74路線と、海外の歴史文脈・合戦図用11路線を同じ正本の`strategyScope`で区別する。朝鮮半島の戦略地図を再開する変更ではない。

## 保持する入力と再現

- `legacy-comparison-lines.json`：旧mainの全モジュール適用後、旧表示補正前の比較入力84件。伊那街道の追加と西海道の整理を含む。未採用の寄り道も残し、配信入力へ戻さない。元のOSRM応答そのものと呼ばない。
- `migration-report.json`：旧版`9baa7286`、全読込モジュール等のSHA、投影規約、各路線の頂点数と地理座標SHA、経路網と代表経路の比較値。小数桁は技術的な往復保持であり史料精度ではない。
- 元の取得物・採否・地図・制御点：既存の`data/inputs/*-road-review/`等を保持する。現代比較線の利用条件をCODHや戦国期の測量結果へ読み替えない。

`tools/geo/prepare-road-vectors.cjs --legacy-root <9baa7286版の別checkout> --output <新しい出力ディレクトリ>`で初回移行を再現できる。出力先は新規ディレクトリに限り、既存の編集正本や出力を上書きしない。通常ビルドはこの準備器や旧比較JSONを呼ばず、編集済みGeoJSONをバイト複写する。

今後はGeoJSONを直接編集し、変更の出典・区間・適用年代を添えて確認する。旧コードと新しい補正を二重適用しない。旧JS形式を書き戻す10生成器は退役し、旧版のGit履歴から参照できる。存続する伊那街道生成器は資料・粗い経由地・戦役回廊だけを生成する。

## 帰属と採用範囲

地物の`geometrySources`は書誌台帳の出典IDに対応する。OSM由来の比較データは © OpenStreetMap contributors、[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)（[公式表示](https://www.openstreetmap.org/copyright)）。国土地理院道路中心線、文化庁選定地図などの加工部分は元の個別条件を保持する。配信側の案内は`kuniezu/static/kuniezu/licenses/DATA_SOURCES.md`を参照する。

江戸・近現代の形状は戦国期の全線を確定する資料ではない。東山道・吉蘇路・中山道の時代差、城へのアクセスと本線の関係、CODHの各街道との区間比較は別の史料審査である。
