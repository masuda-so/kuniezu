# 清洲会議後の旧保存fixture

`legacy-saves.json.gz` は旧実装で作成した1582年7月16・17・18日の
歴史観察保存。ユーザーの個人保存ではなく、回帰検査用に生成した状態です。
生成元commitと元JSONのSHAは展開後のメタデータに保持します。

16・17日は旧生成前、18日は旧実装が三法師を安土の管理ノードへ置いた状態。
現在の人物生成欠落の補完、預かり表示、期限後の未知所在、明示再配置を確認します。
未知の年を補間した行軍や史料の精密な到着日を、このfixtureから生成しません。

圧縮元3保存は同時代の史料ではなく、旧ソフトウェアの動作を再現する検査入力です。
