# 沿岸5地域の原本保持

retention-manifest.json は原本の取得URL、元バイトSHA、論理archiveKeyを記す。原本15件をGit外の私有アーカイブへコピーし、元バイトのSHA-256とサイズを照合した。

コピー先は利用者ごとのアーカイブ根配下にある `archiveRelativePath` で解決する。利用者固有の絶対パス、原HTML、PDF、読図画像をGitへ入れない。再配布許諾は未確認。再取得したファイルのSHAが変われば新しい取得版として再照合する。

輪郭の座標入力は0件。100m正本や既存300標本の照合結果は史料命題ではないため、ここへ混在させない。
