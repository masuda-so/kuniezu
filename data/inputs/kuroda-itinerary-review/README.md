# 黒田長政の1600年東征・西上の原文確認

貝原益軒『黒田家譜』巻9・10を収める『益軒全集』巻5（益軒全集刊行部、1911年）。国立国会図書館公開、DOI [10.11501/1023982](https://doi.org/10.11501/1023982)。NDL IIIF目録の著作権表示はPDM。確認日：2026-11-03。

検索結果の要約から確定せず、該当する原画像を読んだ。ここには必要な6コマのみを保存し、取得URL・SHAは artifacts.json に保持する。二次サイトのHTML全文は保存していない。

6/16は家康の大坂出発、7/5は長政の伏見出発で、同じ地点・同じ主体の出発日ではない。家康の随行者名簿を、長政が家康と同じ日程で全行程を移動した証明へ広げない。大坂→伏見を経て長政だけ遅く東下した説明とは両立するが、6/16–7/5の長政の連続滞在を確定したわけではない。

補助史料は[神戸大学・黒田孝高書状（1600年旧暦8/13）](https://da.lib.kobe-u.ac.jp/da/sc/0100399196/)。所蔵機関の解題は長政・福島正則の清洲接近を伝える書状と説明する。これは中津で受け取った伝聞・到着予告で、8/13の清洲への到着済み記録ではない。画像の二次利用申請が必要とされるため、この書状の原画像は転載していない。

『黒田如水伝』の「6/16に長政が家康に従って大坂発」という検索抜粋は、原頁を今回確認していない。個別の7/5伏見発を消す証拠に採用しない。『黒田家譜』自体も同時代日記ではなく後世の家譜である。原文確認と史実の精密確定を分ける。

今回の所在表示接続では、p.279の宇都宮→小山の順序だけを無日付の経由記録として用いる。p.282の厚木からの再召還には小山／江戸の異説があり、両者を一つの必経由行程へ結合しない。コマ136の原画像を追加保持し、精密な通過経路・通過日を新たな史実観測として作成しない。
