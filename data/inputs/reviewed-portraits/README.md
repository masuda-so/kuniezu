# 表示へ追加する3人の肖像原本

2026-11-09取得。原本は無改変で保持し、URL・SHA・切出し位置・採用理由の正本は `tools/faces/reviewed-portraits.json`。配信する128px画像は `tools/faces/build_reviewed.py` で生成する。元画像の全身・画賛を顔の大きさに数えず、縦横比と傷み・色を保持した。

|伊東義祐|925×1215 PNG|『堺市史 第七巻』所載の肖像写真|
|高橋紹運|1000×1528 JPEG|柳川市天叟寺所蔵の像|

各Commons資料ページはmanifestの `source`。配布元は歴史的作品の忠実な複製としてPD-Art/PDM等を掲げる。米国タグの補足要求も元ページにあるため、表示を省略して「全ての国で条件を確認済み」とはしない。投稿・撮影の年月を絵の制作年月と読み替えない。作品や所蔵館の権利表記と、写真配布元の利用表示を区別する。

伊東像については、[堺市立図書館『ゆづりは』27号2頁](https://www.lib-sakai.jp/yuduriha/yuduriha27screen.pdf)が原画の焼失と写真の保存を説明する。[市史本文39〜41頁](https://adeac.jp/sakai-lib/texthtml/d100070/mp010000-100070/ht000300)も参照し、寺伝の自画像という説明を顔貌の確定としない。[NDLの原刊書誌](https://ndlsearch.ndl.go.jp/books/R100000039-I1049496)は1930年刊・インターネット公開・PDM表示を確認した。後年の復刻版書誌と混ぜない。

龍造寺像は原画の画賛の政家名を確認した。年記は貞享二年乙丑六月一日と読図したが、画賛の日付を絵の制作日や本人の没日へ転用しない。佐賀県立博物館の別作品「隆信・政家・高房像」をこの1人像と同じ作品だと断定していない。

高橋像の所蔵と人物名は配布元の説明に基づく。宗茂像・道雪像を代わりに使わず、原本の欠損した顔の線を生成して補っていない。3人の像は人物典拠や生前の顔の確定命題とは別の表示素材として扱う。

取得時に龍造寺像だけ429応答があり、約7分後に1回再確認して取得。追加の自動反復・別経路での回避はしていない。
