# 上月・有岡・安濃津の布陣照合

確認日：2026-11-03。日付は旧暦。各場面の 0〜100 は出来事の再生位置で、日内時刻や等間隔の経過日数ではない。

## 上月城（1578年）

- [佐用町「上月城と上月合戦」](https://www.town.sayo.lg.jp/cms-sypher/www/info/detail.jsp?id=11722)：4月18日の吉川・小早川の包囲、5月4日の秀吉・荒木村重の高倉山着陣、6月26日の秀吉撤退、7月5日の開城を確認。吉川元長書状に見える毛利3万／織田1万は別勢力の総数で、個別隊や籠城側の人数へ配分しない。
- [赤松裕和「千種川流域の城館構成について―赤松居館跡の分析を通して―」](https://rekihaku.pref.hyogo.lg.jp/wp-content/uploads/2021/03/kiyo05_05.pdf)：本文72頁、表2 S10「高倉山城跡」、X=134.35666、Y=34.97853 を原表画像で実見。城跡の代表座標として採用。全PDFのSHAは `kozuki-site-coordinate.json`。
- 上月城跡自体は既存CODH代表点 134.324477, 34.975678 を使用。高倉山の個々の将の持場や、毛利各将の包囲陣を新しく推定しない。
- 秀吉と村重の救援配置は `25 <= t < 78`。78以後は救援部隊を高倉山に残さない。村重個人の別行程・出発時刻を確定したものではなく、救援段階の表示範囲。

## 有岡城（1579年10月〜11月）

- [太田牛一『信長公記』](https://ja.wikisource.org/wiki/信長公記)：巻十二（十三）に10月15日の滝川一益の上臈塚侵入、岸の砦の渡辺勘太夫、鵯塚の野村丹後・雑賀勢。（十五）に11月19日の荒木久左衛門らの尼崎移動と織田信澄の城内警固。
- [伊丹市「第2回 有岡城で織田信長と戦った?!」](https://www.city.itami.lg.jp/SOSIKI/TOSHIKATSURYOKU/BUNKA/bunnkazai/KEIHATU_ZIGYO/ouchideariokajyou/1588049228013.html)：村重は9月に尼崎へ移り、10月の城内侵入時は城主不在だったことを確認。この場面で村重を城内に置かない。
- 同ページの総構図 `arioka-sougamae.jpg` の主郭と岸の砦を、CODH城跡点および[伊丹市「猪名野神社3棟」の地図情報](https://www.city.itami.lg.jp/SOSIKI/TOSHIKATSURYOKU/BUNKA/bunnkazai/SINAI_BUNKAZAI/KEN_SITEI/1582252824285.html)の代表点へ二点相似登録。上臈塚・鵯塚の図記号中心を読み取った。原画像SHA、画素座標、式、採用緯経度は `arioka-registration.json`。
- 100mの読取幅は基準点・図記号の範囲を見込む目安。独立第三点の測量検証済み精度とはしない。砦の形、軍勢間隔、城内の進路は作図していない。
- `b-kishi`（渡辺）、`b-hiyodori`（野村）、`b-saika`（雑賀）は `t < 20` の外郭段階。`b-0`（久左衛門）は `t < 100`、`a-nobusumi`（信澄）は `t = 100`。退去・警固を同時に城内へ残さない。
- 長期包囲の旧概数5万／1万5千を、この終盤の各将の兵数に転用しない。

## 安濃津城（1600年）

- [竹田憲治／三重県埋蔵文化財センター「関ヶ原の戦と三重の城郭」](https://www.pref.mie.lg.jp/common/content/001067704.pdf)、2022年11月、PDF5頁：8月22日鍋島勝茂の浜手からの攻撃・二ノ丸占領、24〜25日の毛利勢の交戦、25日の長束正家の和議を確認。長束・安国寺恵瓊の先遣と吉川広家の合流も明記。
- 上資料は守将を富田知信と記すが、[津市「津城かわら版② 富田氏とその時代の津城」](https://www.info.city.tsu.mie.jp/www/contents/1685003046920/simple/kawaraban2.pdf)、広報津2023年8月16日号7頁は1599年以降信高の統治、信高・分部光嘉・津の町の住民による籠城を説明。ゲームの人物名は信高を維持し、資料の表記差をここに残す。
- [津市「津藩祖 藤堂高虎」津城について](https://www.info.city.tsu.mie.jp/kosodate_kyouiku/kyouikuiinkai/1004357/1004663/1004713/1004736.html)：毛利秀元が率いる西軍と富田方の籠城を確認。西軍約3万は全体で、秀元1隊へ3万人を割り付けない。
- 鍋島は `t=20` に二ノ丸侵入段階として城域代表点へ、毛利秀元・吉川広家は `t=60` から攻城段階。長束・恵瓊は先遣から名簿に残す。精密な浜手の位置・二ノ丸形状・諸隊の攻め口は資料から確定せず、城域代表点と位置を付けない名簿を使い分ける。
- 津市資料は富田氏時代の城の絵図が未確認と明記する。藤堂期の津城をこの場面にそのまま描かない。夫人の一騎討ちは後世の物語として解説されており、確定した移動として追加しない。
