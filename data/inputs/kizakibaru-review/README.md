# 木崎原の出発地と所在記録

確認日：2026-11-02。本文は要約であり、取得したHTMLをそのまま保持しない。

## 確認した資料

1. 鹿児島県観光サイト「かごしまの旅」『島津義弘公の戦い（第一部）』。「永禄7年（1564年）」「元亀3年（1572年）」、飯野城跡の説明。
   https://www.kagoshima-kankou.com/feature/shimadu2019/introduction2
2. えびの市『木崎原古戦場跡』、2022年2月28日更新。「木崎原の合戦」。
   https://www.city.ebino.lg.jp/soshiki/shakaikyoiku/5/896.html
3. CODH『日本歴史地名大系』施設・地点項目データセット、宮崎県一覧、飯野城跡（460000138600）。
   https://geoshape.ex.nii.ac.jp/nrct-poi/resource/46/index.html

義弘の1564年の飯野入城と、木崎原の合戦に際して飯野から本隊を出したことを資料1で確認。合戦の旧暦5月4日は資料2と照合する。伊東方の三ツ山出発は3日夜であり、これを義弘本隊の出発日時へ転用しない。

人物名は `person:shimazu-yoshihiro` を使い、忠平と義弘で記録を複製しない。1564年は移転の年精度、1572年は出発拠点・交戦地の同日所在記録。同日の二地点は移動の前後で両立し、同時所在や終日の滞在という意味ではない。

飯野城の代表座標は資料3の東経130.867591・北緯32.054126。城域・門・出陣路の測量値ではなく、移動起点の代表点へ採用。新しい領土管理拠点や城門の測量点を追加したものではない。群馬県の同名城（100000248500）と混同しない。

## 実装の診断

保存版22の木崎原直前の表示経路は881点、最後の直線はゲーム内換算で約15.601km。末尾2点は `[278.0321737335237,1918.0000000000002]` と `[265.3575741549852,1943.0000000000007]`（ゲーム座標）。合戦イベントの管理先は飫肥だが、史料上の出発拠点は飯野。管理拠点・本拠・参戦位置を同一視しない。

台帳と人物来歴、合戦当日の局地移動へ反映した。経路は現代OSMの比較線で、1572年の精密な通過路とは扱わない。`modern-road-candidate.json` に152点の応答・吸着距離・取得URLを保持。© OpenStreetMap contributors / ODbL 1.0。代表点への接続を含む実装は154点。詳しくは `docs/reports/KIZAKIBARU_LOCAL_MARCH_REVIEW.md`。
