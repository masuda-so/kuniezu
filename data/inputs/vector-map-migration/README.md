# 編集済み地理正本への初回移行記録

2026-11-07。編集正本は `kuniezu/map/physical/land.geojson`（陸）、`water.geojson`（湖等）、`coastline.geojson`（事前導出の岸線）。OGC:CRS84の経度・緯度で保持し、以後はGeoJSONを直接編集する。岸線は陸の派生であるため、陸・水域を変更したら岸線も整合させ、検査する。通常の配信はバイト複写だけで、原本や以下の初回準備から正本を上書きしない。

この時点では**ゲーム本体の表示は未切替**。CODH江戸期等の比較地形と既存の史料付き部分補正を移行したもので、全国の戦国期実測汀線を確定したものではない。`validFrom`/`validUntil`はゲーム表示の適用区間で、原資料の制作年代・史実の確定日ではない。

`manifest.json` は原本・既採用の正本画像と局所タイル・入力SHA・年代差・保護・岸線一致の記録、初回採用ファイルのSHAを保持する。`derivation-artifact:`は破棄可能な試作中間物の識別であり、ファイルの恒久パスではない。元入力は各GeoJSONの `sourceProvenance`、既存の `data/research/`・`data/inputs/`・`kuniezu/map/edits/`、この記録に結び付く。旧配信タイル3枚のSHAと、それらの元である追跡済み画像・projection・definition等のSHAも保存した。全域画像の復号はせず、小タイル3枚だけで現行分類を確認した。

準備コードの原文・SHAは [initial-preparation.md](initial-preparation.md)へ監査記録として保持する。試作時の絶対パスや途中の不採用版を含む原文であり、通常の生成手順として実行しない。最終の独立レビューで、香取の保護欠落・岸線role・巨大な一体岸線・元IDと利用条件の脱落を修正した。全国岸線は前後2枚を複製せず、共通部分と変化部分を分割し、表示範囲で選べる。

各water地物と保護陸の交差は面積0。有効陸とwaterの交差も両年代0。一括GEOS union後だけ生じる保護面との4.861e-20度²の浮動残差は記録に残している。実測面積や歴史精度の値にはしない。岸線は各年代で有効陸境界から開口抑止部分を除いた期待線と一致し、差の長さ0。


## 追加照合後の採用状態

最終の編集正本は陸2203地物・水域584地物・岸線2969線。W09全556記録の照合から、自然湖17件を追加した。[自然湖の根拠](natural-lake-evidence.md)と[照合記録](w09-coverage-review.json)は、古い時代からの存在と現代比較輪郭の区別を保持する。全未被覆記録を欠落と見なしてはいない。

[溜池の照合](postperiod-water-evidence.md)に基づく7件は、後世の完成輪郭を外し、[元の地物](deferred-waters.geojson)を保存した。前身の沼や池を創作せず、補われる背景は `allowTerrainInference:false`・`noHistoricalDryLandAssertion:true` とする。上堰潟は保持する。`deferred-water-decision.json` の候補状態は当時の選定記録で、現在の適用状態は `manifest.json` の `implementationState` と `deferredWaterApplication` に記録する。

`water-evidence.geojson` は別の4地物。飯沼・見沼・塩津潟は輪郭のない地名点、椿海は既存出典からの推定面で、海陸・行軍判定には入れない。原本・入力SHA・移行検査は manifest の `waterEvidence` と準備コード記録へ結び付く。
