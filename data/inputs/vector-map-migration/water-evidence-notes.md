# 旧水域表示のGeoJSON移行候補

2026年11月7日。既存の水域JS・史料台帳・椿海の登録報告から、4地物の表示情報だけを取り出した候補。編集済み正本への採用は親担当が判断する。リポジトリ、人物作業ツリー、サーバーは変更していない。

|地物|geometry|drawRole|位置・形状|
|---|---|---|---|
|飯沼|Point|water-label|元ラベル位置 `[139.947, 36.13]`|
|見沼|Point|water-label|元ラベル位置 `[139.70, 35.90]`|
|塩津潟|Point|water-label|元ラベル位置 `[139.35, 38.02]`|
|椿海|Polygon|inferred-water|`TK.TSUBAKI_LAKE.rings` の現表示値を無改変で複写|

椿海は閉環を含む102座標（相異なる座標101）、小数最大6桁。座標の順序・環の向きも保持する。元の時計回りの環を反転しない。`data/verification/tsubaki/lake.geojson` にある丸め前の座標は採用せず、`tsubaki-lake.js` と数値列が完全一致する。

飯沼・見沼の少数頂点の旧面や、新発田城を覆っていた塩津潟の旧面は移さない。Pointは史料に記された測点・湖心・城の位置を意味せず、`positionRole: approximate-label` として地名を置くためだけに使う。

## UIへ渡す契約

- `properties.name` と `label` は地名のみ。`description` は地名・歴史上の短い説明だけ。
- 旧ラベルの「湖岸未確定」等は `provenance.originalLabel` に保持。RMS、対応点、未確定の年代、旧面を移さない理由はすべて `provenance` に分離。
- Pointはラベルとして、椿海は推定水域として別に描く。`changesLandMask: false`・`affectsMovement: false`・`exactHistoricalShoreline: false` を全4地物に設定。地形の陸海マスク・移動バフやデバフ・施設判定へ取り込まない。
- `validFrom: [1560,1,1]`、`validUntil: [1616,1,1]` は表示適用範囲。湖の成立・消滅日や原図の描写年ではない。ゲーム対象期間に一様な正確な湖岸があったという主張にも使わない。
- 採用後は編集済みGeoJSONを正本とする。通常ビルドはバイト複写であり、ここに付けた `prepare.cjs` は一度の移行候補作成用だけ。生成器や旧JSから正本を上書きする入口に接続しない。

## 年代と根拠

元のURL・確認箇所・登録時の留保は各地物の `provenance.sources` に置いた。元JS、生成元、読図入力、位置合わせ報告、過去の採用報告の相対パスとSHAを保持した。Pointには位置合わせの記録がないため、generator/registrationReportはnullとし、架空の精度を与えていない。

- 飯沼：[坂東郷土館の展示解説](https://www.city.bando.lg.jp/page/page002762.html)はページ末尾2015年9月27日、1724年の干拓許可とその後を説明する。国交省の元禄・天保図比較も17〜19世紀の参考資料であり、戦国期の面を確定しない。
- 見沼：既存のさいたま市図書館・埼玉県出典を保持。1629年の溜井化はゲーム対象期間後である。図書館ページは今回の再取得ができなかったため、今回再読した資料には数えない。
- 塩津潟：既存の発掘報告第164集の印刷8〜9頁に関する読図報告を保持。1645年図の復元と干拓直後の古地理を区別する。1721・1728・1732年の工事段階を戦国期の面へ前倒ししない。今回原本の再取得や全頁再読はしていない。
- 椿海：1979年の国土地理院報告が1958年の事業史を介して載せた17世紀干拓時の図を使う。原図の「寛文12」と「1670」の不整合は未解決のまま保存し、1670または1672へ決め直さない。[千葉県の解説](https://www.pref.chiba.lg.jp/ap-kaisou/kaisou/kibanseibi/higata.html)にある「1670年（寛文10年）」は別出典の記述として保持する。公刊報告年・転載年・原図が描く時期を分けた。

椿海の当てはめRMS643mは、村名代表位置5点に対する値。独立検証点は0であり、湖岸の絶対精度を表さない。原PDFのSHAは既存manifestと実ファイルで一致した。PDF自体を候補へ複製していない。

## 検証

`verification.json` に結果を記録。4地物・3点＋1面、現表示102座標との完全一致、閉環、概略ラベル位置不変、陸海/移動変更0を確認した。旧面の混入、座標の改変、陸海マスクへの昇格、制作側の文章の表示欄への混入、未解決年号の勝手な確定という5負例を拒否した。読み取り入力17ファイルのSHAも抽出前後で不変。

```sh
node /tmp/kuniezu-water-evidence-source/verify.cjs <リポジトリのパス> /tmp/kuniezu-water-evidence-source
```

検査は候補の構造と移行境界を確認するもの。史料からの新たな汀線確定や、実画面での描画検査ではない。Chrome・全域画像生成・ゲーム日次進行は行っていない。
