# 高天神包囲4砦の一括照合

確認日：2026年11月3日。担当：Codex fort_sources。ゲーム本体は親担当が統合する。

## 採用判断

中村砦の表示開始を1580年から1579年へ変更する。能ヶ坂・火ヶ峰・獅子ヶ鼻の1580年は維持する。根拠は掛川市『歴史的風致維持向上計画 資料編』資料編1（PDF3頁）の年表。年の欄と砦名の行対応は原図でも確認した。年精度の情報であり、月日を補わない。

4砦は高天神城を包囲する徳川方の陣城。主城や武田側の支城として分類しない。中村・火ヶ峰・獅子ヶ鼻は大須賀康高の担当。能ヶ坂は本多の官途に資料間の異同があるため、現行「本多勢」を維持する。担当の記述から、最終日の本人の所在を固定しない。

既存4座標は公開案内地図の地点2〜5と一致した。精密な遺構測量の確認ではない。火ヶ峰は位置に二説あり、東砦の代表点という現行の限定を維持する。獅子ヶ鼻は菊川市の別の案内マーカーと96.33m離れる。入口・主郭等のどの地点を示すか未確定なので、片方へ機械的に動かさない。

これらは自治体史・自治体掲載の研究者の解説であり、16世紀の原史料そのものとは区別する。獅子ヶ鼻の厳密な初築年には町誌紹介との幅があるため、1580年6月を全史料で確定した日程とはしない。

## 採用しなかった記述

- [掛川市の2017年3月31日付記事](https://www.city.kakegawa.shizuoka.jp/gyosei/docs/6328.html)には中村砦を「1590年ころ」の高天神奪還とする記述がある。市年表の1579年築造・1581年落城に反するため、年代根拠には採用しない。
- 案内マーカーの一致を歴史的な城域・主郭中心の測量精度とは扱わない。
- 本多の官途異同を理由に、担当を本多忠勝など特定人物へ置き換えない。
