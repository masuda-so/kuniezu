# 津宮周辺の汀線資料と現代標高の点検

整理日：2026-11-02。ここでは読書用の要約と検査値を保持する。ゲームの湖岸の修正入力や確認済み命題ではない。

## 研究資料

笹生衛「『香取神宮神幸祭絵巻』と神幸祭の史的背景」『香取文書調査報告書―香取文書の文化財としての保存に向けた基礎的研究』、研究代表者・鈴木哲雄、2024年3月、63頁以降。確認箇所は67頁「津宮の古代・中世の景観と三社の神格」および注15〜17。

[大学リポジトリの資料情報](https://tsuru.repo.nii.ac.jp/records/2000111)。研究課題は20K00941、2020〜2023年度。

検索サービスから提供された本文テキストでは、津宮三社の位置、自然堤防、絵巻の描写を合わせて中世前期の汀線を推定している。対象は13世紀初頭頃であり、1560〜1615年の精密な汀線ではない。標高2mの線という説明を地域全体へ広げない。発掘成果や絵画資料と合わせた推定であり、現代標高だけの閾値処理とは区別する。

原PDFの直接取得は503で失敗し、図版の原画像は未確認。香取市の関連講演PDFも404で取得できなかったため、画像を確認済みとは扱わない。取得結果は `source-review.json`。全PDFを保存できたとするハッシュは記録しない。

## 既存の推定湿地の検査

`raster-boundary-review.json` は既存7領域の推定湿地を、元の現代GSI標高へ戻って調べた結果。

- 500m以上の東西・南北方向の辺は7箇所。
- 7箇所とも、調べた中点周辺7×7画素は全て有効な標高値。タイル境界上の辺は0箇所。
- 例として東経140.606・北緯35.884321付近には、東西方向に同じ値が続き、南北に2.7、2.77、2.85、2.9、2.99、3.0mと変わる帯がある。そこで閾値を切ると東西の直線が生じる。

したがって、その辺を欠測タイルの穴埋めや乱数による凹凸で直す理由はない。治水・干拓後の地形や平坦な標高処理を、古い岸と取り違えないことが必要。長い直線が全て誤りという判定でもない。

再検査：

```sh
python tools/geo/fetch-katori-dem.py
python tools/geo/audit-raster-derived-boundaries.py data/verification/katori/estimated-marsh.geojson /tmp/kuniezu-katori-dem data/inputs/katori-tsunomiya-review/raster-boundary-review.json
```

元の湿地形状と復号標高にSHA-256を付け、7箇所の座標・標高抜粋を保存した。地域ごとに別の描画算法は追加せず、共通のWeb Mercator画素で比較する。
