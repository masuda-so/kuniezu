# 塩津潟：年代と位置を分けた照合

2026-11-03、担当 Codex 子エージェント `shiotsu_sources`。ゲームファイルは変更していない。

## 結果

現在の `water-evidence.js` を実行すると塩津潟は `labelOnly: true`、水面輪郭なし。旧13頂点の誤マスクの除去は、湖の復元完了ではない。

新発田市の2019年報告58集第1図に**地形図に重ねた干拓前の全体輪郭**を確認した。図の灰色塗りはPDFのベクトルで、手描き直線を増やさず抽出できる。1,510点、登録後面積17.507km²。`source-boundary.geojson` は**比較資料として採用**する。新発田城と江上館の2点で相似登録、未使用の砂山中道下・住吉は306.45mと190.46m差。中央の青田遺跡を追加で独立照合すると35.93m差。100m精度とは扱わず、1560年の確定汀線へ直接投入しない。

`source-boundary-overlay.png` は原図上の抽出範囲、`gsi-comparison.png` は同じ実座標で国土地理院標準地図へ重ねた図。原図の西岸には村境に沿った細かな凹凸も含まれる。細かい点数がそのまま古湖岸の測量精度を意味するわけではない。

   - 第8図は1645年絵図の復元、第9図は潟の形成以前、第10図は干拓直後。第9図の水域を戦国期へ転用しない。
   - 砂山中道下は中世に形成した自然堤防上の集落。対して野中は古代集落であり、同じ陸地制御点にはできない。
2. 新発田市教育委員会（2019）『住吉遺跡発掘調査報告書』第58集、本文1〜3頁・第1図・巻末抄録。[原PDF](https://sitereports.nabunken.go.jp/files/attach/35/35179/69863_1_%E4%BD%8F%E5%90%89%E9%81%BA%E8%B7%A1%E7%99%BA%E6%8E%98%E8%AA%BF%E6%9F%BB%E5%A0%B1%E5%91%8A%E6%9B%B8.pdf)

3. 新発田市デジタルアーカイブ、神田家文書1834『紫雲寺潟絵図』（1721）。[目録](https://adeac.jp/histlib-shibata/catalog/ct00000030)
   - 原図を実見。北向き水路と海側の排水路を含む。原図全体がゲーム対象時代の地形という扱いは不可。二次利用条件は所蔵者への照会を求めるため、画像は内部照合資料として保持し、ゲーム配布画像へ流用しない。
4. 新潟県新発田地域振興局農村整備部『3 塩津潟（紫雲寺潟）干拓』（2019更新）。[本文](https://www.pref.niigata.lg.jp/sec/shibata_noson/1356833203513.html)

5. 新潟大学積雪地域災害研究センター研究紀要20、81〜104頁、加治川・紫雲寺地域節。[本文](https://niigata-u.repo.nii.ac.jp/record/28031/files/20_81-104.pdf)

## 再実行

`register.py` を pypdf・numpy・Pillow のあるPythonで実行。原PDFの当該ページは `*-excerpt.pdf` に保存し、元の全体SHA・サイズ・ページ対応は `pdf-excerpts.json`。不要な全308頁の複製を避け、78MBの原本から照合用ページ約1.7MBを保持した。HTML原文は保持しない。

`registration.json` に制御点・未使用点・残差・採否、`period-controls.json` に年代別の適用制約を保持。国土地理院タイル20枚は比較画像専用で、古地形として採用しない。

青田遺跡の位置は[全国遺跡報告総覧抄録47131](https://heritagemap.nabunken.go.jp/statistic/47131-%E9%9D%92%E7%94%B0%E9%81%BA%E8%B7%A1.html)の世界測地系（139.357222, 38.022777）。ここでの照合は図の位置合わせを検証するためであり、古代の遺跡存在を戦国期の陸域根拠へ転用していない。
