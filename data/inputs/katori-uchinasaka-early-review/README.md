# 内浪逆浦・早期史料の補強

2026-11-04確認。原頁の所在とSHAを `artifacts.json` に保持する。HTML全文は保存しない。

- **橋本直子（葛飾区郷土と天文の博物館）**「天明浅間山噴火と利根川水系―治山・治水の相克」『sabo』110、2012年4月、本文6頁（PDF8頁）。[原PDF](https://www.stc.or.jp/journal_sabo/pdf/SABOVol.110.pdf)。中世の佐原〜潮来周辺の湖沼として内浪逆浦・外浪逆浦を挙げる。湖の存在の独立補強に採用する。同頁の別河道の年号併記には誤りがあるため、日付や工事年の根拠には採用しない。
- **潮来町『潮来町史』1996年**、[338頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index350.html)・[342頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index354.html)・[343頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index355.html)・[348頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index360.html)。村田氏・七軒島の居住、徳島の離洲と湖沼利用・帰属争いを記す。正保図への言及はあるが、その提出原図を入手したわけではない。342頁の村絵図に年代明記がなく、これを正保図と扱わない。原JPEG4頁を保持。
- **井内美郎・斎藤文紀**「海跡湖の地史−3 霞ヶ浦」『URBAN KUBOTA』32、1993年、本文62頁（PDF64頁）。[原PDF](https://www.kubota.co.jp/urban/data/32.pdf)。局所の堆積速度差や小氷期の水位変化を論じる。水位の低下量は不明であり、堆積だけから岸を単調に逆算しないための制約として採用。
- **茨城県**『土地分類基本調査 潮来・銚子』1989年3月、本文23・33頁。[国土交通省公開PDF](https://nlftp.mlit.go.jp/kokjo/tochimizu/F3/data/pdf/0811t.pdf)。延方・下幡木の砂州、低地の形成・堆積を参照。原本は既存 `data/inputs/katori-uchinasaka-review` に保持。
- **元禄国絵図常陸国**、国立公文書館・特083-0001-0037。[目録](https://www.digital.archives.go.jp/item/764298)。既存のRoDA拡大原図を実見し、近世の水面と砂州の併存を比較。地名の精密同定や1560年の水際の直接復元には使わない。
