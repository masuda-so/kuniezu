# 部隊選択のキー入力確認

2026-11-07、専用Chromeを起動済み8000へ接続し、候補ソースをブラウザ内だけで差し替えた。関ヶ原・伏見の940/335pxの4ケースで、部隊ボタンをクリックした後に実際のSpaceキー入力を送った。

ボタンの選択操作が背後の全国地図の再生キーに横取りされず、地図の速度と日付が変わらないことを確認。密集時のサイズ・個別選択・前面表示・地理位置・一覧の高さと押下状態の検査も通過し、JavaScript例外0。詳細JSONと画像はローカル保管する。

通常の地図上でのSpace／数字キーとEscapeの分岐を読み取りで独立レビューした。実ブラウザで全ショートカットを網羅したという記録ではない。
