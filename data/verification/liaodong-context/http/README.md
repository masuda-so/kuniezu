# 遼東・児島湾の実配信受入

2026-11-03、起動済み `http://localhost:8000/index.html`、配信版 `fe05cc5`。専用Chrome一つで確認し、終了済み。サーバーと普段のブラウザは操作していない。

- 正本 provinces.png の SHA と配信manifestの対応をHTTPで確認。
- 1560・1572・1573・1603・1605・1606・1615年を幅1400/390で確認。寛甸の採用期間、旧誤領域の除去、義州の城領を判定画像で確認。
- 遼陽・瀋陽・開原、女真諸部・蒙古諸部の地名、年代別説明、マウスとタッチの詳細表示、以前の城選択の解除を確認。
- 明の色と参考境界の点線を実際のCanvas呼出しから確認。参考線を精密な確定国境や外交関係としない。
- 児島湾の8点、藤戸の通水、1584年の宇喜多期差分を全時点で確認。1615から1560へ戻した場合も一致。
- JavaScript例外、ゲーム画像等のHTTPエラー、読み込み失敗は0。favicon.icoへの404だけ別記。

初回は遼陽が左年表の下へ固定されて操作できず失敗した。ゲームの表示範囲が古い固定値だったため、正本画像の原点・寸法へ同期し、画面全体が画像内に収まる制限を保って修正した。範囲外を架空の海で埋める対応は採用しなかった。読み込み済みの場合も初回同期する。

`result.json` に全時点の判定・実操作・描画検査、`wide.png` / `narrow.png` に画面を保持。`check.cjs` はこの正本SHAに対する受入時の検査原本であり、将来別の正本へ更新した時はそのまま全体回帰の代わりに使わない。

日付を地図表示に設定した検査で、1560〜1615年の全史実イベントを再実行した検査ではない。遼東線の20〜25km程度の資料精度、古湖岸の推定範囲は元の資料台帳のまま保持する。
