# 合戦図の動き（視点の追従・進軍の矢印）の実画面確認

2026-11-10。作業ツリー `claude/battle-motion` を 127.0.0.1:8000 で配信し、専用の一時 Chrome
（ヘッドレス、1280×900）で確かめた。画像は Git に入れていない。

## 確かめたこと

- 関ヶ原の戦いを経過 54.2 から 5 秒再生：描画は 5 秒で 303 回（毎秒約 60 回）。視点の倍率は
  2.083（関ヶ原本戦）から、経過 55 の交戦の組（小早川・大谷）へ向けて連続して変わった。
- 「動きを追う」を切ると `viewFollow=false` になり、選んである表示範囲（2.083）へ戻った。
- 停止中に「全体」を押すと、倍率は 2.083→1.892→1.523→1.238→1.036→1（約 110 ミリ秒ごと）と
  連続して変わった。
- 関ヶ原・桶狭間・賤ヶ岳・姉川の 4 合戦で、再生中に視点が動き、JavaScript のエラーは 0 件。
  姉川は表示範囲の切替が無い合戦で、追従だけが働く。

## 確かめていないこと

- 全 111 合戦の通し再生（`all-battles-browser.cjs`）は回していない。
- `battle-viewport-browser.cjs` は、この変更の前の main でも同じ箇所
  （`#bCv` の `mapReady` 待ち）で時間切れになり、変更の前後を比べられなかった。
- 実機のスマホ幅と、動きを減らす設定の端末での見え方。
- 長篠の戦いは、今回の手順では合戦図の canvas が開かず、対象にできなかった。
