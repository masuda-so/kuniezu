# 密集した駒の実画面確認

2026-11-07。起動済み8000へ専用Chromeを接続し、候補JS/CSS/HTMLをこのブラウザ内だけで差し替えた。関ヶ原・長篠・大坂冬／夏・伏見を940/335pxの10ケースで確認した。JavaScript例外0。

- 密集時の本体下限は広幅18px／狭幅14px、顔は16pxを維持する。選択隊の本体・顔は従来の大きさに戻る。
- 8ケースで同地点の全隊を一覧から選択できた。選択隊の本体と肖像を最後に描き、元の画面位置を保持した。
- 選択前後の全隊の地理位置・時刻・状態は不変。画布の変換行列による丸めは0.001px以内とし、地理位置そのものを変更して合わせていない。
- 選択リストは最大220pxまたは画面高の28%に抑え、「部隊を選ぶ」と閉鎖操作を上へ配置した。選択中の隊を押下状態で表示する。リストの最後の隊まで実クリックできた。
- 狭幅・広幅の画像を目視し、地図と再生操作、人物の選択を確認した。画像・詳細JSONはローカル保管する。

共有Canvas fixtureのNode検査は全111件の1320フレームで個別ID・中心位置・サイズ下限を確認し、388選択・130同地点一覧を通過した。退場隊の透過と描画状態の復元、駒中心に被った別隊名札の操作も確認した。史実配置や全連続時刻・全端末の検証ではない。

初回のブラウザ検査は画布幅の比率による座標換算と過小な許容差で失敗した。実際の変換行列とその丸めに合わせて検査を修正した。前の候補と失敗時の画像は別ディレクトリへ保持している。
