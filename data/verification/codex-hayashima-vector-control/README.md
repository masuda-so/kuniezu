元8m丘陵の不足約0.99haを早期の陸へ戻し、1584年以降の陸は不変とした。同じ部分だけを管理GeoJSONへ登録し、旧採用定義の`castle:bmatsuyama`を引き継ぐ。史実知行や精密汀線の新しい確定命題ではない。

- `tests/test_vector_sources.py`と`tests/test_subcell_control.py`：4件合格。全正本の幾何妥当性、元丘陵の各時期の被覆、管理部分の丘陵内への限定、水域との交差なし、同時期の管理面の非重複を確認。
- `vector-map.cjs`：色と選択が同じキー・穴・期間を使い、不正入力の原子的拒否とキーによるパスの除外を確認。
- `vector-assets.cjs`、`--vectors-only --check`：7ファイルを座標変更せず配信し、正本とのバイト一致を確認。
- 専用ChromeでDjangoの実配信を検証。旧判定で選択できなかった2地点を、幅940pxと335pxで実際にクリックして備中松山城を選択できた。広狭・回転・全国復帰も確認し、例外0。両幅の画像を目視確認した。
- 小キャンバスの合成入力では、精細管理部分と通常部分のRGBAが一致し、国色を二重に塗らないことを確認。色の取得失敗時も元の国色を維持する。これは実海岸の測量検査ではない。
- 正本取得失敗の別実行では、起動幕と再読込ボタンを保持し、不完全なファイル群を描画へ出さないことを確認。
- 独立レビューで、未知キーの拡張時の退行を指摘され修正。フィルタ付きパスのキャッシュ分離を含め、再レビューで指摘閉鎖。
- `offline.cjs`、Ruff全体、mypy 43ファイル、静的書出し、organization・infrastructureも合格。検査が更新した監査JSONはこの証拠フォルダへ保全し、今回の正本変更と無関係な追跡済み監査差分は検査前のバイトへ戻した。
