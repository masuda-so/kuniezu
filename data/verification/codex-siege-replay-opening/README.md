# 攻城再生の冒頭・終端の実画面検証

2026年11月9日、親担当が起動済み `http://127.0.0.1:8000/index.html` を専用Chromeで確認した。サーバーは親作業ツリー（PR115の変更を含む）を配信し、Fetchで候補の battle-catalog.js / battle-catalog-extra.js / battle-deployments.js / history-date-review.js / battle-presentation.js の5本だけを差し替えた。テンプレート・UI・その他の資産は実配信を使用した。

箕輪城落城、掛川城開城、岐阜城の開城、小田原開城、高天神城の戦い、韮山城の戦いの6件で、実UIの #bNow / #bClock を0・5・49%で確認し、高天神59・60%、韮山50%も確認した。99%から通常の再生処理で終端へ進め、既存callbackへ転送した後のDOMに結果文が到達すること、自動close、再表示、巻き戻しをすべて確認した。自動closeは無効化していない。高天神0・60%の画像は親担当が目視し、包囲から降伏申出への切替を確認した。

結果は6件とも合格、実行時例外なし。画像・result.jsonはこのディレクトリへ保全し、GitにはこのREADMEだけを含める。5本の差替SHAはresult.jsonに記録されている。合戦名や参加隊数、地形位置、史実日付の変更を検証したものではない。
