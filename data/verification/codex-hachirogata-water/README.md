# 八郎潟の候補実画面

香取海を含むmain 96450b4へ追従した独立作業ツリーで、`node tools/checks/hachirogata-water-browser.cjs` を実行した。サーバーの起動・停止はせず、候補のfile URLを専用一時Chromeで開いた。共有localhost:8000の表示更新を示すものではない。

倍率1・3・5.5で表示し、細密段階の湖/復元陸/海の判定と、実行時例外0を確認した。画像と結果JSONはこのフォルダにローカル保存し、GitへはこのREADMEだけを含める。

正本から再生成した地図は、湖面復元6,201セル・陸戻し3,820セル・造成疑いによる保留199セル・局所湖面23,423セルの検査に合格した。香取海の水域1,719セルと保護陸70セル・岸線補正も保持した。これは全古湖岸の史実照合完了を証明する検査ではない。

旧船越水道を追加した最終版でも3ズーム・水陸対照を再実行し、旧水道がlake、中島がlandとなることと例外0を確認した。機械検査では湖→海の4近傍接続と中島の孤立陸18セルも確認。旧水道の追加画像は `hachirogata-old-outlet.png`。
