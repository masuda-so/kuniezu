# 合戦図の位置保持・実画面確認

専用一時Chromeで起動済み `http://localhost:8000/index.html` に接続。
`GAME_OVERRIDE_ROOT` により候補の `battle-atlas.js`、`battle-motion.js`、
`index.html` のみを当該ブラウザ内で差し替えた。サーバー・共有配信物・通常保存は変更していない。

関ヶ原・高天神・本能寺・耳川・木津川口を、1400×1000、390×844、335×740と
地区切替で確認。部隊APIの地理位置の差は0、耳川の推定配置隊を本体クリックから選択できた。
木津川口の模式図は地理座標を返さない。関ヶ原の開いた選択パネルは寝返りで顔枠が更新され、
逆seekで元に戻り、閉鎖後に再表示されない。JavaScript例外0。

`battle-viewport.cjs` は描画命令で実際の駒中心も照合し、幅・倍率・時刻120条件、
同地点の選択、画角外の駒、線種を検査する。Chrome検査と役割を分ける。
画像とresult.jsonはローカル証拠として保持し、Gitにはこの要約だけを含める。
史料自体の精度・推定経路の史実性や全合戦の視認性の確定を示すものではない。
