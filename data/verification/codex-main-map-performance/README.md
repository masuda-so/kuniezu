## 測定の限界と次の判定

後の実入力測定で、ゲーム開始直後のカメラ演出が設定値を1.3へ戻すことを確認した。この測定の再生区間も上書きの可能性があるため、zoom5での再生性能とは断定しない。パン区間は各操作でzoom5を設定しているが、異なる条件の測定から改善率を出さない。

- 既存道具は `--disable-gpu` を付けている。これを普段のGPU有効ブラウザの性能や発熱へ一般化しない。画像品質を落として軽量化したという結果でもない。
- 視点移動は `TKUI.cam` の呼出しで、実ポインタやホイール操作の完全な再現ではない。ズーム中のキャッシュ経路も別に確認する必要がある。
- 道具が待つ `TKTerrain.stats` は現在の本体陰影 `TKRelief` と別。pending=0を全地形の準備完了と読み替えない。遅着タイルによる再構築を含む可能性がある。
- 一回の基準測定で、修正前後の改善や全環境の快適さは証明しない。次はGPU有効時の確認と、同じ操作での画像転写・再構築の比較を行う。

`performance.json`・画面・詳細ログはローカル証拠として保持し、Gitへ含めない。
