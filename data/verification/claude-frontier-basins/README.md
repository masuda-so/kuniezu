# 満州の流域の境・タイルの継ぎ目（claude、2026-11-04）

## 満州と和人地の境を流域で引き直す
- `manchuria-basins.png`：正本 provinces.png の満州（東経122.6〜137.6度・北緯39.6〜45.7度）を区画別に塗った図。紫＝蒙古、緑＝海西、青緑＝東方の女真、黄＝建州、橙＝明、灰＝朝鮮。境は Copernicus DEM から求めた分水嶺。
- 書き換えた画素：蒙古→海西 2,882,263、海西→東方 2,033,288、海西→蒙古 1,103,168、東方→海西 405,422 ほか。和人地：蝦夷地→蠣崎 17,457、蠣崎→蝦夷地 3,294。

## タイルの継ぎ目の線
- 原因：配信タイル（1024画素角）を画面の画素の端数の位置に貼ると、端がアンチエイリアスで半透明になり、タイルの形の細い線が出る。
- 修正：`TKDrawTile`（game/raster-map.js）で四隅を画面の画素の格子に丸め、隣のタイルと端を共有させる（領域の塗りと陰影）。
- 実ブラウザでの照合（4つの拡大率、600×600、陸海を不透明で塗る）：半透明の画素 旧 2,998 → 新 0。
