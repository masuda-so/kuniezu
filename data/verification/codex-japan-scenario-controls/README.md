# 日本の勢力選択・速度選択の実画面検証

専用一時Chromeで、起動済み127.0.0.1:8000の配信に候補ui.jsとテンプレートを差し替えて検証した。通常配信に反映済みとは扱わない。サーバーの起動・停止なし。

全7シナリオ×1400px・390pxと地図からの選択の15ケースに合格。各シナリオで朝鮮が選択肢に出ず、九州・東北の地域絞り込みはゲームを開始せず、選択時だけ1回開始する。335pxで北条を選択し、設定・保存復元も確認した。不明な家と朝鮮への直接選択要求は無視し、既存の史実観察の将来独立家の非表示を保持する。

広幅で速度×2・×1をそれぞれ選び、停止中のaria-pressedと再開速度が一致した。335pxでは速度選択欄から×2を選び、停止中も選択欄とボタンの状態が一致する。JavaScript例外0件。スクリーンショット paused-speed-1400.png と paused-speed-335.png を目視確認した。

画像・JSONはローカル証拠として保持し、このREADMEのみ追跡する。最初の実行はChrome起動不可、次の実行は狭幅で非表示のボタンを検査側が押したため失敗した。検査側を広幅ボタン・狭幅選択欄へ直した最終実行は終了コード0で通過した。

追加の最終実行では「諸家」の朝鮮非表示、滅亡後の継続先の朝鮮非表示、直接指定しても観察中の家や窓が変わらないことを確認した。同じ15ケース・速度の広狭操作・保存復元も再通過。japan-relations-335.png と japan-successors-335.png に保存。

操作案内を修正した最終検証は、180秒制限に達した一括実行を通過扱いにせず、final-wide/ と final-narrow/ に分割した。各8ケースを終了コード0で通過し、重複する地図からの選択1ケースを除いて15固有ケース（7シナリオ×2幅＋地図選択）を保持する。遊び方の再生位置・時間軸・史料入口の文言も画面上で検証した。共有Git管理領域の所在確認中のため、退避したUI・テンプレート2ファイルを明示した一時ハーネスを使用し、Gitによる差分列挙だけを置き換えた。
