## 画像を目で確かめたこと

1560・1582・1600 年の開始時点、近畿と関東、幅 1400 px と 390 px の 12 枚で、郡ごとに家の色で塗られ、郡の境が細く、持ち主の違う郡の境に国境の線（関係の種類ごとの描き方）が引かれ、規則で決められない郡に雲が重なること。
