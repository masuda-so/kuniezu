# 羽州道の表示確認

専用Chromeで1560年シナリオの大鰐付近（東経140.559313度・北緯40.483289度）を5倍で表示し、同一交差点へ戻る比較線12.928kmが個別審査による除外に含まれることを確認した。JavaScript例外は0件。起動済みサーバーが応答しなかったため、テンプレートから書き出した一時ページを使った。

檜山―石川・石川―三戸に検証用部隊を置き、各区間の25・50・75%地点を5倍表示で確認した。既存の行軍描画が返す駒の位置は、6点とも修正後の経路上の期待位置と一致した。史実部隊の着陣や経過時間を測る試験とは区別する。

江戸期の比較線を追加した版でも専用Chromeで5倍表示を確認した。追加した線の中間点が実行時の道路形状に含まれ、出典IDが付くことを確認した。JavaScript例外0件。旧保存移行検査も合格した。

比較線の引き直し後も全319城間接続のIDと端点は一致し、変化した檜山―石川・石川―三戸では、検証用部隊の駒が修正後の経路上の計6地点に描画された。

`offline.cjs` は全7シナリオ各720日の史実進行と保存を含めて合格。専用Chromeでは「操作 → 合戦と史料 → 地図と行軍の出典」の実クリックで、資料名・版・DOI・参照日と、戦国期の経路が未確定である旨を確認した。
