# 児島湾の年代別の版の実画面確認（2026-11-03）

起動済みの `http://localhost:8000/index.html` に専用の一時 Chrome（ヘッドレス、1400×900）で接続し、拡大5.5で撮影した児島付近。

- `s1560-kojima-bay.png`：1560年（版 `15600101-15840101`）。児島・天城・早島は島。
- `s1600-kojima-bay.png`：1600年（版 `15840101-16160101`）。早島が宇喜多堤で本土と続く。

クリックの結果（100m 判定 → 選ばれた城）は両年とも一致：湾の中・沖新田の沖は海で選択なし、児島・藤戸の北岸・天城は天神山城、倉敷・早島の丘・連島は備中松山城。宇喜多堤の内の2点は1560年に海、1600年に備中松山城。JavaScript 例外0。
