# 調査・検証データ

- `inputs/`：元の人物・兵数・追加城リストや地理生成の入力。元資料と出典を維持する。
- `research/`：出典・史実命題・原本・対応関係。実装の棚卸しと史料で確認した事実を分離する。
- `audits/`：検査・生成スクリプトが作るJSON。手で「確認済み」へ変更しない。
- `verification/`：画像、比較図、測定値。実行ごとに保存先を分け、他担当の証拠を上書きしない。

登録された全件の構造点検、史実を出典で確認した件数、歴史上の全件の網羅は異なる。未取得や異説を隠して照合完了にしない。原本はゲーム配信物へ無条件に転載しない。

整理前の場所と新しい場所は `docs/architecture/path-migration.json` に記録。ゲームが配信する `game/` のURLはこの整理で変更していない。
