# 担当別に追加する史料入力

`claims/` は確認済みの一命題を1ファイルで保存する。`sources/` はゲームの出典一覧にない新規の書誌を1出典1ファイルで保存する。同じ名前のファイルや出典IDを別担当が無調整で置き換えない。

出力 `../claims.jsonl` は生成物。新しい調査成果はこのフォルダへ追加し、`node tools/research/export-evidence.cjs` を実行する。再生成しても別担当の入力は削除されない。未審査の候補・質問はここへ入れず、対象別作業の報告に記録する。

命題には安定ID、対象、述語、値、適用年の範囲、出典ID、該当箇所、確認日、実装先、確認範囲内の審査済み状態を記録する。日付精度と異説・限界は該当する項目へ明記する。URLの登録だけで審査済みにしない。

既存21命題は従来の出力と同じ内容を保存した。移行は新しい史実確認を21件行ったという意味ではない。

`identities/` は、2 つの識別子が同じ対象か（`same-site`）、ゲームの拠点が台帳の場所を代表しているか（`represented-by`）の記録。名前が同じというだけでは登録しない。形は [identities/README.md](identities/README.md)。

`people/` と `places/` は固定IDの登録、`locations/` は出典付きの居所・所在・役職の記録。名称・改称と物理的場所を分ける。精密座標は別途照合する。年だけ分かる記録を日単位の滞在へ変換せず、資料の空白年を埋めない。既定の史実命題検索とは別に `query-locations.cjs` を使う。
