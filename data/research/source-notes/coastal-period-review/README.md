# 沿岸5地域の年代比較

13入力を再照合し、具体的な年と工事段階を確認できる8入力から15命題を作成した。残る5入力は比較・留保・別説としてadoption.jsonへ保持し、未検証の輪郭・日付をcurated/claimsへ入れない。

- 年代と対象の二方向検索に接続するが、15命題は人の所在や領有観測ではない。
- 1592年・1603年・1608年の3命題だけがゲーム期間内の工事段階。残る12命題は1615年後の比較記録であり、期間内へ前倒ししない。
- 日精度の新規イベントは0。旧暦月、近代の西暦月、年度と暦年を区別し、原記載はvalue.sourceTimeに残す。
- 地理座標・汀線の採用は0。区域名の命題は正本の塗替えを許可しない。300標本の現行画像照合は実装監査であり、この史実台帳へ混在させない。
- 東京湾の近現代埋立資料は既存のtokyoReclamationと同URLで、別のsource IDとして重複登録しない。
- 大和川1704年西流区間の現行線混入は前回監査で再現しなかった。歴史の改変記録が存在することと、現在の描画が誤っていることは別である。

各地域のMarkdownとadoption.json、hii-dating-alternatives.jsonから根拠と採否を確認する。原本の保管と確認値は data/inputs/coastal-period-review/retention-manifest.json に記録した。
