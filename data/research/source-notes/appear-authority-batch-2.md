# 年表の登場人物 18 名の外部典拠照合（第 2 便、NDL 典拠）

2026-11-09。`appear-person-authority-candidates.json` で候補が 1 人に絞れた人のうち、Wikidata の P349 が国立国会図書館の個人典拠を指し、その主名がゲームの名前と一致し、人物型（foaf:Person）である 18 人を同定した。これまでの典拠の便（筒井順慶など）と同じ型で、同定の根拠は「NDL 典拠の主名と人物型」と「Wikidata の日本語主名と P349 の対応」の 2 項目。ゲームの生没日・登場日・所在と、確認済み史実命題は変えない。

採用：北信愛、平岩親吉、上井覚兼、片倉景綱、大谷吉継、有馬晴信、片桐且元、本多正信、小笠原貞慶、佐竹義宣、森忠政、小西行長、戸沢政盛、徳川秀忠、毛利秀元、李舜臣、豊臣秀頼、木村重成。各人の NDL ID・Wikidata の固定版・両者の生没年の比較は `appear-authority-batch-2.json` の `yearComparison` に残した。

## 留保

- 須田満親は、NDL の生年が 1537、Wikidata の生年が 1526 で食い違うので採用しなかった。
- 平岩親吉の没年は NDL が 1611、Wikidata が 1612 とする（慶長 16 年の年末は西暦 1612 年に入りうる）。同定は主名と P349 の対応によるので、年の差は根拠に数えない。
- 小西行長・木村重成は NDL に生年が無い。小西行長の Wikidata の生年は 1555 と 1558 の 2 つが並ぶ。どちらも年は同定の根拠に数えない。
- 李舜臣は朝鮮の人物。戦略地図の範囲（日本）とは別に、史実 DB の人物として記録する。
- 原本は `appear-authority-batch-2-raw/` に、Wikidata の JSON（CC0）と NDL の応答 JSON を保存した。
