# 遼東の軍政域参考（1560〜1615年）

遼陽・瀋陽・開原まで未割当陸になっていた表示を、明の軍政域と女真諸部を区別して直すための資料。明の官号・朝貢関係は直轄統治と同一に扱わない。

- [史料台帳と年代判断](../source-notes/manchuria-period-review.json)：15資料、採用・除外理由、実装前の画素診断。
- [図形](liaodong-1560.geojson)：旧軍政域マスク、旧辺牆の4線、寛甸外郭の比較線・期間マスクの7件。
- [登録と精度](registration.json)：対照点9件、未使用の比較点4件、変換方法、元資料SHA。
- [読取点](source-trace-pixels.json)：元図の画素座標。第三者の画像本体は同梱しない。

基本図は[李華彥（2014）](https://ming.cnhis.ncnu.edu.tw/wp-content/uploads/2014/11/ming23_04Lee_full.pdf)の図1（PDF11頁）。劉謙の遼東辺牆研究を整理した図で、後世の配置も含む。図2（PDF12頁）の1565年『全遼総図』を内外関係の比較に用い、1573年以降の寛甸外郭と1621年以降の防御配置を1560年の基幹域へ混ぜない。1565年図の比較は地域概略の根拠であり、1560年当日の測量ではない。

地名記号を[法鼓文理学院の地名規範資料庫](https://authority.dila.edu.tw/place/)の代表点9件へ薄板スプラインで登録した。元座標の表示はGRS67で測地原点の指定はないため、1kmの測地系・代表点の留保付き概略位置として利用し、厳密なWGS84変換とはしない。未使用の4点との位置比較RMSは8.518km。図記号の同定幅も含むため、境界の外部測量精度を証明する数値ではない。基幹域は20km、寛甸は25km幅の概略として扱う。内挿対照点の残差0を精度主張に使わない。

正本へ適用する feature は `ming-liaodong-1560-mask` と `ming-kuandian-1573-1605-mask`。変更できる画素は `unassigned` と `neutral:明` のみで、海・湖・城領は保護する。基幹域の閉鎖用の辺を歴史国境として描画しない。旧明の形が基幹域の外へ張り出す部分は除き、寛甸マスクに含まれる部分だけ当該期間の参考域に戻す。

寛甸の表示期間は `[1573, 1, 1]` 以上、`[1606, 1, 1]` 未満。[増井寛也（2022）](https://www.ritsumei.ac.jp/acd/cg/lt/rb/679/679PDF/masui.pdf)で1603〜1605年の退去過程を確認した。これは年単位の表示用区切りで、元日に全域を獲得した事件や1605年末まで均一に統治したとの主張ではない。撤収期にはその説明を表示し、軍・外交・史実行軍の所有者へ転用しない。

清の柳条辺・近代省境・現代の露中国境は入力にしない。後金建国は1616年、ロシアのアムール進出はゲーム期間後なので、1560〜1615年の国名・領土へ前倒ししない。女真の地域名の表示位置は文字の置き場所であり、確定した領土重心ではない。
