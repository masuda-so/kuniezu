# 江島：江戸期参照形状の年代照合

2026-11-09。G01の部分調査。江島全体を水面に置換する変更ではない。

## 現行正本との対応

`uv run --locked python tools/geo/inspect-ejima-lineage.py` は、原本SHAと以下の位相対応を出力する。地図は書き換えない。

- CODH湖沼原本のrow511（中海）のpart0・内環1。
- `water:codh-lake:511` の同じ内環。
- 陸 `land:baseline:01403`、岸線 `shore:common:01469`。

2026-11-09の実行では、原本内環＝現行内環＝陸、陸の境界＝岸線がそれぞれ成立した。対象の経緯度範囲は東経133.188420789〜133.201111869、北緯35.506954487〜35.517047047。原本備考には1754年からの干拓を再現した旨があり、現行水域は `edo-reference` として1560〜1615年へ適用されている。この対応だけでは、どの区画を戦国期の水面へ戻すかは決められない。

## 読んだ資料と採否

渡辺正巳・平石充（2023）「江戸時代以降の江島埋立て史」『Laguna』30、1–10頁。[DOI:10.60290/laguna.30.0_1](https://doi.org/10.60290/laguna.30.0_1)。本文とPDF4頁の図4を確認した。論文全体・図版をこのフォルダへ転載しない。

同論文は1754年以降の新田造成を時期別に整理する。図4は1962年空中写真へ造成区画を付記した比較図で、16世紀の測量図ではない。図2・3の古図、図4の年代別区画、残存自然島を区別して照合する。図4の日英キャプションで開始年が異なるため、区画の表示と本文を優先して確認する。

伊能図等の単純な拡大縮小では造成状況を読めなかったという著者の検討も踏まえ、古図を現代座標へ無理に合わせない。風土記の周長や現在との面積比から円形の島を生成する方法は採らない。

## 次の地物変更に必要な証拠

図4の位置基準と現行陸の対応点、登録誤差、1754年以前の自然島と後世造成区画の区別を記録した上で、陸・水域内環・岸線を同時に編集する。未登録の図版上の線を測量済みの汀線として採用しない。今回の調査は年代の混在を検出したもので、戦国期湖岸の確定を意味しない。

## 位置合わせの試行と棄却理由

PDF4頁を1272×1800画素へ描画した図4で、近世造成域の四隅を現行輪郭の候補点と比較した。以下の画素値はページ左上原点で手動読取した候補であり、測地基準点ではない。

|候補|図版のx,y（画素）|現行の経度,緯度|
|---|---|---|
|北西折点|263,500|133.19277023622453,35.514584680023894|
|北東角|509,355|133.19823809752594,35.51704704653197|
|東の張出し|579,516|133.20053987849008,35.513017513499896|
|南東角|607,618|133.20111186886177,35.51046521361942|

4点の最小二乗アフィン変換では、当てはめ残差は約0.6・7.3・18.1・11.4mとなる。しかし変換から得る画素寸法は約2.21×2.63mで、図4の500mスケールからの概算約3.0m/画素と整合しない。小さい当てはめ残差だけでは正しい位置合わせを保証しないため、この変換は**編集正本への適用を棄却**した。

Claudeの独立読図では、候補点が海岸ではなく造成区画の境を含み、北東点には1901年までの造成区画が混じるとの指摘があった。目盛りの両端にも読取差があり、概算3.0m/画素は確定値ではない。したがって、この試行をCODH原本の縮尺不良の証拠にしない。

地理院の年代別写真 `ort_old10`（1961〜1969年）と `std` を、東経133.184〜133.206・北緯35.506〜35.526、z15で各9枚取得。18枚とも256画素・取得成功。原本とURL・SHA・透明画素数は無公開キャッシュ `.cache/ejima-reference/manifest.json` に保持した。写真の個別撮影年は未照合であり、レイヤ全体の年代範囲を1962年と読み替えない。[公式仕様](https://maps.gsi.go.jp/development/ichiran.html)に基づく参考写真で、戦国期の汀線ではない。論文写真と共通する堤防・道・自然岸を先に照合してから、年代別の線を写す。

## 写真の模様による独立登録

`tools/geo/register-ejima-photo.py` で図4の写真部分を局所相関し、地理院写真と一致した37点のうち36点をアフィン整合点として得た。固定乱数による外れ値除去後の最大当てはめ残差は2.415タイル画素。手動候補の造成区画線を位置基準として採用したのではない。低い残差は写真同士の一致の証拠であり、戦国期の汀線精度を意味しない。

結果は `photo-registration.json` に、画像のSHA・寸法、参照18タイルのURLとSHA、対応点と相関値、変換行列を保持する。原画像は転載しない。ページ描画は同一寸法が必要で、PDF4頁を単独PDFへ抽出してmacOS Quick Lookの1800画素サムネイルで作成した。別の版・解像度の画像では対応を再検証する。

現行陸をタイルのWeb Mercatorへ直接投影した重ね合わせでは、南西の自然岸がおおむね対応し、北東側に造成地を含むことが見える。記録は `data/verification/codex-ejima-registration/README.md`。これにより、先の区画角同士の不一致を島全体の平行移動や座標系の不良と解釈することは避けられる。次は図4の古田と後世の造成区画の境を登録済み写真上で読み分ける。

## 読み取った区間

`dated-field-boundaries.geojson` は、図4の古田西縁と1819年新田域西縁を合わせて23頂点・2本の開いた線で記録した。元ページ画素を属性に残し、登録行列とタイル座標から経緯度へ変換した。閉じた島ポリゴンではなく、ゲームの陸海判定には使っていない。

Claudeの独立読図と照合し、北側の蛇行した区画線を1754年以前の汀線と断定できない点を残した。西岸・南岸も1960年代写真からの参照であり、戦国期の不変を直接証明しない。図2・3も読図したが、それ自体を近代写真へ無理に変形していない。

線の登録誤差と、古図の解釈・成立年代に伴う不確実性は別である。現状では後者を定量化していない。未読区間を直線で閉じて「戦国期の島」として適用することは避け、追加の地形資料で確認する。
