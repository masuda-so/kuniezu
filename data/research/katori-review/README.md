# 香取海の追加史料確認

2026-11-01。G01の担当継続。湖岸の生成データは今回変更していない。

- 香取市の同じ講演会ページは2026年9月26日の「香取神宮文書とは何か？」へ更新されていた。検索結果に残る2月の講演内容と混同しない。取得状態は `source-access.json`。
- 現在公開されている鈴木哲雄氏の配布資料を `../reference-documents/katori-suzuki-2026.pdf` に保存し、配布元URL・取得日・SHA-256を同ディレクトリのmanifestへ記録した。4ページを確認した。中世文書の解説であり、戦国期の湖岸を確定できる地形図ではない。
- 同資料の津宮の売券は文明5年（1473）、海夫注文は応安7年（1374）。新福寺文書の正木時茂禁制は「永禄3年（1560）ヵ」という年代推定を含む。年代を確定イベントへ無条件で転記しない。
- 都留文科大学の『香取文書調査報告書』2024年は書誌確認と本文読了を分離。今回本文の取得は503/429。13世紀の記述を1560年の精密な汀線に置き換えない。
- 香取市「香取遺産」Vol.33は香取駅付近の自然堤防と古代～中世・近世の遺跡を解説する。現代の低標高域を全て水面とする復元には使えない。
