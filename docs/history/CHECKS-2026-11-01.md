## 起動不要の検証

リポジトリ直下で `node tools/checks/offline.cjs` を実行します。
ブラウザ・HTTPサーバーは起動しません。JSの構文、保存容量エラー、書き出し・取り込み、全7シナリオの保存形式、支城の費用・攻略・占領・収入・中止を検証します。ゲームモデルのみを隔離したNode環境で扱います。

## 実画面の検証（ユーザーが起動を許可した後）

```sh
python3 -m venv .venv-play
.venv-play/bin/python -m pip install -r tools/play/requirements.txt
.venv-play/bin/python -m playwright install chromium
```

ゲームのサーバーを別のターミナルで起動した後に、以下を実行します。検証ドライバー自身はサーバーを起動しません。

```sh
.venv-play/bin/python tools/play/drv.py inv.py
.venv-play/bin/python tools/play/drv.py altall.py
SC=桶狭間前夜 .venv-play/bin/python tools/play/drv.py s10c.py
```

接続先は `GAME_URL`（既定 `http://localhost:8000/index.html`）、撮影先は `GAME_TEST_OUTPUT`（既定 `tools/play/artifacts`）で変更できます。今回、共通ドライバーと `inv.py`・`altall.py`・`s10c.py` を移植しました。その他の古い調査スクリプトには旧環境の絶対パスが残ります。

実画面では次を確認してください。

- 新規開始の3段階案内、閉じる・メニューからの再表示。
- 手動保存・読込、JSON書き出し・取り込みの中止と確定。
- 攻撃・外交・築城の介入説明、年表の記録。
- 本城の支城一覧から攻略、30日後の支配・収入、防御補正、途中の同盟で中止。
- 合戦図の経路ボタンと進行スライダー。PC幅1400とスマホ幅390の両方。

画面の表示崩れ、操作、ファイル選択・ダウンロードはオフライン検証だけでは保証できません。

追加検証：全7シナリオのゲームモデルを各720日進め、城の所有者・兵数・当主・本拠の整合性を確認（ブラウザ・サーバーは起動しない）。

## 依存追加なしのChrome実画面検証

MacにGoogle ChromeとNode.jsがあれば、Playwrightの追加インストールなしで次を実行できます。
サーバーはユーザーが起動・停止します。このコマンドは既存サーバーに接続し、検証専用の一時Chromeプロフィールを使います。普段の保存データには触れません。

```sh
node tools/checks/browser.cjs
```

`GAME_URL` で接続先（既定8000）、`GAME_TEST_OUTPUT` で画像・書出しデータの出力先、`CHROME_PATH` でChrome実行ファイルを指定できます。各実行のJSONは別の出力フォルダへ保存します。

PC 1400×900とスマホ幅390×844で、案内、時間進行・停止、保存・読込、実際のファイル書出し・取込（中止／確定）、支城攻略と保存、合戦図の経路・スライダー、陣跡比較地図、年表位置、JavaScript実行時エラーを確認します。
支城の30日経過は専用プロフィールのテスト状態を進めて再現します。実際に30日分の待ち時間をかける検証ではありません。

## 史実データの棚卸し

`node tools/checks/history-audit.cjs` は、出来事・人物・施設・分岐・全シナリオの領域ノードを `data/audits/history-audit.json` に書き出します。出典未確認を検証済みに変換するものではありません。人物の生年不一致なども別の問題として出力します。人が資料照合を進めるための作業台帳です。

実画面検証には通常軍勢による追加拠点の攻略・撤退、全77件の共通描画、大坂冬の陣と拡大操作を追加しています。攻略時は通常の日次処理を進めて消耗・兵糧・行軍を再現します。
