# 塩津潟の位置付き史料比較

2026-11-03。親担当から独立し、塩津潟の史料・形状だけを調査した。編集範囲は `data/inputs/shiotsu-period-review/` と本報告のみ。

## 判定

- **採用**：新発田市報告58集第1図の干拓前全体輪郭を、位置付きの比較資料として登録。PDFベクトル1,510点を保持した。
- **不採用**：同輪郭をそのまま1560〜1615年の100m精度の汀線としてゲームへ投入すること。2点登録の未使用地点残差は青田35.93m・住吉190.46m・砂山中道下306.45mであり、出典の図自体が特定の戦国年の実測図ではない。
- **不採用**：164集第9図（潟形成前）を戦国期の輪郭に転用すること、1721絵図の開削水路を戦国期へ先取りすること。

## 実装へ渡す具体的な修正材料

1. 現行水面は `labelOnly` で欠落している。旧マスク除去だけを完成扱いにしない。
2. 比較輪郭の対象は北端・地蔵新田〜南西の真野原・宮古木方面で、砂丘沿いと東南の自然堤防を含む旧潟。新発田城は含まれない。
3. 南東の砂山中道下（139.3616667, 38.0097222）と住吉（139.3397222, 38.0008333）は中世集落の位置として保持する。単に旧潟の外周を丸め、これらの微高地を塗りつぶす修正は避ける。
4. 野中土手付（139.3641667, 37.9988889）は古代の集落として別記録にする。年代を無視して「遺跡があるから戦国時代も陸」とする根拠にはしない。
5. `source-boundary.geojson` と `period-controls.json` を次の局所登録・年代別水面生成の入力にする。南西岸の細かな村境状の凹凸まで自然汀線と断定しない。

資料原図、第8〜10図、抄録、原図への抽出線重ね図、国土地理院への同座標重ね図を実見した。画像の読み取りは確認済み。原図の細かな凹凸をゲームへ即座に採用したという記録は付けていない。

参照元・頁・原本SHA・再実行手順は [資料ノート](../../data/inputs/shiotsu-period-review/README.md)。サーバー操作、ゲームファイル編集、コミットは行っていない。
