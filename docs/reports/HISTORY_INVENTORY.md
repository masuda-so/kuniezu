## 状態

- **確定**：出典で確かめた記録がある
- **比較値だけ**：ゲームの値など、出典で確かめていない値だけがある
- **決まらない**：調べたが決められなかった（支配の記録の `undetermined` など）
- **未着手**：何も無い

- 人物の全体は、史実 DB の人物（典拠の登録、命題・所在の記録、作業台帳、ゲームの武将）。改名の前後の名前が別の人物として数えられているものがある（例：松平元康と徳川家康）。名前の結び付けは作業 3 の後半（人物の登録）で整える。
- 城の全体は、ゲームの城（行軍拠点 140 と、施設のうち「城」244）。湊・寺・宿などは除いた。
- 生没と所在は、その人物自身についての記録（主語として結ばれたもの）だけを数える。例えば信康の死の命題は家康を関連人物として結ぶが、家康の没年には数えない。
- 器なしの項目は、入力の器がまだ無いもの（家族・主従など）。0 件と取り違えないよう、数えずに分けて示す。
- 城の出来事の「確定」が 0 なのは、確かめた合戦の命題が城を登録済みの場所の鍵（`place:`）で指していて、ゲームの城と同一性の記録で結ばれていないため。結ぶと数に入る。
- 位置は、出典で確かめた代表点（`site-representative`）だけを確定とし、ゲームの座標は比較値とする。
- 比較値の出どころ：生年はゲームの武将の生年、没年はゲームの年表の死去、所在はゲームの年表の登場・移動、築城・消滅はゲームの施設の稼働期間、持ち主はゲームの年表の城の受け渡し。

## 変更

- `tools/research/export-evidence.cjs`：年表の出来事に、その出来事の人物（`people`）を足す。ゲームの武将の一覧 `implemented-people.jsonl`（名前・生年・初出）を書く。
- `kuniezu/history/importer.py`：年表の出来事に人物を結ぶ。ゲームの武将の生年を、未照合の生年（比較値）として取り込む（記録の種類 `implemented-person`、migration 0007）。
- `kuniezu/history/inventory.py`・`manage.py history_inventory`（新規）：棚卸しの表。`--markdown` で上の表、`--rows` で 1 件ずつの状態。
