# 行軍・駒・合戦表示の修正記録

2026-11-01。既存の8000番サーバーを使用。起動・停止は行っていない。非史実ルート・自由攻城の停止を維持。

## 修正した動作

- 表示時刻を共通化。停止、メニュー、保存復元でも日内の移動位置を保持する。日付変更時には移動終了予測点を引き継ぎ、人物の後戻り・日単位の飛びを抑える。
- 描画と移動が同じ道路線を使用する。屈曲経路が直線へ戻る距離制限を撤去し、詳細道路が未接続なら既存の道路網も検索する。駒の向きは現在地点の街道の接線から算出。
- 凸駒は平面的な兵種表示、左に肖像、右に独立した家紋旗、下に中央揃えの兵数。近接する同じ行軍は遠景で代表隊、近景では街道上の前後に配置する。端点で全隊が同一点に重なる問題も修正。
- 家紋16点の余白・縦横比を共通処理。明智光秀の挙兵・山崎では明智紋と独立した軍色を使用。旗の枠から家紋がはみ出す寸法を修正。
- 古い保存の直線経路を初回読込時に再構築する。日付、領地、兵数、資金、日内時刻は維持。経路更新版は3。
- 合戦地形の準備が整うまで固定寸法の待機表示。粗い図を一瞬表示してから切り替える処理を廃止。地形と背景を再利用し、読込待ち中の再生進行を止める。
- 合戦の描画更新を滑らかにし、移動方向や現在の敵陣へ駒を向ける。桶狭間の信長・元康、長篠の勝頼の段階移動を出典に基づき追加。中間線・演出時間は概略表現であり、時刻別の実測復元ではない。

## 街道・シナリオ

登録82街道を形状点検した。東海道は箱根の中世湯坂道回廊を保持し、他区間には詳細な比較経路を使用。塩津街道の深坂越中心部は長浜市のコース図の経路・縮尺・方位を参照。現代西海道の参照線に混入していた約42kmのフェリー迂回を陸上街道から除去した。出典回廊の錨点を保ち、近接する比較線だけを局所採用する。

7シナリオの開始状態を点検。桶狭間は今川の出陣日である旧暦5月12日から開始し、沓掛到着と翌日の戦場への移動を分ける。本能寺は旧暦6月1日、関ヶ原は家康の大坂出発に合わせ旧暦6月16日から。石山は旧暦9月13日に補正。長篠は資料館の旧暦5月8日の布陣を採用し、5月21日の野戦を分離した。新城市の別ページには5月1日開始の記述もあり、唯一確定した攻城開始日とは扱わない。勝頼本陣は城北約600mという市資料を採用し、約40km離れた地名データの誤候補は棄却した。

開始日の変更は新規プレイに適用。既存保存の年代は移動させない。

## 香取海と史料

旧図との登録比較を維持し、湿地推定形状を直線で切っていた境界を地形に沿う段階的な閾値へ変更。7領域・1389頂点の湿地を生成した。現代標高と旧図を併用した推定であり、3mの閾値と1kmの移行幅は表示上の仮定。旧図登録誤差約4.1kmは精密な戦国期湖岸の確定根拠にならない。

資料PDFは研究用に保管し、出典URL・ハッシュ・用途を記録した。全時代の全人物・全城郭の網羅や、全111合戦の部隊別位置・動線の史実確定を、この修正や構造検査の合格から推論しない。現代道路の参考線、史料にある回廊、推定形状を区別して保存する。
