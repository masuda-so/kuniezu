# 遼東の軍政域参考を正本へ接続

## 変更の範囲

児島湾補正済みの正本（f77817a相当、4入力SHA `46ac0497…`）を土台に、史料担当が読図・登録した [遼東参考GeoJSON](../../data/research/liaodong-reference/liaodong-1560.geojson) を適用した。20〜25km程度の地域概略で、100m格子の分解能を史実境界の精度とはしない。根拠・9対照点・読取点・年代幅は [資料説明](../../data/research/liaodong-reference/README.md) を参照。

正本の `unassigned` と `neutral:明` だけを変更し、海・湖・城領・他の中立地域は保持した。旧明490,115画素のうち325,494画素が1560基幹域内、129,008画素が基幹域外の寛甸参考域、35,613画素が両域外だった。基幹域外の旧明は未割当に戻し、女真等の確定領土へ自動変換しない。

基幹域で未割当→明3,763,736画素、旧明→未割当164,621画素、変更計3,928,357画素。基幹域内の海湖城領等987,328画素と寛甸域内の保護対象1,651画素は変更しない。

## 年代差分

寛甸方面は基幹域へ混ぜず、217,799画素の型紙に分離。`from: key:unassigned` で元が未割当の画素だけへ適用する。

| 表示期間 | 使用する差分 |
| --- | --- |
| 1560〜1572年 | 正本の基幹域 |
| 1573〜1583年 | 寛甸方面 |
| 1584〜1605年 | 寛甸方面＋宇喜多期366画素 |
| 1606〜1615年 | 宇喜多期366画素 |

1573は築堡開始年、1603〜1605は段階的撤収の時期。[1573,1,1]〜[1606,1,1) は年精度の表示区切りで、1月1日の一斉領有変更や1605年末までの均一統治を意味しない。撤収期説明を併記し、軍・外交・行軍の所属へ転用しない。城の所属を変えるイベントは追加しない。

## 生成・検査

1. 行ごとに正本を加工し、全域RGB配列をメモリへ展開しない。変更前の4入力SHAで対象を限定、旧ベクターによる巻き戻し防止は維持した。
2. 正本から100m・400m・800mの251タイル、領域辺、年代別3版を再生成。
3. 独立PNG検査で正本504,753,216画素と100m配信216タイルが一致。未定義色0・相違0。
4. 変更前後の正本全画素を独立デコーダで比較。遼東bbox外の相違0、海・湖・城領等の保護対象の相違0。全変更が未割当↔明だった。
5. 遼陽・瀋陽・撫順・開原・鉄嶺・海州・清河・鳳凰城の代表点は明、義州は以前と同じ `castle:uiju`。
6. 1560/1573/1583/1584/1600/1606/1615の7時点で児島湾の100m2枚・400m1枚・800m1枚が補正済み旧表示とバイト完全一致。宇喜多型紙のpayloadも不変、変更数366を維持。
7. 再適用は書込前に拒否、拒否後の正本SHA不変。province-editsの実PNG回帰検査も通過。
