# 街道参考線の入力品質と棄却記録

2026-11-01。残る大きな閉路を調べ、北国街道の経由点と土佐東部の道の区別を照合した。

## 北国街道

長浜米原観光協会の街道説明と長浜市図書館の調査事例を参照し、木之本・柳ヶ瀬・椿坂・中河内・栃ノ木峠の関係を確認。GSI住所検索、OSM地名検索で同名候補を照合した。GSIの町名代表点をそのまま道路へ吸着すると、柳ヶ瀬山付近へ寄ることがあり、宿場位置とは同一でなかった。検索で正確な地物が見つからず別地域の地名候補へフォールバックした応答も保持し、不採用とする。

自転車・徒歩双方の再照会は過大迂回で不採用。最初の自転車候補は約299.67km、区間によって約60/80/103kmとなり、最大約1.96kmの吸着があった。照合点を変更しても峠周辺の大迂回が残る。現代の通行制約を16世紀の交通路へ持ち込まないため、この候補で公開地図を置換していない。data/inputs/hokkokukaido-review/。

## 土佐東部

林野庁四国森林管理局の野根山街道は奈半利から野根へ尾根伝いに約35km。室戸岬を回る海岸の遍路道とは別。高知県の室戸岬の遍路道図を取得し、1頁を画像化して目視した。赤線は岬の東西と最御崎寺を通る。この図の範囲を県域全体へ拡張しない。原PDF・SHAはreference-documents/manifest.json、ゲームへの図版転載はなし。

現在の「土佐東街道」一本で官道・山越え・巡礼道を表す点は、路線区分と資料の再照合が必要。大閉路135kmを一括削除して古道が復元できたことにはしない。

## 共通の取り込み検査

collect-road-reference.pyにroad_reference_review.pyを追加。全地域に同じ基準を使い、経由地から250m超の吸着・経由地を結ぶ距離の3倍超・2km超の閉路を検出した候補は自動採用しない。しきい値は品質点検の設計で、歴史上の移動距離の法則ではない。

従来は棄却理由だけで形状・区間別情報が消えていた。今後は棄却した候補の形状、元と吸着後の経由点、区間別距離、照会URL・方式を保持し、再調査に使用する。検出だけで史実の支線を削除しない。

現在使用中の81参考線入力を同じ基準で再点検。41本に250m超の吸着記録、49本に2km超の閉路がある（重複あり）。表示側で既に除去した往復も原入力には残る。data/audits/road-reference-inventory.json。原データと公開表示を混同せず、既存の採否を機械的に取り消していない。

road-reference-review.pyで正常な比較線の通過、吸着・閉路の検出、実際の棄却候補保持を検査。収集器はAST構文検査。3資料のメタデータをcurated/sourcesへ保存し台帳へ再出力、29史実命題は増やしていない。今回の結果を16世紀の全街道考証完了とはしない。ゴールactive、サーバー操作なし。
