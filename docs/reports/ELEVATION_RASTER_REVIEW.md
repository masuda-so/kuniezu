# 標高画像の配布方針と出典確認

現行の `game/terrain-tiles.js` は外部の地理院 `dem_png` と AWS Terrarium、一部のローカル概観タイルを読み、ブラウザで標高を復号して陰影を作る。画面用の陰影PNGは開発時に生成し、領域画像と同じ原点・範囲・解像度・タイル番号で配布する案を検討する。標高値の画像と描画用の陰影は用途と再利用性が異なるため、別成果として審査する。

| 入力 | 配布前に確認すること |
|---|---|
| 国土地理院の標高タイル | [利用規約](https://web1.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)に従って出所と加工を明記する。[測量成果の事例集](https://www.gsi.go.jp/LAW/2930-sample.html)は標高データを使った陰影段彩図を第30条の使用承認の対象例とする。[利用手続フロー](https://www.gsi.go.jp/common/000221848.pdf)の陰影表記例もあるため、出力が陰影のみの場合と、測地座標付き標高格子や地形段彩を配布する場合を分け、今回の出力仕様を示して国土地理院に該当性を確認する。非営利だけで申請不要としない。 |
| AWS Terrain Tiles / Terrarium | RGBは符号化方式。AWSの[データ登録](https://registry.opendata.aws/terrain-tiles/)は[Tilezenの帰属表](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)を条件として参照する。[入力資料一覧](https://github.com/tilezen/joerd/blob/master/docs/data-sources.md)にあるように原資料が複数で、ズームと地域によって混ざる。実際の取得範囲・ズーム・取得日・利用可能な原資料識別情報を保存し、対象タイルの帰属と再配布条件を確認する。 |
| Copernicus DEM | Terrarium全体をCopernicusと扱わない。別の入力として採る場合に配布元・製品・版・帰属条件を特定して比較する。 |

陰影生成の条件は、隣接タイルを1画素以上読んで境界で勾配が切れないこと、欠測を海と混同しないこと、日本・朝鮮に同じ勾配と色付けを適用すること。出力マニフェストに入力製品・使用日・出典表記・座標・解像度・NoData・ハッシュを残す。切り替え前に国境・海岸をまたぐタイルの隙間、ズームアウト直後の欠落、主要地点の標高と実画面を検査する。

今回は規約と現行経路の調査。新しい標高画像の取得・配布は実施していない。既存の `tools/map/build-height-raster.py` は保有する標高PNGの格子変換を試すツールで、配布の承認を示すものではない。

## 事前生成の実装

`python3 tools/map/build-hillshade-raster.py <共通格子のmanifest.json> <16bit標高タイルのディレクトリ> <新規出力ディレクトリ>`。PillowとNumPyを使用。既存の配色を使い、隣接タイルの境界画素を参照して勾配を計算する。欠測画素は透明、隣接欠測では有効な片側を使う。経度方向の画素間隔は緯度に応じて補正する。入力格子・標高画像のハッシュと寸法を検証し、出力マニフェストに元の標高マニフェストと画像のハッシュを記録する。

合成標高を1枚と4枚に分けて変換し、端数タイル・継ぎ目・欠測を含む全56画素でRGBA値が一致した。実地の配布画像とブラウザ接続は別工程。

手元にあった早島の地理院標高PNG（Z14・6枚）で、旧格子と拡張作業版の双方に標高と陰影を事前生成した。出力タイル番号は `9-8 → 9-12`、有効な2,360画素と欠測の透明部を含む陰影PNGはバイト単位で一致。Y原点の4タイル移動が描画内容を変えないことを、この範囲で確認した。生成物は一時ディレクトリに留め、配布対象に含めていない。

`build-height-raster.py --provider terrarium` は手元のTerrarium PNGを既存の標高格子と同じ投影・採取処理へ通す。16bit符号化では海底標高も保持できるよう0.5m刻みとし、地理院の0.25m刻みは維持。符号化はマニフェストで判別し、陰影生成器は両方式を同じ処理で読む。リポジトリ内の朝鮮周辺Z6画像1枚から36枚の陰影試験タイルを生成した。別のZ6タイルも入力に加え、ソウル付近の画素で入力復号と出力の差が0.25m以内であることを確認した。Z6入力の細部が100m精度になるという意味ではない。地理院の早島出力は既存版とPNGが一致した。

継ぎ目の再検査は `python3 tools/checks/hillshade-raster.py`。合成データだけを使い、横・縦の境界、端数タイル、境界付近の欠測を含む画像を1枚出力と4枚出力で全画素比較する。ソウル付近の比較値は入力・出力とも61.0m（Z6の画素値）。

標高変換に `--factor 1|4|8` を指定できる。陰影生成は入力の倍率と格子寸法を検証し、その間隔で勾配を求める。既存の早島入力を使った試験では100mで2,360画素、400mで150画素、800mで35画素。
