# 八郎潟の推定湖岸と旧船越水道

湖内の大きな三角形の陸、南西岸の過大な水面、船越側との接続欠落を修正する。中世にも湖が存在した資料と、干拓前の比較図を照合した推定復元であり、1912年の岸を16世紀の精密な岸として確定しない。

## 採用する範囲

| 対象 | 最終候補 |
|---|---:|
| 基準の檜山領色から湖へ | 6,201セル |
| 基準の湖から檜山領色へ | 3,820セル |
| 変更合計 | 10,021セル |
| 近世造成の可能性により陸戻しを保留 | 199セル |
| 旧水道内で保護する中島 | 18セル |
| 局所窓内の八郎潟 | 23,423セル |
| 海・他城・他湖の変更 | 0セル |

南西岸の保留199セルは、史料にある埋立面積ではなく、地名・低地・段丘縁から定めた採用保留区域との重複数。鳥居長根の約400haには原野への引水も含まれ、全てを湖の埋立とはしない。保留セルの湖分類も16世紀の水際の確定を意味しない。

中島18セルのうち12セルは基準からの陸、6セルは比較図による陸戻しであり、全18セルが元画像から不変という意味ではない。

旧船越水道は蛇行する旧流路と中島の内岸を読図し、1962〜1964年の直線新水道を使わない。水道追加前の陸戻し265セルを除き、基準の陸60セルを水面に追加した。養魚場など後世施設の周辺を変更しない対照点は、戦国期の陸の証明に転用しない。

## 正本と再現性

香取海を保持したmainの元画像から、`data/research/hachirogata-reference/pixel-reconstruction.json` の非重複RLEを一度だけ適用する。適用済み画像へ再適用しない。`tools/map/apply-province-runs.cjs` は元色・格子・範囲・重複・件数を検査し、既存出力や生成中の入力変更を拒否して一時ファイルを片付ける。基準と出力のSHAは `source-application.json` に保持する。

比較原図・取得元は `sources.json`、公開GCPと位置合わせは `registration.json`、読図はGeoJSONと画素点へ保存した。近世造成は `edo-review/`、旧水道は `outlet/` に根拠と制約を分ける。元図の全文やHTML本文を重複させず、要約・読図位置・原図の取得情報を保持する。原図画像は研究用の比較入力で、ゲームの背景素材には転用しない。

EPSG:4326の配信図をゲーム格子へ対応させたが、原図の旧測地系・旧経線・独立実測点による誤差は確定していない。四隅GCPの内部残差を地上精度の証明にせず、500m級の慎重な比較として扱う。100m格子は描画の分解能で、歴史資料の精度ではない。公的な湖面積への数合わせは行わない。

## 根拠

- [大潟村「干拓前の八郎潟」](https://www.vill.ogata.akita.jp/encyclopedia/history/2-2.html)：湖の規模、鎌倉時代からの漁業。個別の中世汀線は与えない。
- [東北農政局「地域の歴史」](https://www.maff.go.jp/tohoku/nouson/kokuei/hatirougata/rekisi.html)：1957年度着工、1966年中央干拓地全面干陸、1977年3月完成の区別。
- [長谷紘和・平山次郎『五城目地域の地質』1970年](https://www.gsj.jp/data/50KGM/PDF/GSJ_MAP_G050_06003_1970_D.pdf)、印刷2・4頁、第3図：干拓前の湖底地形。引用文献の1965年を測深年としない。
- [三浦鉄郎「八郎潟東岸平野における開発の歴史地理学的研究」1970年](https://doi.org/10.4157/grj.43.674)、『地理学評論』43(11)、674–685頁：中世・近世・近代の開発差。
- [森岳](https://mapwarper.h-gis.jp/maps/1207)・[船川](https://mapwarper.h-gis.jp/maps/1199)・[深浦](https://mapwarper.h-gis.jp/maps/3672)・[五城目](https://mapwarper.h-gis.jp/maps/3492)：干拓前比較図。制作・測図・補入・発行年代を出典台帳で区別する。
- [堀野一男「寒風山からの湧水を利用した水利開発事業」1988年](https://www.jstage.jst.go.jp/article/journalhs1981/8/0/8_0_160/_pdf/-char/ja)、165頁と引用元の[村井良八『渡部斧松』1915年](https://dl.ndl.go.jp/info:ndljp/pid/980789)、18頁：湖岸への土砂移送。精密な埋立区画は示されない。

## 検査

局所検査では、最終セル数・保留199セル・湖から海への4近傍接続・中島の孤立した18セルを確認した。香取海1,719セル・保護陸70セルと岸線補正、年代差分の半開区間・正本ハッシュ・原子書込みの検査も通過した。海と湖の界面は既存の境界生成器が岸として描かないため、実岸を隠す追加マスクは不要。

正本と配信の全体照合も通過し、最終候補の実画面3ズーム・旧水道の水面・中島の陸地の対照点は例外0で合格した。独立担当も別実装でRLE・連結・島・保留区域を確認した。詳細は `data/verification/codex-hachirogata-water/README.md`。画像・動画をGitへ含めず、地図の生成物もコミットしない。生成後の `raster-province-pixels.json` は正本ハッシュと一致するものを提出する。
