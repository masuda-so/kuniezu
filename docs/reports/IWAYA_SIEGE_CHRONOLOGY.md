# 岩屋城の戦いの再生順

『上井覚兼日記』の天正14年7月26日条は下柵突破と包囲を、27日条は朝の攻撃と午後の落城を記す。合戦図にこの3段階を設定し、島津方の推定接近経路を外した。城内の区画や高橋紹運の戦死時刻はこの記述から特定できない。[鹿児島県編『鹿児島県史料 旧記雑録後編二』第166号、205–208頁](https://www.pref.kagoshima.jp/ab25/documents/6756_20221201091952-1_1.pdf#page=92)

『史料綜覧』は7月26日条に落城と紹運の戦死を掲げる。既存命題 `death-date-takahashi-joun` と、日記の2日分の命題を別々に保持した。合戦図の経過には日記の記述を採り、年表の落城イベントは現行の1586年9月10日（旧暦7月27日相当）を維持した。[東京大学史料編纂所 大日本史料総合データベース](https://wwwap.hi.u-tokyo.ac.jp/ships/w61/search)

史料台帳、配置、部隊移動、読み込み確認値の検査が通過。専用Chromeで再生バーの0・45・100％を操作し、日付・本文・史料リンクを確認した。[画面検証の記録](../../data/verification/codex-iwaya-chronology/README.md)
