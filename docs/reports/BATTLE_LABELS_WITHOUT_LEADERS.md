# 合戦図の引き出し線を削除

2026-11-08。人物名と駒を結ぶ線を全表示方式から削除した。
部隊の地理座標・経路・個別IDは維持し、名札だけを近距離の空き位置へ配置する。
城郭図・模式図も同じ配置処理を使い、城郭名や見出しを避ける。

同一の記録地点かつ実際の表示位置が1px未満で一致する場合だけ、
個別に選択できる名前欄を共有する。別地点の隊はまとめない。
名前を収められない場合は、駒を選択した際の部隊一覧で各人を確認できる。
選択した駒を強調し、未選択隊の軌跡は描かない。

## 検証

- `battle-label-cards.cjs`：全合戦1,390フレーム、名札同士の非重複、引き出し線0、部隊位置維持。
- `battle-mode-labels.cjs`：城郭図・模式図36ケース、194選択。伏見守備7隊の個別選択と注記を維持。
- `battle-counter-density.cjs`：1,390フレーム、388隊選択、同地点130選択を確認。
- 専用Chrome：関ヶ原・長久手・設楽原・伏見城・木津川口を940px／335pxで確認。
  肖像の重なり、部隊選択、選択前後の座標、周辺表示への切替を検査。

実画面の記録は `data/verification/codex-counter-label-no-leaders/` と
`data/verification/codex-counter-label-modes/`。この検査は描画・操作の検証であり、
各合戦の歴史的配置の正しさを追加で証明するものではない。
