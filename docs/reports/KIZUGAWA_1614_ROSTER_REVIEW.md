# 木津川口・1614年の参加武将と出典

2026-11-02。蜂須賀至鎮だけだった攻撃側へ、浅野長晟・池田忠雄を追加した。根拠は黒田日出男「徳川美術館蔵『豊国祭礼図屏風』の注文主」PDF4頁の旧暦11月19日の記述。蜂須賀が先に攻略した経過も本文へ反映した。論文は笠谷和比古の研究を参照しており、同時代の原史料そのものとは分けて保持する。

従来の大阪城天守閣リーフレットは全6頁を実見したが、今回の木津川口3将の記述を裏付けるものではなかった。1576・1578年の海戦の鳥羽市資料とも分け、1614年の専用出典へ接続した。大阪歴史博物館の共同研究報告32〜34頁の木津城・集落・浜堤の記述も補助出典として登録。木津城と河口砦の同一地点や精密持場を断定しない。

入力原本・図版・本文抽出・SHA・確認できる事項と確認できない事項は data/inputs/osaka-kizugawa-review/source-manifest.json に保持。game/battle-event-catalog.jsの3将・2出典を、battle-deployments.jsの既存読込へ渡した。複数出典を持つ追加合戦に対応し、従来の単一出典も維持する。

## 河口地形の照合

- 大阪歴史博物館の[共同研究成果報告書17、第2章第1節、32〜34頁](https://www.osakamushis.jp/education/publication/kyodokenkyu/pdf/kyodo-17/kyodo-17_3.pdf)は、中世木津集落が木津川河口から東に延びる入江に面したと推定する。木津集落・後の鼬川・浜堤は地形を照合する手掛かりになる。1614年の河口全体を測量した図ではなく、砦の地点も確定しない。
- 南秀雄「発掘からみた中世大阪の沿海開発―難波砂堆」[大阪市文化財協会研究紀要23、15頁](https://sitereports.nabunken.go.jp/files/attach/67/67513/141849_1_%E5%A4%A7%E9%98%AA%E5%B8%82%E6%96%87%E5%8C%96%E8%B2%A1%E5%8D%94%E4%BC%9A%E7%A0%94%E7%A9%B6%E7%B4%80%E8%A6%8123.pdf)のBM18-1次調査では、元禄期に干拓された津守新田の調査地点で、それ以前の浅い潮下帯・潮間帯の環境を推定している。この地点は戦国期の恒常的な陸地として塗る根拠にできない。調査地点の結果を津守全域へ外挿しない。
- 大阪歴史博物館の[木津川河口の遊里を描いた屏風の解説](https://www.osakamushis.jp/news/2009/tenjigae/0908223.html)は、1650年前後の三軒家と推定する。冬の陣後の復興期の景観であり、1614年の岸線をそのまま転写する用途には適さない。

専用Chromeで確認した現行背景の直線は、合戦図が共通地図の陸地マスクを拡大したもの。調査地点と旧集落の位置を同じ縮尺で照合し、時期を絞った入江・浜堤・潮間帯の根拠が揃った範囲から別レイヤーにする。以上の史料で得られたのは地形の制約であり、現段階では新たな岸線の座標は追加していない。

### 図22の位置合わせに使う情報

所蔵PDFの第6ページ（冊子33頁）を長辺1250pxで描画し、図22の記号と縮尺を目視した。図の黒四角は中世の作土、白四角は近世以降の作土、黒丸は古代の作土、白丸は時期不明。作土の時期は各調査地点の土地利用を示すため、白四角の地点すべてが1614年に水面だったとは判定できない。

| 津守新田の調査地点62（BM18-1次） | 干拓前の潮間帯・浅い水域の観測。図中の白四角を、津守全域の水域境界として扱わない |
