# 沿岸5地域の工事年代を史実DBに登録

東京湾・大阪湾・濃尾平野・中海／宍道湖・十三湖について、8件の調査入力から15の命題を登録した。ゲーム期間内は日比谷、江戸、木曽川の3件。残る12件は後世の比較記録で、ゲーム年代へ繰り上げない。工事の開始、許可、完成、中止を分け、旧暦月や年度の精度を原資料のまま保持する。

[地域別の資料ノート](../../data/research/source-notes/coastal-period-review/README.md) に採用範囲を記録した。斐伊川の東流年代の異説は資料ノートに保持し、確定年や河道線には変換していない。原本15件は私有アーカイブへ保存し、SHA-256とサイズを照合した。公開するのは書誌・要約・確認値。

史実DBの書き出し後、SQLiteとJavaScriptで120記録・283検索を照合した。暦・期間入力とキューブCLIの検査も合格。今回の対象は調査台帳と検索で、画面に表示される年代や地図の画素の変更はない。
