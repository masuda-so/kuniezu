# 地域共通の地形描画

2026-11-01。ユーザーの日本・朝鮮・今後の地域を共通アルゴリズムにする指示を適用。

- 河川：投影済み座標を標準入力にして、長さ・境界を一度計算。両地域で同じ画面外除外、7px未満の省略、1.1pxの線幅、最大2pxの角の丸めを使用。描画用Path2Dは同じ縮尺で再利用する。地域ごとの描画関数を廃止。
- 標高：日本のGSI陰影画像の着色を廃止し、GSI DEM PNGを使用。0.01mの符号付き標高へ復号し、Mapzen Terrariumの復号後と同じ陰影・着色・投影処理へ渡す。データ取得先と符号化形式が違っても、同じ高さは同じ色になる。無効標高の隣に崖を作らず、無効画素は透明にして下の画像を残す。日本の標高解像度を粗い全体画像へ固定して共通化したのではない。
- 領域と海岸：地域IDによる分岐を除き、全領域はChaikin2回、海岸は1回の表示処理。元データを書き換えず、政治区分の史実精度が改善したとは扱わない。

国土地理院の詳細仕様 https://maps.gsi.go.jp/development/demtile.html を確認。RGBの符号付き計算、無効128/0/0を実装・検査。帰属表示とDATA_SOURCESも更新。

common-riversで337入力線の長さ・可視性、丸め、Path2D対応を確認。common-reliefで正負標高・無効値・欠測周辺・異なる形式から同一陰影になることを検査。terrain-transitionで中間層、部分読込、地域移動、取消を再検査。

専用Chromeの日朝同倍率の画像を data/verification/common-regional-rendering/ に保存し目視。国土地理院DEMが読み込まれることを明示的に検査し、単なる全球フォールバックで成功扱いにしていない。例外0。観察時は両地域で8秒後の待機・取得中が0。全111合戦や全期間を再検証した結果ではない。

この変更は描画算法の共通化。朝鮮の行政区分の史料照合、海岸の基礎データ、城施設の拡充、街道の閉路候補等は継続ゴールの対象。サーバー操作なし。
