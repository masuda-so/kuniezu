# 合戦関連の年表注記4件の分類

`history-date-review.js` が追加した注記4件に、合戦図または年表イベントの分類がなかったため、既存の布陣検査が停止していた。全noteを検査対象外にせず、岩石城の落城、鍋島勢・毛利勢の安濃津攻撃、大友義統の降伏だけを既存の分類表へ登録した。既存の年表・史跡表示を変えるものではなく、分類情報の欠落を補う。

岩石城は年表と史跡地点、安濃津の2注記と石垣原の降伏は既存合戦の経過として扱う。個別部隊の配置を作らず、既存の111場面・原暦・換算日・出典・史跡座標を維持した。

根拠は添田町『歴史的風致維持向上計画』第2章2-38頁（https://www.town.soeda.fukuoka.jp/uploaded/attachment/2309.pdf）、竹田憲治・三重県埋蔵文化財センター『関ヶ原の戦と三重の城郭』PDF5頁（https://www.pref.mie.lg.jp/common/content/001067704.pdf）、別府市『べっぷの文化財No.44』印刷1頁（https://www.city.beppu.oita.jp/doc/gakusyuu/bunkazai/booklet/no44.pdf）。再照合は既存出典の出来事を確認するもので、新しい部隊位置や経路を採用しない。

専用検査 `node tools/checks/battle-event-classification.cjs` は全合戦関連イベントの分類と4件の原暦・出典・既存場面対応を確認する。小さな開始状態に実エンジンで岩石城の注記だけを適用し、年表と史跡が残り、近隣の領主を変えず架空の合戦図を再生待ちへ入れないことも合格した。実年代を進める既存deploymentsの検査は保持した。

全deploymentsは分類修正後に別件の高天神城の表示範囲不足を検出する。これは変更前からの範囲設定による問題で、別候補で修正する。本変更はUI描画を変えず、実画面全体の改善完了を意味しない。

追加点検で、既存の木津川口の4隊は経緯度ではなく攻撃順序の模式図なのに、検査が経緯度または位置不詳欄だけを受け入れていた。模式表示の明示、全参加者の経路、有限な正規化座標、0〜100の時刻と昇順を検証して第三の既存表示方式を認める。経路欠落・表示指定欠落・範囲外・逆順・非数値は拒否する回帰5件が合格した。ゲームの表示や地理座標は変更しない。
