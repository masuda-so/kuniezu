## 確かめていないこと

- ライセンスの原文と、各機関の利用規約は読んでいない。
- Commons のページを 1 件ずつ目で開いてはいない。API が返す表示（ライセンス・作者・出典・日付・カテゴリ）から
  機械的に分類し、疑いのある 4 件だけ個別に判断した。
- 「そのまま配信可」の 142 行は、Commons の Public domain・CC0 の表示が正しいことを前提にしている。
  原画の制作年代や作者の没年は、1 件ずつは確かめていない。
- `tools/faces/raw/` の画像が、記録（meta.json）のファイルから取得したものかどうかは、バイト列では照合していない。
- 米国での扱い（Commons が補足のタグを求めているもの）は見ていない。

## 作り方

`tools/faces` の記録（meta.json・low.json・added.json・reviewed-portraits.json・fallback-crops.json）と
`data/audits/portrait-audit.json` から Commons のファイル名を引き、Commons の API（`prop=imageinfo` の
`extmetadata` と `categories`）で 158 ファイルの表示を取得した（2026-11-11 08:01 UTC）。表に保存したのは、
ファイル名・URL・ライセンス表示・作者・出典・日付・説明の先頭・投稿者・ライセンスにかかわるカテゴリである。
画像そのものは新しく取得も保存もしていない。
