# 年表の「領有 take」を綱文で照合する（第 1 便、10 件、2026-11-09）

利用者の指示「データベースを拡充させて」。年表（`TK.HIST`）の「領有 `take`」101 件（題名あり 62 件）を、史料編纂所「大日本史料総合データベース」の綱文で照合する。Codex と合意して 5〜10 件ずつに分ける。この便は、1566〜1581 年の単独の城の攻防 10 件。

照合の手順：年表の日付を暦表で旧暦に直し、その月と前の月の綱文を全件取り、城名・人物名を含む条を拾った（七尾城は範囲の外の 9 月だったので、城名で年内を引き直した）。

## 分けたこと

- 綱文の語に合わせて、落城（陥る）・降伏（降す）・明け渡し（致す）を別の述語にした。明け渡しの述語 `castle-handover` を新しく足し、`kuniezu/history/importer.py` で衝突（CONFLICT）に分類した（試験も追加）。
- 綱文が落城の語を使わない 2 件（小谷城＝攻城と自害、岩村城の奪還＝城将の捕縛と処刑）は `military-event` にし、落城の日としない。
- どの命題も、綱文の日付を城域全体・郡や国の支配の移り変わりへ広げない（各命題の `eventScope`）。

## 対象の場所と人物

- 台帳の場所を 9 つ足した（`curated/places/`：箕輪城・月山富田城・稲葉山城・掛川城・岩村城・小谷城・七尾城・三木城・鳥取城）。座標は主張しない。
- そのうち 8 つに、ゲームのノード（`node:minowa` など）が代表する同一性の記録（`represented-by`）を足した。名前の同じ別の対象を作らない。
- **鳥取城**には記録を作らなかった。ゲームの `node:tottori` の名前は「布勢天神山城」で、鳥取城とは別の城。年表の「鳥取の渇え殺し」は `node:tottori` を使っているので、ゲームの側の対応は確かめが要る（報告のみ、ゲームは変えていない）。
- 人物は既存の ID だけに結んだ。綱文に出る吉川経家・美濃三人衆などは人物の ID が無いので結ばず、新しく作っていない。

## 検証

- `export-evidence.cjs`：命題 177 件（main の 167 件＋10）。
- 隔離 DB で `import_history`：10 件とも `conflict`。同一性 36 件（＋8）、名前による座標の借用は 0 件のまま、代表の点 26 件（＋8）。
- 各検査・`pytest`・`ruff`・`mypy` の結果は PR の説明に書く。

綱文の日付は編纂上の掲出日で、関連史料の本文は読んでいない。検査の合格は、合戦・城の攻防の全件の網羅を示さない。
