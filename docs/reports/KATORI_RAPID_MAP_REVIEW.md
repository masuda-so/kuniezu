# 香取海の同縮尺比較：迅速測図

2026-11-02。農研機構の位置合わせ済み迅速測図を、既存の共通タイル取得器・重ね図作成器に追加した。現代標高から生成した推定湿地を、出典年代の明らかな古地図と直接比較できる状態にした。

## 入力と座標検査

- 対象：東経140.36〜140.66、北緯35.81〜36.03。霞ヶ浦南端・北浦南端・浪逆浦・佐原周辺。
- 迅速測図1880〜1886年と地理院標準地図を、ズーム13の同じWeb Mercator画素へ配置。各56枚、計112枚。全枚取得、SHA-256照合。
- 農研のタイルは南起点のTMS。通常のXYZ行番号をそのまま使わず、`2^z - 1 - y` へ変換する。提供元KMLの1タイルの四隅と計算した緯経度との差は最大2.85e-14度。これは配信画像の投影確認で、原図の測量誤差が消えたという意味ではない。
- 迅速測図には72,900画素の完全透明部分があった。取得失敗ではなく原画像の未収録部分として灰色で保持した。画像が届いたことと全画素に史料があることを区別する。

入力と画像は `data/inputs/katori-rapid-review/`。`validation.json` に検査、`manifest.json` に年代・許諾・全タイルURL・SHA・透明画素数。`sample-tile.kml` は提供元の座標範囲。`runtime-comparison-lines.json` は比較時点の24輪郭で、青が現代比較湖岸、赤紫が既存推定湿地。これは新たな戦国期汀線の入力ではない。

## 画像を確認した結果

`rapid1880-controls.jpg` を実見した。現代比較の霞ヶ浦・北浦の主要な岸と、明治図の台地側の岸を同じ位置で読める。一方、南側の低地には明治図の広い流路・島・小水域と、現代低地からの推定湿地輪郭との相違が見える。既存推定の一部の直線状の辺も確認でき、古図からの読図線と混同しないよう比較対象として保持した。

この相違をすべて戦国期の陸水差と扱わない。[香取市の解説](https://www.city.katori.lg.jp/culture_sport/bunkazai/isan/141-150.html)は、利根川東遷後の土砂堆積と新田開発を説明する。明治までの変化があるので、古図の水域をそのまま1560年へ貼り付けない。次は原図上の地名・島ごとに輪郭と開発年代を対応させる。実行時の湖岸・領土・城域は今回変更していない。

## 再現

Pillowを使えるPythonで、リポジトリ直下から実行する。

```sh
python tools/geo/collect-era-map-tiles.py data/inputs/katori-rapid-review 140.36 35.81 140.66 36.03 13 rapid1880 std
python tools/geo/overlay-era-controls.py data/inputs/katori-rapid-review data/inputs/katori-rapid-review/runtime-comparison-lines.json
```

元から対応するGSIの1974〜1978写真・標準地図も同じ処理を利用し、地域ごとの別描画算法は追加していない。重ね図作成器は点に加えて線を描けるようにした。

出典：**農研機構農業環境研究部門**「第一軍管区地方2万分1迅速測図原図」／[CC BY 2.1 JP・利用案内](https://habs.rad.naro.go.jp/habs_faq.html)。画像を接合しゲーム内輪郭を重ねて加工した。現代図は[国土地理院・地理院タイル](https://maps.gsi.go.jp/help/use.html)。提供元FAQの位置精度は誤差の大きな所で約100m、元縮尺1:20000。

## 治水年代による採用条件

ユーザーの2026-11-02の補足に従い、関東平野では「古図だから採用」ではなく、河道・堤防・干拓地ごとの成立年代を検証する。1590年や1603年に一括して現在地形へ切り替えない。対象期間1560〜1615年の途中に工事がある場合は、その段階だけを反映する。古図上の岸、湖、島、自然堤防、人工堤防、農地を分け、明治の水際を戦国期の汀線と見なさない。

[関東農政局「水をめぐる混乱」](https://www.maff.go.jp/kanto/nouson/sekkei/kokuei/ryoso/rekishi/03.html)は江戸初期の瀬替えによる流入水の変化を説明している。原図が明治期であることに加えて、描かれた水域が東遷前後のどちらかを照合する。[利根川下流河川事務所の概説](https://www.ktr.mlit.go.jp/tonege/tonege_index016.html)にも同じ変化の解説があるが、本文の「天正8年（1590年）」は年号と西暦が不一致なので、工事の実施年をその記述だけから登録しない。概説・工事記録・原図の役割を分けて確認する。
