# 1534年を扱うための共通暦の拡張

ゲームと史実DBが共用する`koyomi.js`の月初表を、旧暦1532〜1623年へ広げた。
1532年から含めるのは天文改元等の参照余地を確保するためで、開始シナリオの追加や
全期間の人物・領土の登録とは別の変更。

manakai/data-localeの固定版`052d97b256648fa42f060bca855c0c3f5bd66913`から、
月初の元の行だけを抽出して保持した。元全日ファイルのSHA、抽出入力のSHA、
利用条件の説明文も保持。生成器は通信せず1138月を再生成し、全ての隣接月が
29日または30日であることと、既存853月の絶対JDNが変わらないことを確認する。
原点を早め、差分を非負に保つので既存DBの読取形式を変更しない。

元データの先発グレゴリオ暦を、ゲームの改暦前ユリウス暦と混同しない。
1534年旧暦5月1日の元データと絶対日を比較し、そこから11日後がゲームの
西暦1534年6月23日になることをDB側の暦関数で検証した。

全体CIで、1534年の綱文を暦表外として扱う旧テストが一件失敗した。
日付のある綱文は新しい表で換算できるため期待値を更新し、未分類であること、
年だけの綱文に日精度・確定した境界を付けないことも確認した。
対象取込テストと暦テストは合わせて20件通過。取込処理自体は変更しない。

`node tools/build/build-calendar.cjs --check`、asset stamps、差分検査を通過。
`tests/test_history_dates.py`は追加した早期日付とDBでの旧853月の読取を含め19件通過。
ruffと`node tools/checks/offline.cjs`も通過。全7シナリオ、保存・移動の継続性を
確認し、検査が出力した監査JSONは証拠側へ保全して元に戻した。
