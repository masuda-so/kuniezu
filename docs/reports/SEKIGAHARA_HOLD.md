# 関ヶ原の不参戦隊に対する汎用前進の除去

## 根拠と挙動

毛利秀元・吉川広家・安国寺恵瓊・長宗我部盛親・長束正家には、本戦で動かなかったという資料と矛盾する敵方向への汎用前進が付いていた。役割の文章から推測せず、対象IDごとに出典付きの待機方針を持ち、模式経路や史料の地点移動がないときだけ汎用前進を止める。明示された経路・寝返り・退却を上書きしない。

根拠：岐阜県・岐阜関ケ原古戦場記念館『関ケ原合戦ガイドマップ 決戦編』1頁・下段の経過。https://sekigahara.pref.gifu.lg.jp/wp/wp-content/uploads/2024/03/a8fd5bc45fff52ca3707e4149652f5e8.pdf 。当日実測図や分単位の記録とは扱わず、既存の代表配置点を維持する。戦後の退去経路・時刻を新しく作る変更ではない。
