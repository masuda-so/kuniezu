# 遠景の行軍駒の向き

2026-11-01。街道の密な折れ点に対して、ズームによらず前後0.6地図単位だけで向きを求めていた。遠景では見えない蛇行にも凸駒が回転する。

表示する位置の前後を画面上12px相当（地図単位0.6～60）参照して向きを算出する。位置・行程・到着日・時計は変更しない。時間依存の遅延補間は使わず、停止中も同一の入力なら同じ向きになる。近景の前後配置には、その表示地点を使用。経路ごとの空間索引を再利用し、毎フレーム全頂点を走査しない。

`distant-heading.cjs`で蛇行、拡縮、反転経路、ゼロ長、位置不変を検査。合成蛇行の角変化総量は75.432→1.162rad（約98%減）。これは実際の全軍の統計ではない。専用Chromeで起動中の1560シナリオを遠景・近景で描画、例外0。画像と結果は `data/verification/distant-heading/`。サーバーは操作していない。

この修正は向きの微振動が対象。全街道の史実照合や全軍の全期間の見え方の完了を意味しない。継続ゴールはactive。
