# 六十里越街道の図間にある仮接続

庄内と内陸の調査図を結ぶ約4.58kmの直線は、近世以前の道路を確認した区間ではない。1933年刊の「左沢」図幅と同縮尺で重ねると、この直線は図中の川沿いの道路から離れ、尾根と谷を横切る。同図幅には近代道路の改修も含まれる。[左沢図幅](https://mapwarper.h-gis.jp/maps/1129)

全国地図では六十里越街道を二つの描画区間に分け、この直線と、その上に載る可能性のあった街道名を外した。両側の点列は保持した。現地測量で確認された弓張茶屋跡周辺とダム建設前の道筋を結ぶためには、さらに位置合わせが必要。今回は表示上の訂正で、行軍の経路選択や既存の保存データは従来の形状を使う。[弓張茶屋跡の現地測量報告、107–112頁](https://www.iccp.jp/wp-content/uploads/2014/09/21371f2f7168e28fae813dc580c83bc8.pdf)

全読み込み順で表示区間の端点と元の点列を照合し、専用Chromeで描画命令を確認した。[実画面検証](../../data/verification/codex-rokujurigo-gap/README.md)
