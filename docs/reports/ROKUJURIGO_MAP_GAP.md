# 六十里越街道の図間にある仮接続

庄内と内陸の調査図を結ぶ約4.58kmの直線は、近世以前の道路を確認した区間ではない。1933年刊の「左沢」図幅と同縮尺で重ねると、この直線は図中の川沿いの道路から離れ、尾根と谷を横切る。同図幅には近代道路の改修も含まれる。[左沢図幅](https://mapwarper.h-gis.jp/maps/1129)

全国地図では六十里越街道を二つの描画区間に分け、この直線と、その上に載る可能性のあった街道名を外した。両側の点列は保持した。現地測量で確認された弓張茶屋跡周辺とダム建設前の道筋を結ぶためには、さらに位置合わせが必要。今回は表示上の訂正で、行軍の経路選択や既存の保存データは従来の形状を使う。[弓張茶屋跡の現地測量報告、107–112頁](https://www.iccp.jp/wp-content/uploads/2014/09/21371f2f7168e28fae813dc580c83bc8.pdf)

全読み込み順で表示区間の端点と元の点列を照合し、専用Chromeで描画命令を確認した。[実画面検証](../../data/verification/codex-rokujurigo-gap/README.md)

行軍表示の追試では、尾浦―山形と山形―本庄の城間経路に同じ直線が残る。全7シナリオを開始日から1615年12月30日まで、連続移動の計算を有効にして計88,089日進めた。稼働中の軍勢の現区間と表示用経路、史料に基づく部隊の経路、武将の移動経路に、仮接続の両端を結ぶ線分は見つからなかった。既存の保存データと、端点が異なるほかの未確認区間は検査範囲外。

## ダム建設後の復元道との区別

国土交通省が掲載した現地事業報告の印刷5頁「街道の復元整備（ダム水没区間の復元）」を確認した。本道寺地区では、補償対象の区間とは別に約800mを復元整備の対象とし、2008年度の現地調査とルート選定を経て散策路の整備を進めていた。添付略図は歩行可能・消失・復元予定の各区間を区別する。このため現在の散策路を一括して旧道へ置換する根拠には使わない。次に線を採用する際は、復元・補償区間を区別し、ダム前の図面と現地調査の共通点で位置を照合する。[国土交通省「風景街道 活動事例」印刷5頁](https://www.cgr.mlit.go.jp/cgkansen/fukei/pc/pdf/best/best.pdf)
