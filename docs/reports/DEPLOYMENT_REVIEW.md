## 表示から漏れていた合戦を含めて111件に統一

従来の79件という集計には、二種類の欠落があった。

- 名前の判定で「海戦」「干殺し」「兵乱」等が落ち、兵数表に存在する13件が表示されていなかった。閑山島・鳴梁・露梁、三木・鳥取、御館の乱などを追加。
- 年表にあるのに兵数表にない19件も表示されていなかった。牛久保、掛川、手這坂、第一次・第二次木津川口、戸次川、玉浦、岐阜城、真田丸などを追加。

現在の表示対象は **111件、480名・隊、283群**。個人名の分からない勢力名も480件に含む。同じ人物が別の合戦へ登場するため、480人の固有人物を意味しない。位置を持つ群は220、位置不詳の群は63。部隊の所在地、城全体、戦闘地域の代表点は区別し、全群を精密な本陣座標と扱わない。

`battle-catalog.js` は兵数表の登録を題名で除外しない。`battle-catalog-extra.js` と `battle-event-catalog.js` で不足する両軍・関係者・地理範囲を補い、`battle-deployments.js` で全図を同じ表示形式へ変換する。旧模式図の移動用座標を史実の陣地として転用していない。

年表の合戦・攻城等の名称も別に検査し、未表示または除外理由のない記録が残ると検査が失敗する。「粟之巣の変」は死亡事件として年表へ、「大坂冬の陣の和睦」は冬の陣の終結へ統合する。題名のない支配変更を根拠なく新しい合戦として作らない。

## 街道・湖岸・海岸

- 会津中街道は[那須塩原市](https://www.city.nasushiobara.tochigi.jp/soshikikarasagasu/nomuchikusanka/1/sateraito/13137.html)が1695年の開削を説明しているため、1560〜1615年の街道から除外。活動中の街道は82本。
- 朝鮮の関東路は、忠州へ向かっていた旧折点を、漢城・楊平・砥平・原州・安興・平昌・珍富・大関嶺・江陵の回廊へ修正。[九叱峴古道の国家遺産指定資料](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=&flSeq=112375543)の1530年記録等を参照した。31の折点は概略の通過地で、全区間の旧道中心線を復元したものではない。
- 朝鮮の海岸はGSHHGのhighからfullへ更新。**2,336輪郭・128,835頂点**を使用し、海戦図と全国地図へ共通反映。以前は2,228輪郭・24,566頂点で、海峡を拡大すると大きな直線になっていた。原資料は現代の比較海岸であり、干拓前の戦国期海岸ではない。
- 霞ヶ浦の白地修復と比較湖岸を維持。[国土交通省の説明](https://www.ktr.mlit.go.jp/kasumi/kasumi00771.html)から、現在に近い姿は江戸中期で、17世紀の水系変化も考慮すべきことを追加。8世紀の面積2〜3倍という説明を戦国期へ流用して、巨大な湖を描くことはしていない。

霞ヶ浦周辺で無名の多角形に見えていた飯沼・見沼・椿海も再照合した。[坂東市の飯沼新田資料](https://www.city.bando.lg.jp/page/page002762.html)と[千葉県の椿海干拓史](https://www.pref.chiba.lg.jp/ap-kaisou/kaisou/kibanseibi/higata.html)は、対象時代より後の干拓を説明する。水域を削除するのでなく、旧輪郭を概略・湖岸未確定と明示した別レイヤーに移した。[さいたま市図書館](https://www.lib.city.saitama.jp/contents?5=&pid=133)によれば、見沼の溜井化は1629年なので、1560〜1615年は沼沢地として区別する。既存の少数頂点の輪郭は史料から精密復元したものではない。全国地図・合戦図の両方へ同じ区分と名称を反映した。

## 地図移動の負荷

地形だけでなく、海・領域・街道・境界・湖を一度合成し、小さな移動では周囲160画素を含む画像から等倍で切り出す。ズーム、画面幅、領主、主従、同盟、交戦記録、年、選択、表示方式、標高取得状態が変わると作り直す。領主交替を古い画像のまま隠さない。大画面では画像の面積を制限する。

海の青海波、山地の細部、各家の色を減らして速度を上げたものではない。全体の文字フォントが取得できないとタイトルが出ない問題も修正し、代替フォントで起動・操作できるようにした。

読み込み中の再測定では、画像1枚ごとの再合成と座標変換の繰り返しにより、移動の処理時間が大きく増える問題も見つかった。`terrain-tiles.js` は、表示に使う同倍率の画像群が揃った時だけ更新する。画像の座標変換は64回の部分画像転送から、緯度に応じた画素補間と1回の書込みへ変更。タイル1枚ずつの継ぎはぎ表示を防ぐ既存仕様を保持し、画面外の読み込み完了だけでは再合成しない。

処理時間は、同じ1400×950・霞ヶ浦周辺・倍率5・24回の移動について、地形の読み込み完了を確認してから比較する。最初の0.345秒という測定と、その後の取得中3.917秒は条件が揃っていなかったため、最終比較値として使用しない。変更前の `ui.js` と `terrain-tiles.js` は専用ブラウザ内だけで読み込みを差し替え、ユーザーのゲームファイル・サーバーを巻き戻さない。FPSや全端末の性能保証ではない。

最終比較は**変更前1.804秒 → 変更後0.319秒（約82％減）**。ブラウザの `TaskDuration` を各1回測定した値。データは `data/verification/deployments/performance-before.json` / `performance-after.json`。移動24回すべてで合成画像を再利用した。取得済み画像数と表示更新回数は、変更前261枚／261更新に対し、最終版353枚／4更新。余白を増やしたため取得範囲・枚数は異なる。取得できなかった画像には既存の親画像・別の標高データを使い、取得待ちが0になってから計測した。取得失敗の原因別内訳は未集計。


起動時のファイル読み込みを依存順へ統一し、通信失敗だけ最大3回まで再試行する。失敗したまま後続を実行して空白画面になることを防ぎ、理由と再読み込みボタンを表示する。実行中の例外は副作用の重複を避けるため再実行しない。専用ブラウザで一時的な通信失敗、継続的な失敗、スクリプト実行エラー、再読み込み後のゲーム復帰を再現して確認した。並行検証時に発生した初回の読み込み欠落の通信原因そのものは特定できていない。

## 検証と見直し範囲

以下の検査を通過。ブラウザの通常操作でJavaScript例外なし。検証用の読み込み失敗は専用プロフィール内でのみ発生させた。結果一覧は `data/verification/deployments/results.json`、代表画像も同フォルダへ保存。地形や海岸を変えずに同倍率で描画を再利用し、領主・同盟・年・関係表示・選択の変更時に更新される検査も通過。

- `deployments.cjs`：111件の両軍、480名・隊の一意な所属、位置の範囲、出典登録、年表との表示網羅性、再構築、日付訂正、実際の城の所有者変更。
- `atlas-regressions.cjs`：111件の地形、参加家、北条選択での桶狭間の非表示、旧保存の設定、本能寺旧地、戸田の異名重複。
- `battle-review.cjs`：全図のID・語り・登録出典、戦役45名、伏見落城と戦死・再生、岐阜城の日付と長期戦の再生時点。
- `offline.cjs` / `map-history.cjs`：構文、保存失敗時の保護、7シナリオ各720日、今川・元康、甲州・山崎、北畠の継承、旧保存の出来事の読み位置。
- `march-audit.cjs`：1560〜1615年の20,010日を通過。201行軍・125イベント名に不連続な経路や無効な座標なし。通過路の史料照合とは別の検査。
- `deployments-browser.cjs`：111図の読込と部隊・名簿の対応、320／390／820幅、伏見・三木・金ヶ崎・海戦の狭幅、選択、地図合成の再利用・所有者等の変更時の更新を実画面で検査。
- `completion-browser.cjs`：手動保存、37日経過後の自動保存と復元、メニュー、全図、狭幅の上部表示、自然終了後の閉鎖を検査。
- `army-zoom-browser.cjs`：近い軍勢の集約→拡大して個別表示、同位置の隊の一覧、各隊の選択、縮小して再集約を検査。
- `startup-browser.cjs`：ファイルの通信失敗とコードの実行失敗を区別し、再試行・依存先の停止・再読込後の復帰を確認。
- `font-browser.cjs`：外部フォント配信を遮断した状態で、タイトルとゲームが表示・操作できることを確認。

今回の変更で、**表示対象の欠落を補い、全図を同じ形式で読めるようにした**。一方、全人物・全施設・全イベント・全国の古地形・全街道について史実の全面照合が完了したとの意味ではない。全軍の日々の持場・移動時刻、田辺・永禄・岩屋の出発地と行軍経路、甲州旧領6拠点の個別明渡し、全国湖岸の時代別復元などは、まだ確定資料が揃っていない。`data/audits/history-audit.json` と `data/audits/march-audit.json` は未確認を未確認のまま保持する。人物台帳の斯波詮直の生年（1546／1560）の異同も未解消として残す。

自由攻城・非史実ルートはユーザー指定の保留を維持。史実観察の保存データを非史実へ移さない。歴史訂正は既に通過した日付を旧保存へ強制再適用しないため、開始時から訂正後の経過を見る場合は新規シナリオを使用する。
