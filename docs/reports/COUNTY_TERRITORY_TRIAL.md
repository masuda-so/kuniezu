# 支配の記録の試行（東海、10 城）

`docs/designs/county-territory.md` の PR 5。PR 4 で作った支配の記録の形を、東海（三河・遠江・美濃・伊勢・信濃南部）の 10 城で使い、形の過不足を確かめた。

## やったこと

新しく史料は読んでいない。既に綱文などで確かめた命題（`data/research/curated/claims/`）のうち、城の持ち主が替わったことを述べるものを、支配の記録に写した。記録の `claim` に元の命題、`checked` に元の命題を確かめた日を書き、`checkedBy` に「写した」ことを書いた。

## 分かったこと

1. **記録の形は足りた。** 10 件で、項目の追加は要らなかった。PR 6（史実 DB への取り込みと書き出し）は、この形のまま進められる。
2. **ゲームの年表と日付が合う。** ゲームの年表 `TK.HIST` の同じ城の受け渡しと、ユリウス通日で比べた。

   | 城 | 結果 |
   |---|---|
   | 稲葉山・懸川・岩村・高遠・岐阜（1600） | 同じ日（差 0） |
   | 三河吉田 | **年表が 256 日遅い**（年表 1565-4-10「三河平定」、綱文 永禄7年6月20日）。PR 7 で記録が年表を置き換えると、吉田城が早く徳川に渡る |
   | 大河内 | 年表は 8 日前に「大河内城の戦い」で北畠が織田に従う（`submit`）。記録は北畠の保持。従属は持ち主を変えないので食い違いではない |
   | 高天神・馬伏塚・横須賀 | 行軍拠点でない城。年表に受け渡しが無く、持ち主は周辺施設の規則（`G.yOwner`）で決まる。PR 7 で初めて記録が効く |

3. **出典の要旨に渡した家が無いことがある。** 岩村・高遠は、要旨が攻めた側しか述べないので `from` を `unknown` にした。区間の導出は受けた家（`to`）だけを使うので困らないが、前の記録とつながるかは確かめられない。
4. **家の単位に当てにくい勢力がある。** 1600 年の岐阜城を落とした東軍は、徳川家に従う諸将の連合。ゲームの家の単位では徳川家に当て、`uncertainty` に書いた。関ヶ原前後の記録は同じ判断が多く要る。
5. **ゲームの城に無い城がある。** 松ヶ島城（`matsugashima-handover-1584`）は、ゲームの城の一覧に無いので記録できなかった。年表の「松ヶ島城の戦い」は別の城（`kiriyama`）を受け渡している。城の一覧の見直しの候補。
6. **年だけの記録は窓になる。** 馬伏塚城の観察は年だけなので、持ち主の根拠にしない（窓）。横須賀城の築城も年だけの変化で、旧暦の天正6年の全体が「切り替えの幅」になる。

## 作業量

既存の命題からの写しなので、1 城あたり数分（選ぶ・家を当てる・要旨を書く）。新しく綱文を引いて登録する作業の量は、この試行では測れていない。新しい史料からの登録は、別の試行で測る。
