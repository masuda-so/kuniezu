# 六十里越街道の旧道図抽出（2026-11-02）

国土交通省酒田河川国道事務所の庄内・内陸の現地調査図を保持し、青い旧道線だけを抽出した。緑・橙の国道112号は対象にしない。庄内7区間353点、内陸1区間395点、計748画素点。庄内は国道との交差で青が消えるため、全区間を無理に接続する方式をやめ、欠落区間を保持する方式とした。写真・文字で覆われた部分も補間しない。2枚の重ね図を実見し、抽出線が青線上にあることを確認。

内陸図では村山（旧楯岡）・東根・天童・寒河江の駅記号4点を国土地理院の駅検索結果へ合わせた。自治体代表点や同名の長野県村山駅を誤採用しない。当てはめ残差RMS1.9595px。ただしこれは独立精度ではなく、各記号の中心選択には5pxの幅を持つ。旧駅位置の変遷、当てはめに使わない地点、庄内図の接合を確認するまでゲームへ反映しない。

鶴岡市の説明では、松根・十王峠・大網・塞ノ神峠・田麦俣・大岫峠・志津・本道寺・寒河江を経由する。国交省の戦国期の記述では1587年の最上義光の庄内進攻での利用を確認。年譜には当時の起終点・駅に関する記述もあるが、全欄の年代対応を無検証で採用しない。現地調査図が直ちに1560〜1615年の全経路確定を意味するものではない。

入力・抽出線・重ね図・候補変換は data/inputs/rokujurigo-review/。再現は tools/geo/rokujurigo-map-trace.py、rokujurigo-map-register.py。ゲームの線と保存経路版11は変更していない。次は独立基準点と庄内側の図面接合を確認し、経由地の時期を照合して道路へ組み込む。ゴールはactive。

独立照合追補：羽前長崎駅の図上記号を別に読み取ったところ候補と26.96pxの差があり、8pxの読取り幅を超えた。候補はrejected-independent-controlへ変更し、ゲームへ不採用。駅の移転と記号同定を見直す。独立検索応答と結果は同入力フォルダに保持。
