# 密集した合戦駒の局所表示

選択隊だけを原寸へ戻す処理が、隣接する隊を再び隠していたため、選択中も周囲と同じ密度に応じた大きさを維持する。選択は金枠・前面描画・選択欄の肖像で示す。

選択欄の「この周辺を見る」で、その隊の位置を中心に局所表示へ切り替える。位置・隊ID・行動・再生時刻は変えず、「全体」で元の範囲に戻れる。同地点の隊は選択候補を保持し、別の位置にずらさない。図解には局所倍率を適用しない。

検証：全111合戦・1320フレーム、388選択、130の同地点候補を検査。専用Chromeでは関ヶ原・長篠を940px／335pxで表示し、選択前後のサイズ維持、局所拡大・全体復帰、時刻・座標・候補の保持、狭幅ヘッダの収まりを確認した。JavaScript例外は0件。画面証拠は `data/verification/codex-battle-counter-focus/` に保存。
