# 人物典拠10人の追加

既存の人物調査で同定した10人を、Wikidataの固定版と接続した。対象と照合根拠は [資料ノート](../../data/research/source-notes/person-authority-expansion.md)、各QID・固定版・原URL・照合2項目は同名JSONに保持する。取得したEntityDataを別JSONへ保管しSHA-256を照合する。

人物の登録数は59から69。人物典拠の追加で史実命題・所在観測は増やしていない。塩津潟のPR #60を取り込んだ後の入力は、史実命題109件・所在観測22件。人物レコードを年ごとに複製せず、既存の対象別索引・典拠ID・別名の検索を利用する。親族・役職・戦役による同定結果は、独立した日付や所在の命題を増やす根拠にしない。

趙英圭と建国期の同名人物を区別し、盧蓋邦の役職も釜山市の説明と突合した。日本語ラベルがない2人に、取得値を装った日本語ラベルを補わない。曖昧さ回避ページを人物IDとして登録しない。後半10人はAPIの429で取得を止め、十分な根拠がない候補は登録していない。

史料入力・人物所在の入力・共通索引の検査、353件のJS/SQL比較が合格。Djangoの全入力保持と全別名の人物同一性の2試験が合格した。ゲーム実行時のコード・肖像・地図・行軍には変更がなく、この変更で実画面検証を行ったとは扱わない。

PR #60との統合ではREADMEの両方の説明を保持し、curatedから再生成した。人物69件・史実命題109件・所在22件で449件のJS/SQL比較が合格した。
