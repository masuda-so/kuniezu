# 地図の向きを明治「大日本全図」に合わせる（2026-11-04、Claude）

利用者の要望：北が真上でない、思い描いた向きの日本地図にしたい。手本は利用者がウィキペディア「日本地図」で見つけた明治初期の「大日本全図」（1880 年頃、Geographicus 提供、Wikimedia Commons、パブリックドメイン）。利用者の判断：「大日本全図を参考にしたい」「お任せします。理想の形になるように」「旧平面＋回転」（円錐図法は取り下げ、地図平面は従来のまま回転だけを足す）。

## 呼び名

「北が上でない地図」に固有の名称は無い。地図の上がどの方角かという性質は **方位（orientation）** で、北上・南上・東上のように呼ぶ。上が真北からずれている図は「図北（図の上方）が真北から何度か」で表す。作る操作は **地図の回転（map rotation）**。江戸期の国絵図のように上下を定めない描き方は **四方対置**（礒永和貴「絵図の方位表現」2007）。

## 手本の読み取り

- 大日本全図の経緯線は装飾的で一定の図法ではない（2 組の線は直交するが、どちらを経線と見ても陸地の向きと合わない）。角度は格子からでなく、陸の形で合わせる。
- 本州の軸（鹿児島→津軽半島の先端）は図の上から約 28 度（画素から測定、±2 度）。本作の平面（経緯度に比例、基準緯度 36 度）では同じ軸が 39.3 度。差は **11 度**。
- 昭文社「卓上版日本全図」（ランベルト正角円錐図法）は同じ軸が約 32 度で、回転は 7〜8 度。
- 手本は東北を実際より細長く立てて描くので、軸だけで合わせると東北が手本より寝て見える。

## 海岸線全体での合わせ込み（採用：16 度）

1 本の軸ではなく、本州・四国・九州の海岸線全体で合わせた。
- 手本：Wikimedia Commons の原寸画像（3,580×5,000 画素）をブラウザの canvas で 1/8 に縮め、海岸に沿って引かれた水色の彩色（b > r+12、g > r+8、b > 170）を取り出した（全画素の 2.2%）。経緯線は装飾なので使わない。
- 本作：本線の配信タイル（800m 段）から陸を取り、本州・四国・九州（北緯 30.9〜41.6 度、東経 129.3〜142.3 度、対馬を除く）に限って、陸の点 510 と、陸の外側 2 セル（約 6km）の海の帯の点 461 を旧平面の座標で用意した。
- 当てはめ：相似変換（回転 θ・拡大 s・平行移動）で本作の点を手本の画素へ写し、「海の帯の点が水色に乗る割合 − 0.5 ×（陸の点が水色に乗る割合）」を最大にした。θ は 0〜30 度を 1 度刻み、s は 1.5〜2.2 画素/単位、平行移動は 40 画素刻みの全探索の後、3 段階で細かくした。
- 結果：θ = **16.5 度**（反時計回り）、s = 1.79 画素/単位、得点 0.211。角度ごとの最良値は 14〜18 度で平らな山（0.18）、11 度で 0.15、0 度で 0.07。重ねた図（`data/verification/claude-map-orientation/fit-overlay-16deg.jpg`）で九州から東北まで海岸が手本に乗る。
- 既定値は整数に丸めて 16 度。11 度は「本州の軸だけ合わせる」として残す。

手本自体が歪んでいるので完全には一致しない。合わせ込みは本作の正しい形を保ったまま、手本に最も重なる向きを選ぶ。

## 実装（game/ui.js、game/index.html）

- `U.mapRotation`（度、北を上から反時計回りに回す。既定 16、`localStorage` の `tenka-maprot`）。表示設定の「地図の向き」で 0（北が上）・16（大日本全図の向き）・11（本州の軸だけ合わせる）・25（本州を立てる）を選べる。
- 画布 `#base`・`#top` を回転のぶん大きくして画面の中心に置き、CSS の `rotate(-θ)` で回す。描画の中身（タイル・線・塗り）は回さずに描くので、継ぎ目や粗さが出ない。
- 画面の中心（パネルを除いた所）は画面の座標で決めてから画布の座標へ回し戻す（`vcCalc`、画面の矩形は `vcs()`）。入力（押す・なぞる・滑車）は画面の座標を画布の座標へ逆に回す（`evXY`）。なぞりの移動量も回す。
- 文字は `fillText`／`strokeText` を包み、回した画布へ載る文脈（画布・層・下図の控え）で、変換が回っていない時だけ画面で読める向きに戻す。道の名のようにわざと回して描く文字はそのまま。合戦図や書き出しの画布は対象外。
- DOM に置く軍勢の案内・布陣の札・選択した城の寄せは、画布の座標を画面の座標へ回して配置し、画面の外かどうかも画面の範囲（`VPW`／`VPH`）で判定する。画面レイアウトの判定（`narrowSel`・`mobsel` など）も画面幅で行う。
- 右上に北の印（`#northMark`）を出し、同じ角度で回す。
- 経緯度→画面の変換は従来の一次式（`G.PJ`）に回転を重ねるだけで、史実 DB の実座標との往復は厳密に逆算できる。

## 確認

実画面（worktree を 8001 番で配信、`data/verification/claude-map-orientation/README.md`）：既定の 16 度で全域・畿内の拡大とも塗り・境界線・街道・城が一致し、城名・大名の札は読める向き。伊達政宗の札を押すと名生城が選ばれ、側面の板に合わせて中心が動く。検査：`offline.cjs`・`organization.cjs`・`infrastructure.cjs`・`stamp-assets --check` PASS。
