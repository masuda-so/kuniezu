# 地図の向きを明治「大日本全図」に合わせる（2026-11-04、Claude）

利用者の要望：北が真上でない、思い描いた向きの日本地図にしたい。手本は利用者がウィキペディア「日本地図」で見つけた明治初期の「大日本全図」（1880 年頃、Geographicus 提供、Wikimedia Commons、パブリックドメイン）。利用者の指示「大日本全図を参考にしたい」「お任せします。理想の形になるように」。

## 呼び名

「北が上でない地図」に固有の名称は無い。地図の上がどの方角かという性質は **方位（orientation）** で、北上・南上・東上のように呼ぶ。上が真北からずれている図は「図北（図の上方）が真北から何度か」で表す。作る操作は **地図の回転（map rotation）**。江戸期の国絵図のように上下を定めない描き方は **四方対置**（礒永和貴「絵図の方位表現」2007）。

## 手本の読み取り

- 大日本全図の経緯線は装飾的で一定の図法ではない（2 組の線は直交するが、どちらを経線と見ても陸地の向きと合わない）。角度は格子からでなく、本州の軸（鹿児島→津軽半島の先端）で読む：図の上から約 28 度（画素から測定、±2 度）。実際の方位は約 39 度。
- 昭文社「卓上版日本全図」（ランベルト正角円錐図法）は同じ軸が約 32 度で、回転は 7〜8 度。北海道がさらに回って見えるのは円錐図法の経線の寄り。
- 本作の円錐図法の平面では同じ軸が 38.9 度。手本に合わせるには反時計回りに **11 度**。

## 実装（game/ui.js、game/index.html）

- `U.mapRotation`（度、北を上から反時計回りに回す。既定 11、`localStorage` の `tenka-maprot`）。表示設定の「地図の向き」で 0（北が上）・11（大日本全図の向き）・20（本州を立てる）を選べる。
- 画布 `#base`・`#top` を回転のぶん大きくして画面の中心に置き、CSS の `rotate(-θ)` で回す。描画の中身（タイル・線・塗り）は従来どおり回さずに描くので、継ぎ目や粗さが出ない。
- 画面の中心（パネルを除いた所）は画面の座標で決めてから画布の座標へ回し戻す（`vcCalc`）。入力（押す・なぞる・滑車）は画面の座標を画布の座標へ逆に回す（`evXY`）。なぞりの移動量も回す。
- 文字は `fillText`／`strokeText` を包み、変換が回っていない時だけ画面で読める向きに戻す。道の名のようにわざと回して描く文字はそのまま。
- 右上に北の印（`#northMark`）を出し、同じ角度で回す。

## 確認

実画面（1400×900、`data/verification/claude-map-orientation/README.md`）：全域で本州の軸が 27.9 度、城名・大名の札は読める向き、伊達政宗の札を押すと名生城が選ばれ、側面の板に合わせて地図の中心が動く。検査：`offline.cjs`・`organization.cjs`・`stamp-assets --check`。

## 残り

- 城の記号や家紋の絵は地図と一緒に 11 度傾く（文字だけ戻している）。気になれば絵も戻す。
- 「天」を東西南北に切り替える（90 度単位）も同じ仕組みで足せるが、今回は入れていない。
