# 人物典拠18名の追加

2026-11-09。mainの人物典拠91件へ、既存ゲームに登場する18名を追加し109件とした。A群10名とB群8名を別担当が照合し、相互の読取レビューを経て採用した。人物の同定と名前の対応だけを追加し、生没・所在・所属や名乗り開始日の命題を創作しない。

対象は堀秀政・堀秀治・島清興／島左近・田中吉政・鳥居元忠・前野長康・中村一氏・高山右近・石川数正・柴田勝家・筒井順慶・筒井定次・蜂須賀正勝・家政・至鎮・九鬼嘉隆・長宗我部盛親・香宗我部親泰。[A群の読書ノート](../../data/research/source-notes/authority-batch-a.md)、[B群の読書ノート](../../data/research/source-notes/authority-batch-b.md)に採用範囲と除外名を記録した。

Wikidataの原本18件とNDLの原本11件の人物型・revision・主名／採用別名・対応ID・SHAを照合した。NDLが確認できない人物に番号を補わず、自治体・博物館の人物紹介で補助照合する。後者は現代の解説であり、当時の古文書本文の確認とはしない。B群の自治体HTML原本3件はgzipで別保存し、読む情報はMarkdownへ整理した。CC0の記載はWikidata原本だけの範囲とし、NDLや自治体資料へ拡張しない。

島清興と島左近は両典拠の名前対応で一つの安定IDへ結び付ける。蜂須賀至鎮の幼名など、自治体とWikidataで食い違う名前は追加しない。堀父子、筒井の順慶／定次、石川の数正／康長を名前の類似で統合しない。未採用の別名や異説を検索名・歴史上の日付へ転記しない。

## 検証

- `evidence-store.cjs`、`history-index.cjs`、`location-store.cjs`で原本・同定と索引を確認。
- 既存58件と追加18件、計76件の人物取込試験が合格。別名・安定ID・外部IDが一意に結び付き、別人物のレコードを作らないことを検査した。Ruffと対象Pythonのmypyも合格。
- 分離したローカルRDBへ3,452記録を取り込み、19表記が18安定IDへ一意に結び付くことを読み取りSQLで確認。phenomenonは1,449、participationは972のまま。
- 史実命題155件・所在22件、実装イベント・施設の入力はmainとバイト一致。人物同定追加を全登場人物の所在照合完了とは扱わない。
