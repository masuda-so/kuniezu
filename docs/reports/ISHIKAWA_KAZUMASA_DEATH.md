# 石川数正の死去を文禄元年の精度で登録する（2026-11-09）

Codex の依頼（4 人の死去の照合）の残り 1 人。#112 で登録した 3 人に続き、これで 4 人の区切りとする。

## 調べたこと

- 綱文（大日本史料総合データベース）：「石川數正」「石川数正」「數正」のほか、別名・官途名の「石川康輝」「石川吉輝」「石川出雲守」「石川伯耆守」で検索した。死去の条は無い（別名では 1 件も当たらない）。
  - 文禄元年3月18日 第1条（史料綜覧 編11・冊912、350頁）：千石秀久とともに名護屋へ向けて京都を出る。
  - 文禄元年12月13日 第1条（同、374頁）：秀吉が子の康長に「亡父」数正の信濃松本の封を継がせる。
  - この 2 条から、死去は文禄元年3月18日（暦表で 1592-04-29）より後、12月13日（1593-01-15）までと読める。
- 松本市（国宝松本城）の公式年表『松本城の歴史（年表）』：文禄1年の項に、名護屋への出陣とともに数正の死去を記す。月日・場所・死因は書かれていない。
- 松本市教育委員会『史跡松本城保存活用計画』（PDF）も文禄元年の死去を書いているとの検索結果があったが、ファイルが大きく本文を読めなかったので出典にしていない。

## 登録したもの

- 出典 `matsumotoCastleChronology`（`curated/sources/`）。
- 命題 `death-date-ishikawa-kazumasa`（主体 `person:ishikawa-kazumasa`、既存の人物 ID）。
  - 時間は `described-period`（`文禄元年（天正20年）`、暦 `Japanese-era-description`）。旧暦の文禄元年は暦表で 1592-02-13〜1593-02-01 にまたがるので、西暦の年に置き換えず、検索用の年を 1592・1593 の両方にした。境界は史実上の始まり・終わりと主張しない（`boundsAreHistoricalStartEnd: false`）。
  - 月日は補わない。綱文の 2 条から読める範囲は不確かさの欄に書くだけで、日付にしていない。
  - 文禄2年とする説もあるが、この命題では扱わない。

## ゲームとの比較

ゲームの死去年の表（`TK.DEATH_Y`）には数正の年が無い。年表の扱いは年表の担当に渡し、この変更ではゲームのデータに触らない。
