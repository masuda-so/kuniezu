# 現行方針と受入条件の同期

旧受入条件には朝鮮・明の戦略地図、画像正本の恒久維持、エージェントのサーバー操作禁止が残っていた。利用者が決めた日本限定の戦略地図・改変済みGeoJSON正本・許可済みローカルポートの運用へ揃え、戦役と局地戦、年月と対象からの参照、史実着陣日の維持を明記した。旧文面と登録数・当時のHEAD等は履歴へ全文保存した。

20要望のID・担当区分・優先度とactive状態を維持する。方針の変更を、作業の完了や史実の全件照合の完了として扱わない。現在の対象カタログは棚卸しのスナップショットであり、歴史上の全施設や全人物の網羅を示さない。

`build-catalog.cjs --requests-only` は要望行だけを同期する。既存IDと順序、1506件の非要望行、担当state・claim・完了証拠を変更せず、元の生成日と方針更新日・SHAを分ける。全対象の再棚卸しとは区別する。

検証：同期前後のID・非要望行不変、欠落・重複・未登録要望の拒否、入力非改変、同期済みの再実行を検査した。方針SHA確認と構成・担当競合検査も合格。独立レビューで阻害指摘なし。画面やゲーム状態を変える変更はないためブラウザは起動していない。
