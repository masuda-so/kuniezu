# 対象年代を1534〜1615年へ広げる

2026-11-09の利用者指示により、次の大型アップデートまでの対象を信長誕生から元和偃武までとする。対象年代を1534〜1615年として台帳へ明記し、ゲームと史実DBの両方を拡張する。

H01・H03・H06の受入へ、追加期間の存在・人物候補・1534年の開始状態・連続進行・時の帯・保存互換を追加した。要望同期で既存の対象ID・非要望行・担当・完了証拠を変えない。対象別の行は棚卸し当時の記録とし、最新の対象年代は上位要望を参照する。将来の全件生成ではperiodを読む。

実装上はengineの過去再生がs1560を起点とし、uiの時の帯も1560年開始、終了は1615年6月10日となっている。地理の有効期間と人物・領有の初期状態も追加期間で照合する必要がある。この変更で1534年開始を利用可能とは記載せず、日付や状態を創作して埋めない。

Codexは開始シナリオ・表示・保存と通常配信確認、Claudeは人物候補・史実DB収集を担当する。Wikiの一覧は候補の入口とし、全史実人物の網羅・重複ゼロとは扱わない。

検証：既存1526対象のIDと全非要望行が変更前と一致、完了state3本を変更せず保持、requests-onlyの同期と照合、work-policy、差分検査が通過した。過去の完了証拠を追加期間の実証と読み替えない。
