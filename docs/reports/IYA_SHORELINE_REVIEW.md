# 中海南岸・揖屋の昭和干拓地を湖面へ戻す

国土交通省『中海・宍道湖の環境管理計画』図3-3-12（誌面59頁）の1947年と2018年の汀線、1956年と2006年の空中写真で造成域を確認した。地理院の1961–69年オルソと現代地形図を同じ縮尺・XYZ座標に置き、造成域と造成前の水面が重なる箇所を読図した。干陸調査は揖屋の強制排水開始を1974年10月とする。

- [国土交通省・図3-3-12](https://www.cgr.mlit.go.jp/izumokasen/iinkai/ryuiki/econet/bukaivol6/files/05_shiryo2.pdf#page=60)
- [国土地理院・タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)
- [足立ほか「干拓地土層の農地化過程」](https://www.jstage.jst.go.jp/article/jjsidre1965/56/12/56_12_1203/_pdf/-char/ja)

[画素差分](../../data/research/iya-shoreline/pixel-reconstruction.json) を既存の100m格子に適用し、月山富田の管理色319画素を中海の湖IDへ変更した。変更部はすべて既存湖と4近傍でつながる。元と候補の全画素照合で指定外の変更は0、河川正本との重複は0。隣接する港や江戸期新田は範囲外。昭和造成部の除去であり、戦国期の精密な汀線には他の資料が必要。

最新mainの正本移動後も元PNG・投影の一致を確認した。台帳更新後に既存の年代差分を再生成し、揖屋の配信タイルを100m・400m・800mで319・20・4画素、周辺対照4点を100mで検査した。

専用Chromeでは、湖の区画IDが正しくても陸色になる別の不具合を再現した。陸地マスクと湖色を含む下地が同じ描画キャッシュキーを使っていたため、キーを分けた。[実画面記録](../../data/verification/codex-iya-shoreline/README.md) では中海・宍道湖が水色に戻ることと、揖屋の区画判定を確認した。

中国四国農政局の揖屋地区資料でも、昭和38年度以降の中海干拓事業の工区で、包括面積323ha、本堤2,658mと確認した。包括面積は事業の集計範囲であり、319画素の採否や戦国期の汀線を面積合わせで決める根拠には使わない。100m・400m・800mの補正画素数をそれぞれ319・20・4として検査に固定した。[中国四国農政局「揖屋地区」](https://www.maff.go.jp/chushi/kj/tyutyo/photo/photo_iyakantaku.html)
