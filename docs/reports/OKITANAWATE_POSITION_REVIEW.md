# 沖田畷・有馬本陣の表示位置

2026-11-02。旧点130.373,32.798は地理院標準地図でも海側に位置した。単にゲームの海岸線が粗いためではなく、「海岸方面」へ置いた代表点自体の照合が不足していた。

島原市文化財調査報告書第14集『森岳城跡』本文2頁（PDF18頁）は、有馬方本陣を後の森岳城付近とするが位置不明と明記する。同市文化財課の[解説](https://www.city.shimabara.lg.jp/rekishi/page2793.html)も森岳を本陣としている。本文は丸尾城に猿渡越中守を置いた伝え、1792年崩壊による市街地の地形変化も記す。現在の島原城の建物・縄張を1584年のものとして転用しない。

有馬隊を「森岳方面・有馬本陣」に変更し、地理院標準地図z15、28250/13221の丘の図記号から読んだ代表点130.36656,32.78984へ修正した。約100mの読取幅であり、当日の本陣を精密確定した点ではない。報告書原本・該当頁画像・市解説・地図9タイル・旧新座標・SHAは data/inputs/okitanawate-review/ に保持する。地理院検索で島原城の完全一致が得られなかった市代表点は不採用とした。

battle-deployments.jsに2出典を追加。地形・部隊表示本体はClaude担当のため編集していない。japanLandはwater-evidence.jsでlandから切り出した配列で、日本の海岸精度が別物という当初の仮説は誤りだった。マスク切替案は撤回済み。

## 検証

- atlas-regressions / deployments：全111件の構造、範囲、出典、重複なしを確認。
- okitanawate-position：旧点が現行海域、新点が陸域、森岳の表示と位置精度注記を確認。
- 専用Chromeで0/50/85%を保存し例外0。中盤画面で有馬隊の陸上表示を実見。data/verification/okitanawate-position/。
- 全合戦の海岸マスク外の代表点16群を data/audits/battle-coast-points.json へ棚卸し。水軍を含むので全て誤りとせず、陸戦・海戦・当時の地形を分けて点検する。

ゴールはactive。サーバー起動停止なし。日本全土の海岸の精密化、沖田畷の各将の詳細持場まで確定したとの意味ではない。
