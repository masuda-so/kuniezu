# 登録漏れの肖像3人を表示へ接続する

伊東義祐・龍造寺政家・高橋紹運は、旧生成入力に原画がある一方、現行の顔表示へ登録されていなかった。公開原本を取得し、人物名と資料説明を照合して顔中心の共通128px正方形へ切り出す。原本・SHA・crop・出典を入力として保持し、生成器で配信画像と `portrait-layout.js` の専用ブロックを更新する。

古い全件生成器の `/home/claude` を前提とする経路を使わず、この3人だけを低負荷で再生成する。既存の肖像・別名・spriteを上書きせず、スクリプトの読込順やUIの描画処理は変えない。主画像取得に失敗した時も、生成した別形式の共通セルを既存ローダーから使えるようにする。

原画の採否と利用表示は [入力の説明](../../data/inputs/reviewed-portraits/README.md)。長野業正は既存の白黒写真が登録されているため、今回の欠落3人には数えない。全人物の肖像網羅・顔貌の真実性をこの追加で証明しない。

確認：生成器の `--check` によるバイト一致、128pxセルと代替WebPの画素一致、原本SHA相違・範囲外crop・出力先重複・既存名・既存画像・代替画像の上書きの拒否、既存5人のfallback再現、既存ローダー検査を実施。専用Chromeの実ページで通常取得・主画像失敗・両画像失敗の3条件を検査し、各3人×3サイズの表示を確認した。通常と代替は9画像、両方失敗時は9件の文字表示となり、別人の画像を流用しない。JavaScript例外0、画像取得の同時数は最大2。生成器・既存fallbackの試験を含むpytest 11件、Ruff、追加試験のmypyも通過した。[実画面検証](../../data/verification/codex-reviewed-portraits/README.md)。
