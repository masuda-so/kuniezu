# CODHベクター参照入力の取得と準備

利用者の2026-11-07の指示に従い、江戸期地理データセット4種の公開GeoJSON5表現を取得した。取得物を可逆圧縮して原本SHA・HTTP更新情報・出典・個別利用条件とともに保持する。概要・クレジットは [入力README](../../data/inputs/codh-edo/README.md)、新しい移行方針は [設計](../architecture/codh-vector-map.md)。

`tools/geo/codh_reference.py` は原本を検査し、経緯度のGeoJSONと出典manifestを新規ディレクトリへ生成する。元属性・null・別々の地物を保持し、行番号のfeature.idを版内の参照として付ける。取得SHAが変われば別の観測版として扱い、行番号を恒久的な城・水域IDにしない。

海岸1888地物は線版で、object_idは全て同じ。閉じていない列やnullがあるため、陸の面へ自動変換しない。湖沼点1551行には異座標の重複IDがあり、面は573件だけ。街道47地物には本州・北海道の離れたR200があり、宿場90路線のうち54路線には線がない。宿場にも同一IDで異座標がある。これらを自動平均・連結・直線補間せず、検査結果へ出す。

入力の改変、未知CRS、不正な座標・環、元CRSとメタデータの不一致、江戸参照を戦国確認済みへ書き換える入力、既存出力の上書きを拒否する。12試験・Ruff・mypy・構成・施設の回帰検査が合格した。検査結果は `data/audits/codh-vector-inputs.json`、要約は [検証記録](../../data/verification/codex-codh-vector-inputs/README.md)。

今回は参照入力と再現可能な準備処理の追加であり、ゲームの下図は切り替えていない。ベクター描画・年代補正の移植・操作負荷の比較・実画面での位置一致は次段階で検証する。取得した江戸形状を1560〜1615年の形状の確定としない。

別担当が全5層の派生featureから追加idだけを除き、原本の全featureと完全一致することを独立確認した。宿場の座標が将来欠損した場合も、補完せず欠損行として記録する。
