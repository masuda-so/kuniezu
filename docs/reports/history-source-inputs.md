# 既存出典の独立した史実DB入力

2026-11-07。未統合の元作業ツリーのJavaScriptで定義されていた書誌26件を `data/research/curated/sources/` へ追加した。現行mainのJSにはこの26IDの定義がなく、未統合のJS自体は持ち込まず書誌だけを分離する。古湖岸・城・行軍・合戦の資料を、JavaScriptの読込に依存せず他担当と共有できる入力として保持する。作者、資料名、URL、該当箇所、対象範囲、確認日の既存値を保ち、取得・読了日を新しい日付に偽装しない。

台帳を `node tools/research/export-evidence.cjs` で再生成した。出典は437から463件へ増え、以前の437行は内容不変。109命題・22所在記録と他のJSONLは変更していない。これらを引用する未統合34命題は今回の変更へ含めず、書誌の移植を新しい史実検証の完了として数えない。

独立レビューでも26件の元メタデータとの一致、既存出典の不変、新規の検証済み属性がないことを確認した。

検証：evidence-store、history-index、SQLインポート・検索19試験、既存出典の全行一致とID重複なし、claims/locationsの差分なし、差分整形。配信する地図・合戦・UI・保存形式は変更していないため、実画面の変化を検証結果として主張しない。
