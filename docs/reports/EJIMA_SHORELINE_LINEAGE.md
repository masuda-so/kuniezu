# 江島の年代別湖岸照合（2026-11-09）

現行の中海内環・江島の陸・岸線が、CODHの江戸期参照形状と同じであることを再現可能な読取スクリプトで確認した。原本の備考に1754年以降の造成が記されるため、この形を戦国期の確定岸として扱わない。

- [資料の採否・地物ID](../../data/research/ejima-review/README.md)
- [読取スクリプト](../../tools/geo/inspect-ejima-lineage.py)：原本と現行入力のSHA、対象範囲、3組の位相同値を標準出力へ記録する。

実行：`.venv/bin/python tools/geo/inspect-ejima-lineage.py`。3組とも `true`。`.venv/bin/ruff check tools/geo/inspect-ejima-lineage.py` も合格。これは形の来歴の検査で、16世紀の正確な湖岸を証明するものではない。

論文の本文と図4を読み、1754年以降の造成区画と自然島を分けて照合すべきことを確認した。ゲームの陸・水域・岸線はまだ変更していないため、今回の読取作業に伴う実画面の変更はない。次は図版の位置基準と登録誤差を記録して、後世造成区画を3層同時に修正する。G01全体の完了記録にはしない。

続いて同時期の地理院写真を取得し、図4写真との模様の対応を独立に登録した。37候補の36点が整合し、最大残差2.415タイル画素。現行陸を地理院写真へ直接投影した比較も確認した。[登録と目視の記録](../../data/verification/codex-ejima-registration/README.md)。写真の登録値を16世紀の汀線精度とは扱わず、年代別造成区画を写すための位置基準に限定する。
