# 黒田長政の中津本拠と1599年移動の訂正

確認日：2026-11-03。対象：1599-01-20の黒田長政→香春岳イベント、関連する中津の本拠表示、旧保存の移動予約。前段50ファイル候補の後に適用する限定差分。

## 要因と採否

`hist.js` は1599年1月20日に長政を主城ノード `kawara` へ移す補助イベントを持っていた。中津城は城郭施設として同ノードの管理域に入るが、香春岳城そのものは田川郡の城であり、黒田氏の中津本拠とは異なる。行橋市史では豊前六郡は黒田氏、企救・田川二郡は森吉成に配分された。

家督継承は1599年ではなく1589年。福岡市博物館の解説と行橋市史を照合すると、如水が長政へ譲ったのは天正17年旧暦5月である。中津城の築城着手は1588年。引退と国元への日々の滞在も別で、如水はその後も従軍し、1598年以降は京都の連歌会にも参加している。1599年1月20日の香春岳転居を裏付ける資料は確認できず、同日を別の城への転居日に置き換える案も不採用とした。

## 修正

- 旧移動イベントは無作用の `note` スロットへ変更。タイトル・本文は持たず、年表へ架空の出来事を追加しない。イベント件数と、同日以降の索引を保つ。
- 中津城の施設説明・役割と人物史料集を更新。黒田氏の本拠、長政の家督継承、細川氏への移行を記載する。主城ノードの追加・所在地の瞬間変更は行わない。
- `G.historicalPrincipalBase` は本拠または城主職の参照を返す。点座標や現地滞在を返さない。台帳の `principal-base` と `held-castle-lordship` も区別する。
- 旧保存からは、長政、香春岳、1599年1月20日発行、360日有効、通常移動という全条件が一致する保留命令だけを除く。実行済みの現在位置・軍・帰路・兵数・日付・領土・史実索引は動かさない。
- `displayCastleGens` は画面だけの一覧。中津本拠の期間の長政を代理管理ノードの「在城者・城主」と表示しない。エンジンの `castleGens` は変更しない。UI担当が4箇所を差し替える独立patchを添付した。

## 1600年の軍・帰路への影響

発熱の指示を受ける前に開始済みの1600年開始から500日監査は完了。新たな全期間計算は実行していない。

| 段階 | 監査した状態 |
|---|---|
| 1600/7/26開始 | 内部locは旧版の香春岳から姫路へ戻る。軍なし |
| 1600/8/30 | 東海道諸将の東軍参加処理が長政の管理locを清洲へ変更 |
| 1600/10/19 | 関ヶ原隊は清洲をoriginとして清洲→岐阜で生成。姫路発ではない |
| 1600/10/21 | 合戦で軍が解除され管理locは岐阜。500日内に長政の帰還軍は生成されない |

長政の既存 `documentedArmy` や中津を扱う行軍起点APIはなかった。したがって、今回の旧move除去で既存の関ヶ原隊が姫路発に変わることも、姫路へ新しく帰還することもない。UI一覧の訂正を軍経路修正と数えてはいない。

ただし、戦役前の管理locによる単独移動と戦後の岐阜残留は既存モデルの粗さであり、今回で正確な行程まで再現したと扱わない。福岡市博物館は長政の大坂城接収と筑前入国を記載する。二次資料には旧暦6/16大坂発と7/5伏見発の相違があり、月日を確認せず自動行軍へ追加するのは避けた。競合資料・取得結果は `data/research/source-notes/kuroda-nakatsu-review.json` に保存する。

## 併せて訂正した森吉成の拝領日

同じ行橋市史は豊前の大名配置確定を旧暦1587年7月3日とする。先行候補の6月25日・月精度を、7月3日・日精度へ訂正した。主城香春岳の管理域切替も同日とし、7月2日までは旧状態を保つ。黒田領と森領をまとめない。

## 検査

`kuroda-residence.cjs`：旧命令だけの除去、移動中・帰還中の軍を含む保存状態不変、任意の他命令保持、分岐保存不変更、UI用一覧と戦闘用一覧の分離、中津の年代別説明、人物史料集の出典、年/本拠/城主職/現地滞在の区別を確認。

`historical-integration.cjs`：森吉成の拝領直前/当日と、従来の九州・相良・城の改称/移転・行軍前提を再検査。`evidence-store.cjs`、`location-store.cjs`、`history-index.cjs` も通過。最後の本拠参照APIは独立した軽量検査で、本拠/転封年の城主職の区別、点座標を返さないこと、状態を変更しないことを確認した。実機・全期間の再検査はroot側の温度・検査枠調整後に行う。
