# 児島湾補正の格子対応と経緯度ベクター化

2026-11-07。CODH移行で既存の児島湾補正を失わないよう、採用PNG3枚を経緯度の面へ変換する準備器を追加した。100m画素の範囲を移す処理であり、歴史上の汀線の精度を上げたものではない。現行画像へ再適用しない。

## 格子版の証明

Git `550179070dbdb3493bae5e654312f7b62445db07` は北側792行を削除し、年代差分のwindow行から792を引いた。親の `game/map_data/projection.json` を改変せず `data/inputs/kojima-coast-review/grid-before-2026-11-04.json` に保持した。SHAは `04bd30868c1f5a9420b308d318d606a95d1158c23a8e6f18b3f7ecfe6b01466a`。

旧原点y=-903.8965145526411／旧window行12823と、現行原点y=-761.604024434064／現行window行12031の四隅は同じ経緯度となる。窓は西133.5499221917847・東134.24945760844378・南34.400097017606896・北34.75043837585339。3枚のPNGは同親コミットと全バイト一致した。

`mask-vector-bindings.json` は各定義のSHA、対応する格子版、共通の現行窓、採用画素数を結び付ける。現在の投影や型紙が変わった場合は検査を失敗させ、古いwindowを現行原点へそのまま渡さない。

## 変換と意味の保持

`node tools/geo/prepare-mask-vectors.cjs --output <新規ディレクトリ>`。各画素の四隅から面を作り、穴・離島・対角接触・カテゴリを保持する。座標の微小移動、補間、平滑化はしない。閉路が同じ頂点へ戻る箇所は単純な外環・穴へ分割する。GeoJSONは外環を反時計回り、穴を時計回りにし、元の定義・出典・推定範囲・適用期間も保持する。管理用城キーを史実領有の新たな確認として扱わない。

基底の海復元12,643画素、陸復元10,663画素、1584年以後の宇喜多期366画素。宇喜多期の年精度の切替と1616年未満の条件は元定義どおり。生成面は `adopted-raster-extent` と明示する。出力先は新規に限り、全入力検査の前に出力を作らない。

## 検証

- 512通りの3×3二値マスク、穴、対角接触、複数キーで面積・セル中心・リング方向・非閉じ重複頂点を検査。
- 実PNG3枚の窓を、出力ベクターから**現行格子**へ走査線で逆ラスタ化。計737,100セルの値が全て元PNGと一致。
- 旧格子の取り違え、SHA相違、既存出力の上書きを拒否。
- 独立レビューで見つかった自己接触2環を分離し、全環の重複頂点0を再確認。採用画素数は不変。
- 一時環境のShapely 2.2.0で出力3層の全5featureを検査し、無効な面0。検査用依存は一時環境だけで、ゲームやプロジェクトの依存へ追加していない。結果は `/tmp/kuniezu-vector-topology-20261107/result.json`。
- Node構文、organization、差分整形。2つの専用検査をOffline checksへ接続。

これは移行入力の検証で、CODH面との地理的採否やゲーム画面の切替完了の証明ではない。サーバーは起動・停止していない。
