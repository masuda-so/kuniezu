# 城系の拠点に、国指定の史跡の候補を結ぶ道具

2026-11-11。ゲームの城系の拠点（日本、359 件）について、国指定の史跡の候補をジャパンサーチの API から集める道具
`tools/research/heritage-site-candidates.cjs` を作り、目録
[heritage-site-candidates.json](../../data/research/source-notes/heritage-site-candidates.json) を保存した。
目録は位置の根拠の候補で、存在年代・城域・所在の史実命題には採用していない。ゲームの拠点の位置も変えていない。

## 結果

| 結果 | 件数 | 意味 |
|---|---|---|
| title-and-near | 124 | 題名が拠点の名前の語幹を含む史跡が、拠点から 5km 以内にある |
| title-only | 5 | 題名は合うが、5km より遠い（30km 以内） |
| none | 230 | 候補なし |

title-and-near の 124 件のうち、題名が「拠点の名前」か「拠点の名前＋跡」とちょうど同じものは 112 件、
拠点から 1km 以内のものは 108 件だった。

候補なしの 230 件は、史跡が無いという意味ではない。このデータベースは国指定だけで、
都道府県・市町村の指定は入っていない。別名の史跡（稲葉山城に対する「岐阜城跡」、月山富田城に対する
「富田城跡」など）も、名前の語幹で探すこの道具では拾えない。

## 道具の作り

- 題名の欄だけを探す指定（`q-bunka-1-s`）を使う。`keyword` で探すと、解説文に語が出ただけの文化財が大量に混じり
  （「江戸」で 11,615 件）、取得の上限で本物の候補が切れる。パイロット（#150）で「語と距離だけでは雑音が多い」
  としていた原因はこれだった。
- 種別が「史跡名勝天然記念物」のものに限り、題名の終わりが 跡・城・館・遺跡・台場 などのものだけを残す。
  同じ種別に名勝と天然記念物が入るので、「角館のシダレザクラ」「名古屋城のカヤ」のような題名が落ちる。
- API は取得件数（size）が 500 を超えると、HTTP 200 のまま `e-search-limit-error` と 0 件を返す。これを
  「候補なし」と取り違えないよう、失敗として止める。500 件で取り切れないときは続きを取る。
- 保存するのは ID・名称・種別・都道府県・所在地・指定年月日・座標・URL だけで、解説文は保存しない。

## 確かめていないこと

- 候補の史跡が、ゲームの拠点と同じ城かどうかは、1 件も人の目で確かめていない。
- 史跡の座標が城域のどこを指すか（本丸か、指定範囲の代表点か）は確かめていない。
- ジャパンサーチの API の利用条件と、文化庁のデータの二次利用の条件は、今回あらためて読んでいない。
  パイロット（#150）と同じ範囲（ID・名称・座標・種別・URL）に、都道府県・所在地・指定年月日を足して保存している。
