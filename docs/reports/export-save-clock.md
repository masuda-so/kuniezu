# メニューからのファイル保存で行軍位置が戻る問題

プレイ中のメニューは時間を止めるが、停止ボタンと異なり、その操作だけでは自動保存しない。ファイル書き出しが古い `S.visualFraction` をそのまま符号化していたため、現在の日内時刻 `U.acc` が失われていた。調査の1560年今川軍の例では、0.63日から0日に戻ることで約13.815km後退した。

`saveFraction()` を共通化し、手動枠・自動保存とファイル書き出しの全てで現在の日内時刻を使う。ファイルは日内時刻を反映したスナップショットを渡し、保存形式・経路版・進軍速度・到着予定・史実日付は変更しない。

実際の書き出し関数・保存コーデック・取込前検査・ゲームの状態復元を使う回帰検査を追加した。変更前はファイルの時刻が0.63でなく0となり失敗し、変更後は5時刻で位置・日付・兵数・到着予定を保持する。手動枠と自動保存も同じ時刻を保持することを確認し、Offline checksへ追加した。

専用の一時Chromeで実メニューから書き出し、ダウンロードしたファイルをファイル選択から取り込んだ。時刻0.63・部隊197の位置・兵25000・到着予定40・日付が前後で一致し、JavaScript例外は0件。結果は [検証記録](../../data/verification/codex-export-save-clock/README.md)。現行サーバーや普段のブラウザ・保存は変更していない。
