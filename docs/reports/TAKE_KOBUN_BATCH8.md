## 分けたこと・気づいたこと

- **吉田城**：綱文は永禄7年（1564）6月で、年表の三河平定は永禄8年（1565）。年が違う。
- 綱文の日が「報告・通知の日」の条（謙信の越中、政宗の黒川城の明け渡し）は、文書（`administrative-document`）の命題にし、攻略・明け渡しの命題は作らない（第 2 便の八上城への Codex の指摘と同じ型）。
- 越中・日向・伊那郡・全羅道は地域の参照（`region:`）にし、国や郡の境の輪郭は持たない。
- 既存の台帳の場所を使った：日向の松尾城（`place:matsuo-hyuga`）、七尾城（`place:nanao-noto`、#116）。根拠の命題を足した。
- 新しい台帳の場所 3 つ（三河の吉田城・讃岐の十河城・会津の黒川城）は、同じ名前のゲームのノードが代表する。黒川城はゲームの `yosho:黒川金山` とは別。
- 人物は既存の ID だけに結んだ（長連龍・温井景隆・菅屋長頼・下条頼安は結ばない）。
- 黒川城の明け渡しの通知：秀吉は日付の無い明け渡しの相手で、この日の通知（政宗から田村宗顕へ）の当事者ではないので結ばない（#130 の Codex のレビューの基準に合わせて直した）。

## 日付語の作用範囲の点検（2026-11-09 追記）

#122 の八上城への Codex のレビュー（綱文の「是日」が降伏ではなく処刑に掛かっていた）を受けて、この便の綱文の全文を引き直し、「是より先」「是日」「尋で」がどの行為に掛かるかを確かめた。「是日」や「尋で」が別の行為に掛かっていた命題は、その日に掛かる行為の命題に直し、日付の無い行為の命題は作らない。上の表はその後の形。年表（ゲームの日付）は変えていない。
