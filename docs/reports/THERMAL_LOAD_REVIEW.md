## 観測と対応

初回のプロセス計測では Chrome Renderer が CPU 115.5%、RSS 約 0.9 GiB。そのプロセスは次回計測時には終了しており、終了理由・起動者は特定していない。8 GiB のメモリに対し使用中スワップ約 4 GiB だったが、同時の memory_pressure は空き 57% を示し、スワップ残量だけで現在の圧迫を断定しない。pmset は温度警告・性能警告の記録なし。センサー温度は未取得で、冷却を確認したという意味ではない。

重い画像生成・全画素照合・ブラウザ検査は一つずつ実行し、調査とコード編集だけを並行する。起動した専用 Chrome は検査終了時に閉じる。

ゲームではタイトルへ戻った後も速度の状態により描画ループが再生扱いを続ける問題を Claude が修正。タイトル/シナリオ画面で速度と日内蓄積をリセットし、ゲーム中・ダイアログなし・終了前の実再生だけを描画条件にする。非表示タブでは定期確認も止め、visibilitychange で再開する。
