# 全合戦の再生・陣営・到着予定の実行照合

最新版は [転進と到着の再検査](RELAY_ARRIVAL_REVIEW.md)。下記の旧版の位置集計は、末尾に記した検査条件の誤りがあるため履歴として扱う。

2026-11-02。基盤は家康1600修正を含む1b21bb4。描画担当の未コミット変更を含めない専用作業ツリーで検査した。

`node tools/checks/battle-arrival-audit.cjs` は1560開始から1615年末まで進める。111図の再生通知、直前・当日の軍/表示記録、同名を目的とする軍だけでなく参加将名で対応する別戦役の軍も取得する。前後で同じ軍IDの目的名が変わる場合も両状態を残す。

## 結果と範囲

111件すべての再生通知を観測。同名目的の軍が登録到着予定より先に戦闘通知を受ける例は0件。これは両陣営の現地到着の証明ではない。

戦闘分類のうち、軍/表示記録の対応が両陣営とも取れない通知6件、一方だけ取れない通知70件、対応軍が再生図の範囲外の陣営を含む通知42件（重複あり）。参加将名の一致と、家だけの推定対応は区別する。表示図の枠自体は戦場境界の確定値ではないので、範囲外をただちに誤配置としない。

同名目的の軍が未観測なのは、大坂冬、富山、鉢形開城、小田原開城、1614木津川口の5戦闘項目と、非戦闘の石山開始・会津出兵の2項目。会津は別名の家康行程で表すため、軍が存在しないとは扱わない。他も別名の包囲・降伏段階との関係を点検する。

範囲外の候補には、長篠の一方、関ヶ原の一方、山崎・三方ヶ原・賤ヶ岳・沖田畷の双方などが含まれる。到着予定が一致していても、最終地点・別戦役の軍・指揮官名との対応が不十分な場合がある。個別の元データと史料の照合へ進める。

## 証拠

全件は data/audits/battle-arrival-audit.json。各観測に前後の軍ID、氏族、指揮官、目的、登録到着予定、位置、出発/経由城、陣営対応の根拠、再生枠内外、位置付き/不詳の布陣群数を残す。分類一覧は battle-arrival-side-candidates.json。

位置不詳の表示補助は、史料上の現地配置済みの証明としない。史料上の正しさをこの検査だけで完了扱いにしない。サーバーは使わず、起動停止なし。全体ゴールはactive。

## 2026-11-02 再検査による訂正

上記の旧集計は表示用の連続移動を有効にせず測定していたため、表示位置の範囲外判定には使用しない。修正版は `auditVisualMoves=true` で全111通知を再観測し、両陣営不対応7件・一方不対応85件・範囲外16件（重複）を候補として保持する。長篠・三方ヶ原・関ヶ原は検査条件の訂正で対応を確認し、山崎は帰陣フラグが転進へ残る実際の不具合も修正した。詳細は [転進と到着の再検査](RELAY_ARRIVAL_REVIEW.md)。全図の考証が完了したという意味ではない。

## 長谷堂城の照合

包囲中の軍は内部の終了管理名 `#hold` を使うため、監査では元の戦役名 `historyTitle` に戻して照合する。長谷堂城で直江兼続軍が撤退段階まで継続している場合も、包囲中の観測を同じ戦役に数える。位置の判定は別に維持する。

山形市の散策マップでは直江の本陣は菅沢山。最上義光歴史館の屏風解説は旧暦9月15日と10月1日前後を別の場面としている。全国地図の既存イベントは山形城を管理拠点にしているため、布陣図と照合するときは山形城の座標を本陣に流用しない。旧道経由の進軍、本陣での滞陣、撤退を別々に確認する。[山形市の散策マップ](https://www.city.yamagata-yamagata.lg.jp/_res/projects/default_project/_page_/001/003/682/2025hasedou.pdf)・[最上義光歴史館の屏風解説](https://mogamiyoshiaki.jp/?l=462020&p=log)

再実行では111件すべての再生通知を観測し、同名の到着予定より先に出た戦闘通知は0件。長谷堂は撤退開始の直前に「長谷堂城の戦い」の軍として追跡できた。経路は黒川→白河→須賀川→二本松→山形で、直前の表示点は戦場図の外。撤退開始直後は山形→米沢に切り替わるが、表示位置は同一点だった。したがって戦役名の欠落とは別に、進攻経路と滞陣位置のデータ修正が必要。山形県の遺跡一覧で菅沢山本陣跡の登録番号201-264と調査報告書の参照箇所（中城報2、32頁）を確認した。[山形県の遺跡一覧](https://www.pref.yamagata.jp/documents/3490/yamagata.pdf)

直江兼続の配置群を菅沢山の概略点（東経140.270度・北緯38.222度）、志村光安の配置群を長谷堂城跡の代表点に設定した。菅沢山は市資料の本陣名と、現地踏査資料の城から北約1.1〜1.2kmという位置関係を照合して概略点を置いた。専用Chromeで1600年シナリオを開始し、撤退前日の直江軍がこの点で滞陣していることを確認した。JavaScript例外0。進攻経路と旧保存の滞陣表示は別途検証が必要。[山形市の散策マップ](https://www.city.yamagata-yamagata.lg.jp/_res/projects/default_project/_page_/001/003/682/2025hasedou.pdf)・[菅沢山の現地踏査](https://www.hb.pei.jp/shiro/dewa/sugesawayama-honjin/)

転進処理も次の戦役に設定した経由地を使うよう修正した。直江軍は前任務の位置から米沢へつなぎ、荒砥・畑谷を順に経て菅沢山に着く。荒砥と畑谷は地名の代表点で、地点間は既存の経路探索を使う。専用Chromeで表示経路の3点の順序、菅沢山での滞陣、例外0を確認。山崎への転進と旧保存位置を確認する `relay-arrival.cjs` も通過した。長谷堂進攻中の既存保存は未照合。[大江町の保存管理計画](https://www.town.oe.yamagata.jp/files/original/20210607094914197c0350026.pdf)・[山形おきたま観光協議会](https://sengoku.oki-tama.jp/?l=105705&p=log)

保存版22の長谷堂進攻中の軍にも、読込時に新しい表示経路を一度適用する。旧経路の日内位置から菅沢山へ接続し、日付、着陣予定、兵数、領有を保持する。再読込時は適用済みの経路を再構築しない。検査は `node tools/checks/hasedo-save.cjs`。旧版の山形城行きの表示経路を再現し、日内位置0.42と新経路の終点を照合した。
