# 安土城火災の報告日

松下浩「本能寺の変以後の安土城と織田家」（滋賀県、2024年）第4節所収の『兼見卿記（別本）』天正10年6月15日条を照合した。同日に吉田兼見が火災の報を記したことを登録する。講座資料が示す炎上の幅は旧暦6月14〜15日。出火時刻と放火者は確定しない。[滋賀県の発掘調査成果報告会資料](https://www.pref.shiga.lg.jp/file/attachment/5456533.pdf)

一時DBで安土城・1582年から検索し、旧暦6月15日がゲームの表示日と同じユリウス暦7月4日に当たることを確認した。火災報から城跡の座標は推定せず、観音寺城とは別の地点IDを登録した。今回の入力追加は史料台帳に限り、火災の描画や日付は変更していない。
