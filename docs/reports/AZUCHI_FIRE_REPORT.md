# 安土城火災の報告日

松下浩「本能寺の変以後の安土城と織田家」（滋賀県、2024年）第4節所収の『兼見卿記（別本）』天正10年6月15日条を照合した。同日に吉田兼見が火災の報を記したことを登録する。講座資料が示す炎上の幅は旧暦6月14〜15日。出火時刻と放火者は確定しない。[滋賀県の発掘調査成果報告会資料](https://www.pref.shiga.lg.jp/file/attachment/5456533.pdf)

一時DBで安土城・1582年から検索し、旧暦6月15日がゲームの表示日と同じユリウス暦7月4日に当たることを確認した。安土城を観音寺城とは別の地点IDで登録した。今回の入力追加は史料台帳に限り、火災の描画や日付は変更していない。

奈良文化財研究所の文化財総覧WebGISが示す世界測地系の点（北緯35.15638度・東経136.1393度）を、安土城跡の代表点として登録した。安土城跡・1582年・周辺の矩形を組み合わせたDB照会で火災報が見つかり、座標の根拠が `site-representative` と返ることを確認した。[文化財総覧WebGIS「安土城跡」](https://heritagemap.nabunken.go.jp/statistic/98015844-%E5%AE%89%E5%9C%9F%E5%9F%8E%E8%B7%A1.html)

年表の文章も更新し、天主などの焼失、旧暦6月15日付の日記、原因不明を伝えるようにした。ゲーム内の資料と史料台帳で出典IDを共有する。[専用Chromeでの年表・資料・炎の確認](../../data/verification/codex-azuchi-fire/README.md)に合格した。

ゲーム内の安土城の点は、旧座標（北緯35.16度・東経136.14度）から約408m離れた史跡の代表点に更新した。観音寺城の基準点は別に保持する。既存のセーブに保存された地点座標は読み込み時に保持するため、補正は新しい開始・築城から反映される。
