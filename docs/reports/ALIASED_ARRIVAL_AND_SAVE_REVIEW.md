# 改名前後の人物名による到着点と保存位置

2026-11-02、移動保存版22。

## 修正した挙動

木崎原の軍は「島津忠平」、合戦図は「島津義弘」で登録されていた。到着地点だけが表記の完全一致を要求していたため、同じ人物の布陣地点を見つけられず、管理拠点へ進んでいた。既存の名前対応と同じ正規化で照合し、元の人物名や史実の日程を変更せずに、登録済みの合戦代表点へ接続した。木下・羽柴・豊臣秀吉なども同じ処理を使い、同定できない人へ位置を割り当てない。

島津忠平と義弘の同一性は、[鹿児島県観光サイト「とりまく人々」](https://www.kagoshima-kankou.com/feature/shimadu2019/introduction1-2)の冒頭で確認し、人物の安定IDと一命題を登録した。ここでは改名年を確定していない。命題の対象期間を、その全期間に「忠平」と名乗った意味へ読み替えない。

## 旧保存の移行

版21以前の移動中の軍は、保存時点の日内位置を旧経路から取り出し、そこから新しい経路の残りへ接続する。出陣・帰陣・転進の全てで、現在位置と登録到着期限を保持する。未出発なら出発予定を保持する。軍を伴わない人物の移動も、保存した日内位置からつなぎ直す。日付・領土・兵数は書き換えない。

## 検証

- `arrival-aliases.cjs`：忠平／義弘、木下／羽柴／豊臣秀吉の照合、同定不能な秀勝への位置捏造の抑止。1570開始から木崎原直前まで進め、忠平の実際の軍が代表点へ到着することを確認。
- `movement-save-position.cjs`：出陣・帰陣・待機・単独人物の保存位置と期限、日内0.37／0.63の保持。
- `relay-arrival.cjs`、`movement-save.cjs`：山崎への転進と古い保存の移行。
- `offline.cjs`：全7シナリオ各720日と既存の史実進行・保存・道路・兵数検査。
- 全111図の通知を再観測。範囲外の候補は16件から15件へ。木崎原の島津軍の候補は解消したが、相手軍の軍勢記録が対応しないことを史実上の不在とは扱わない。

### 実画面検証（作業ツリーの移動処理）

既存8000番の共有版 `f7c71df` に専用Chromeで接続した。共有ファイルは書き換えず、専用ブラウザのリクエストだけを差し替え、`movement-continuity.js` と `scenario-openings.js` を作業ツリー `9952d59` の版へ置き換えた。両ファイルのSHA-256を結果に保持する。共有側そのものの配備完了という意味ではない。

- 木崎原前日（旧暦1572年5月3日／西暦6月13日）の日末直前に、島津忠平の軍が登録済み代表点へ到着。翌日、木崎原の合戦図を表示。例外0。
- 画像2点と数値は `data/verification/arrival-aliases-worktree/`。両画像を目視し、元の人物名・兵数札・合戦図の表示を確認。
- 合戦図の両群は同じ「交戦地域の代表点・対陣方向未詳」であり、実証済みの対陣配置ではない。名札の密集や、地図上の最終経路に見える長い直線も別の改善対象として残る。モデルから経路881点を取り出すと、末尾区間はゲーム内換算で約15.601kmの直線だった。えびの市の説明は伊東軍の三ツ山出発・加久藤攻撃・鳥越合流と島津援軍の集合を述べるが、この軍の長距離進路を裏付けるものではない。今回の人物同定修正だけで布陣や経路の精度を証明しない。

再現コマンド（サーバーの起動・停止なし）：

```sh
GAME_MOVEMENT_OVERRIDE_ROOT="$PWD" GAME_TEST_OUTPUT=data/verification/arrival-aliases-worktree node tools/checks/arrival-aliases-browser.cjs
```

共有側統合後は `GAME_MOVEMENT_OVERRIDE_ROOT` を付けずに実行し、差し替えなしの検査を別フォルダへ保持する。
