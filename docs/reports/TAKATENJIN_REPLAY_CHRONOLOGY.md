# 高天神城の段階と経過文をそろえる

1580年の砦による包囲強化、1581年旧暦1月25日以前の降伏申し出、同年旧暦3月22日の出撃と落城を別の再生段階にした。掛川市の年表が挙げる水野文書・浜松御在城記の記述範囲に従った。再生バーは順序を示す。[掛川市「高天神城に関する歴史について」](https://www.city.kakegawa.shizuoka.jp/gyosei/docs/8328.html)

共通の合戦生成処理では、年表から借りる結果込みの要約を再生の最後に置く。段階の記録がある場面には引き続き専用の経過文を使う。既存の年表の日付とセーブ形式は変更していない。

全111図の名簿・配置・日付関連の既存回帰検査に合格。高天神城と共通処理を使う箕輪城で[再生バーを実画面検証](../../data/verification/codex-takatenjin-replay-chronology/README.md)した。

読み込み順を揃え、変更前後の全111場面を比較した。41場面は年表要約の本文を保持して表示時点だけを開始から終了へ移した。高天神城は専用の3段階を追加し、残る69場面の経過文・段階見出しは一致した。全場面で既存の合戦日、登録部隊、布陣、出典IDが一致した。
