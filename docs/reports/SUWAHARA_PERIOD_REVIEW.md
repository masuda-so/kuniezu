# 諏訪原城の名称・所属・活動年代

2026-11-01。対象 `site-419be35cc2ac`。

旧処理では長篠シナリオの旧暦1575年5月8日時点でも牧野城と表示された。島田市博物館が『今川氏真詠草』に基づいて採用する旧暦8月24日で、名称と武田・徳川の所属を切り替えた。全国図の名札と詳細も共通の名称処理を使う。

位置は既存のCODH代表点（138.119899,34.818330、220000269800）を維持。城域の測量境界ではない。役割は武田方の遠江攻略拠点、徳川方の国境防御拠点とし、単なる近隣城の支城と断定しない。守将と交代の城番を区別した説明を追加。

同市の城紹介は廃城時期不明、別ページは1590年関東移封に伴う廃城説とする。1590年説を採用するモデルを維持し、年の精度しかない終了を年初へ先取りしないよう、非稼働は1591年からとした。特定の廃城日を確認したという意味ではない。画面にも仮説として説明する。

詳細で同じ説明を繰り返していた表示を整理し、旧暦の日付を明記した。

`site-periods.cjs` と専用Chromeで旧暦1575年5月8日・8月23日・8月24日・1590年8月1日・1591年1月1日の名称、所属、稼働、実画面を確認。画面検査は日付を隔離設定した検証で、世界全体の年表を各日まで進めた結果とは別。offlineは別途7シナリオ各720日を確認した。サーバー起動停止なし。

証拠：`data/audits/site-periods-review.json`、`data/verification/site-periods/result.json` と同フォルダの画像。確認済み命題を独立入力へ2件追加し、RAG出力は23命題となった。
