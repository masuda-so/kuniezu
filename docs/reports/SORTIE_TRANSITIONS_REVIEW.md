# 軍の生成日と包囲日・記録接続の修正

2026-11-01。サーバー操作なし。M01の継続作業。

## 確認した原因

長篠の勝頼隊は、包囲段階への到着を旧暦5月8日へ変更していた一方、軍を生成する判定は本戦5月21日から逆算していた。1560年から継続すると、到着期限を過ぎて初めて生成され、`schedule.start > schedule.end` となった。開始シナリオだけの確認では見つからない不整合だった。

筒井定次隊は1584年12月15日に生成された直後、同じ日次処理で一日分の行軍が加算されていた。軍の存在しなかった直前フレームから、街道途中へ跳んでいた。

信長は既存の大河内行軍記録の開始時に、前の状態で残っていた観音寺付近から、記録上の岐阜の出発点へ切り替わった。

## 変更

- 出陣の逆算判定にも、到着計算と同じ段階の日付を使用する。包囲段階と本戦の日を混在させない。
- 日次処理開始時に存在していなかった軍には、一日分の行軍を加算しない。生成した日の冒頭は未経過時間として扱う。時点記録や日程指定の軍は、別途その記録時刻で位置を計算する。
- 連続した行軍記録の最初の地点には、前の位置から道路沿いの推定移動で接続する。途中日程は推定であり、`estimated` と元の出典ID・接続先の記録IDを保持する。出発地や経路が不明な一点記録に架空の行軍は追加しない。

## 資料と適用範囲

[長篠城址史跡保存館の展示解説](https://www.city.shinshiro.lg.jp/mokuteki/shisetu/shiryokan/nagashinojyoshi/tenjikaisetsu.html)の第2ケースは旧暦5月8日の包囲と8～14日の攻撃を記す。一方、[同市の観光解説](https://www.city.shinshiro.lg.jp/kanko/meisyo/nagashino-shitaragah.html)は5月1日、[新城商工会の年譜](https://www.shinshiro.or.jp/battle/nenpu.htm)は4月21日の包囲と5月8日の本格攻撃を区別する。5月8日を初期包囲の唯一の確定日とは扱わず、今回の実装ではその攻撃・包囲段階の到着時刻として使用する。

商工会年譜にある4月5日甲府出馬は次の出発地・経路照合の手掛かりであり、今回の変更でその出発日・途中行程を再現したとはいえない。元康の大高記録と同様に、表示の連続性と史実の精密な逐日位置の検証を分ける。

確認済み命題を `nagashino-siege-may8` として独立ファイルに保存した。資料の異同と適用範囲も同じレコードに保持し、資料再出力で消さない。命題総数は24件。
