# 日向道・三国峠越の史料線を道路へ統合（2026-11-02）

文化庁112番の選定地図から抽出した市場―内山―三国峠―上津小野―小野市の21.214kmを、日向街道の描画と行軍表示用の道路網へ反映した。旧参考線の東寄りの経由から、史料に基づく内陸の区間へ修正。公式地図の赤ベクトル線の屈曲を保持し、単に旧線の見た目を丸めたものではない。

北側は大分側から戸次・野津を経る47.452kmの近現代比較線。小野市から延岡側は50.906kmの歩行向け比較線。自転車向けの南側候補は117.641kmの閉往復を含んだため不採用・原入力保持。短い区間に分けた歩行向け候補では大閉路・過大吸着なしを確認。比較経路の取得は歴史的通過の証明ではない。

線の接続差は北1.322m、南17.701m、旧延岡側0m。既存街道の両端は保持し、史料区間と旧参考線の8〜10kmの隔たりを推測直線で繋がない。延岡以南は既存の比較線を保持。街道名キーは保存・関連参照のため維持する。

完成線は3118点。史料区間の採用点・北側比較・南側比較・既存南部という4区間の出典境界を入力JSONへ保持。公式図の線は1m程度の簡略化幅、周辺の比較線は従来どおり数m幅。採用した史料区間の全点が描画に残り、近現代線の往復除去が史料上の九十九折れを消していないことを検査した。将来の再生成ではaccepted-whole-reference.jsonを上書き採用するため消えない。
