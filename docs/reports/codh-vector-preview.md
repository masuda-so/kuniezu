# CODHベクター描画の比較画面

2026-11-07。公式海岸ポリゴン・湖沼面・街道線・宿場点を、ゲームの `kuniezu/map/projection.json` と同じ平面へ変換する独立参照画面を追加した。原本の採否前にゲームの戦国期地形を置き換えない。

`uv run python tools/geo/codh_preview.py --output <新規ディレクトリ>` で原本検査とGeoJSON変換を実行し、外部要求のない `index.html` を生成する。生成先が既存なら拒否する。GeoJSONと出典manifestも出力に残す。属性文字列の `<` はJSON埋込み時にエスケープする。

Path2Dは地物ごとに初回だけ作成し、ズーム時はカメラ変換と画面上の線幅を変える。範囲外の地物はbboxで省略し、操作・リサイズ時のみ再描画する。Polygon/MultiPolygonの全リングを保持して偶奇則で塗り、陸面と岸線は同じ公式ポリゴンから描く。点だけの湖から輪郭を作らず、分離した街道を接続せず、宿場の異座標重複もまとめない。

専用一時Chromeで日本・関東・児島湾の切替と拡大操作を確認し、例外0。初回パス生成44.1ms、観測した各参照画面の描画0.2〜1.8ms。これは単発の参照画面測定であり、ゲーム全体の性能改善や負荷試験の結果ではない。児島湾の画面を目視し、湾と島、街道、宿場の描画を確認した。江戸末期の輪郭に直線的な干拓堤防等が含まれるため、そのまま1560年の湾へ採用しない。

ゲームとの接続では現行の海模様・陰影を維持する。現行の領域画像を使う選択判定、陸マスク、境界線、年代別水域も採用面と整合させてから切り替える。この画面の生成は、その切替完了を意味しない。
