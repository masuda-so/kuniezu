# 十三湖の水戸口の出典表示

現行正本の十三湖と日本海が辺で接する2セルの中心を国土地理院の現代図に重ねると、現在の突堤の間に入る。国土交通省の資料では、1649年の開口は明神沼の南端で、近世には現在に近い位置にも開口した。戦国期の開口位置をこの変遷表から確定できないため、地図の画素は変更せず、資料画面に現行表示の位置と確認範囲を記した。[国土交通省「水戸口の変遷」](https://www.thr.mlit.go.jp/bumon/kisya/kisyah/images/62929_1.pdf#page=3)
