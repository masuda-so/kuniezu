# 桧原旧道の同縮尺比較

2026-11-01、ゴールactive。前回の柏木城の位置補正を踏まえ、北塩原村の桧原歴史さんぽ2頁地図をW09-05桧原湖形状と比較。

## 比較結果

地図は回転している。湖岸の類似変換（拡大率・回転・平行移動）を求め、318点の比較で画像内の残差中央値3.96px、90百分位9.71px。拡大率0.17697px/mで約22m・55mに相当するが、これは合わせに使った湖岸の残差であり、独立した測量精度ではない。湖岸重畳画像を実見し、北部の湾・半島の整合を確認。

公式図の橙色の旧道を1205点の未採用候補として抽出し、元図上の重畳を実見。現在の桧原湖の北端を横切る旧道点線を含む。元図の概略点線を細分化しても史実精度が上がるとはしない。表示上の街道と異なり、候補は南西端約139.9823,37.6716、北東端約140.0583,37.7716を通る。

図面・現代湖形・取得情報・SHA・候補線はdata/inputs/hibara-map-review。再生成は/tmp/kuniezu-geo-env/bin/python tools/geo/hibara-map-register.py、同hibara-map-trace.py。元PDFはreference-documents/hibara-history-walk.pdf。図は資料照合用でゲーム描画へ転載しない。

## 採用前の確認

桧原歴史館の現代OSM代表点も取得したが、館の文字ラベルの位置と施設記号・学校記号を混同して制御点にしない。今回独立制御点としての一致確認は完了していない。峠・寺社等の位置と照合してから、米沢街道の既存線との接続と原資料の時期を検証する。未採用のためゲーム・保存経路版9は変更なし。湖も追加しない。ゲーム試験の再実行はせず、解析2処理の再実行と元図との視覚照合を実施。

## 独立照合と接続調査の続行

湖岸合わせに未使用の大山祇神社鳥居を防災科研07-005の座標140.041378,37.722228と照合。図中記号[1288,835]に対し予測[1280.90,839.84]、差8.59px=48.56mで記号幅16px以内。単一点・図の記号幅の検査であり全線の精密測量を保証しない。hibara-map-controls.pyとindependent-controls/review JSONで再現可能。神社の文字位置ではなく鳥居記号を使用した。

現在の米沢街道参考線への最近点は、公式図トレース南西端から約8880m、北東端から約5926m離れる。遠い線へ無理につなぐ修正を避け、北127タイル・南160タイルの地理院現代道路形状を取得。原URL・SHA・404記録保持。北33/南4は404の欠測。北の候補は同一連結成分まで1059m、南は9934mで不採用。取得範囲や地物の連結性に関する結果であり、「現実に道路が存在しない」ことの証明ではない。仮の橋や直線を追加せず未採用候補JSONを保持。

gsi-road-reference-candidate.pyは地域固有の接続処理を持たず、共通road_geometry_network/reference_reviewを使用する取得済み資料の変換器。次は旧峠道と熊倉以南の時代別経由地を確認して範囲を補う。江戸宿場マップR218の塩川経由を1560年からの確定中心線へ遡及しない。今回ゲーム描画・経路版9は変更していない。
