# 天正壬午の和睦の成立日を同期する

和睦の説明が1582年11月13日、外交成立と関係台帳が11月14日となっていた。大日本史料第11編之2・846頁の綱文と、[茅野市神長官守矢史料館『八ヶ岳通信』42号1頁](https://www.city.chino.lg.jp/uploaded/attachment/37201.pdf)は旧暦天正10年10月29日を記す。共通暦の1582年11月24日へ3箇所を同期した。命題の旧暦は保持し、換算した実装と区別する。

領有の取り決め・婚姻の約束を、城の引渡し・人質各人の移動・婚礼の完了とは扱わない。既存の外交イベントに領地や軍の移動を追加しない。[小田原市公開の詳細年表](https://www.city.odawara.kanagawa.jp/global-image/units/545484/1-20220804145354.pdf)312頁（PDF38頁）は実婚姻を翌1583年の項に置く。既存の丸島論文は今回429で再読できず、本文読了の根拠には使っていない。

旧保存は史実観察・既知の直前版署名・当該成功記録を要求して限定修復する。11月13日から23日の旧説明を除き、旧外交成立済みの場合は当該戦争状態・同盟値・関係値・別の有効盟約がないことを追加確認して早すぎる同盟を除く。成功件数は削除した記録分だけ戻し、完全一致の旧ログだけ除く。

失われた外交値の元の数値を復元したとは主張しない。外交修復時は既存の史実戦争ルールの上限15を適用する。過去の通行許可から派生した移動は巻き戻さず、11月24日以降の旧年代記も保持する。未知署名・失敗記録・別盟約は推測して書き換えない。既存の没日訂正前と和睦訂正前の署名の組合せにも対応する。

焦点検査は旧日付の実進行で作った11月13日・14日・23日の保存から修復と24日の成立、冪等性、未知署名・履歴欠如・失敗・別盟約の拒否、無関係状態の維持を確認。既存没日・移封の移行、史料台帳、asset stampsも通過した。専用Chromeで旧保存2件×幅940px・335pxを再開し、例外0、早すぎる同盟・記録の除去と元の日付を確認した。[検証記録](../../data/verification/codex-tensho-peace-date/README.md)。
