## 分けたこと・気づいたこと

- 綱文の語に合わせた：落城（陥る・抜く）・降伏（降す・招降）・明け渡し（開城して入城）。城を捨てる・退城・放火・進入は `military-event` にし、落城や明け渡しの日としない。
- **小田城**：年表は太田資正が小田城を奪ったとするが、綱文の攻め手は佐竹義重（資正は佐竹方）。主体の食い違いとして報告する。
- **八上城**：綱文が掲げる日は、降した兄弟を信長が磔にした日。降伏そのものの日は補わない。
- **長島**：綱文は「退城」と書くだけで城を特定しない。地域名の場所 `place:nagashima`（長島）にし、ゲームの `node:nagashima`（長島願証寺）とは結ばない。
- **石山本願寺**：ゲームの側に `node:ishiyama` と `yosho:本願寺（石山）` の 2 つがある。1 つの場所の代表は 1 つに限るので `node:ishiyama` だけに結んだ。2 つのゲームの拠点の関係はゲームの側で確かめが要る（報告のみ）。
- 駿府・箕作城・長島はゲームのノードが無いので、台帳の場所だけ。
- 人物は既存の ID だけに結んだ（教如・太田氏資は ID が無いので結ばない）。
