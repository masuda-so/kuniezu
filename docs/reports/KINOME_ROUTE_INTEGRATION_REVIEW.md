# 北陸道・木ノ芽峠区間の採用と検証

2026-11-02。対象は北陸道の敦賀―木ノ芽峠―今庄―湯尾付近。全線を戦国期の精密中心線とするものではない。

## 史料と位置合わせ

福井県史の中世交通記述から敦賀―木ノ芽峠―今庄―府中の経路を確認した。栃ノ木越は別系統として北国街道（近江）を残す。柴田勝家による整備を、新道の初開通と取り違えない。史料一覧は [出典検討](HOKURIKUDO_SOURCE_REVIEW.md) と data/inputs/hokurikudo-review/source-review.json。

[文化庁「歴史の道」木ノ芽峠越の選定図](https://www.bunka.go.jp/seisaku/bunkazai/shokai/kinenbutsu/rekishinomichi/pdf/92088301_s036_01.pdf) を保存し、河川の重なりで現代地形図と位置合わせした。採用登録の河川相関は0.6038。位置合わせに使用しなかった今庄・湯尾・南今庄の駅記号3点は、それぞれ27.9m、56.7m、16.4m差で、図記号の読取幅100m以内。駅の現代代表点と図記号の比較であり、戦国期の道路精密測量値ではない。

図の赤い選定区間と青い接続区間を区別して抽出し、1893点・13.510kmを採用。PDF原本、画像、登録行列、独立点検値、抽出線は同入力フォルダへ保持した。SIFT照合不成立・誤検索地点を使った経路・大きい閉往復を含む候補は不採用のまま保存している。

## 実装

旧比較線の20.855km閉往復を含む区間を置換。南12.410kmは地理院道路比較、中央13.510kmは選定図、北15.638kmは近現代道路比較へ分け、既存全線の両端を保持した。接合差は1.412/1.925/3.561/0m。今庄の既存北国街道端点と図上線の距離は23.061mで、局所道路網でも両系統の接続を検査した。長い直線で欠落を埋めない。

再生成入力は accepted-whole-reference.json。出典は game/road-display.js、座標は game/modern-road-reference.js。保存済み道路の移行版を16へ更新した。公式図の採用点を全て描画線に残す検査を設け、九十九折れを閉往復として誤削除しない。

## 確認結果

- kinome-mapped-route.cjs：原端点、接合差、全採用点保持、誤削除なし、今庄の局所接続を確認。
- gsi-controls.py：検索の先頭結果を無条件採用せず、完全一致名と地域範囲で選択。曖昧・欠落を拒否。
- road-reference-review.py：誤った遠隔地点による過大迂回を収集前に検出。
- 全7シナリオ×720日、保存移行、出典出力、構成検査を通過。確認済み史料命題48件。
- 専用Chromeで木ノ芽峠・今庄・湯尾の3画面を保存して実見。例外0。data/verification/kinome-mapped-route/。

現行の道路整理は85線中61線、203往復区間、180.344km。残る250m超の同一点閉路候補は59線224件。交差・非閉路支線は別点検であり、候補を一律に削除しない。北陸道の他区間を含む史実照合と全体ゴールは継続する。

3画面のうち標高は後の画面で読込完了しており、初期2画面の平坦表示から標高読込遅延の点検を継続する。サーバーの起動・停止はしていない。
