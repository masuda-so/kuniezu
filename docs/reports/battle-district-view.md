# 合戦図の全体・地区表示

広域戦の全体図を人物名で埋めず、全体では個別の駒と顔・選択隊の名前を表示し、地区では近接した名札を読む構成にした。名前を置くために部隊の地理位置をずらさず、全員を個別に選択できる。地区名は既存地名か人物の周辺を使い、史実上の軍団編成や境界を新設しない。

8隊以上・複数の位置群・十分な広がりがある戦だけに共通判定で地区を用意し、狭域戦や模式図には不要な切替を足さない。現行データでは長篠・関ヶ原・賤ヶ岳・小牧長久手・大坂夏/冬が該当する。全体と最大4地区を使い、狭幅は全体ボタンと地区選択を一行に、広幅はボタンで切り替える。切替中も時刻・再生を維持し、画面幅変更時は同名の地区を保持する。キーボードのfocusも復元する。

選択中の色を消していた既存テーマの強制指定を修正。狭幅の長い引出線を避け、空きがなければ名札だけを省く。個別駒・肖像・選択・参加者一覧は維持する。読み込みで肖像の内容が更新されても、陣営の枠色を独立に確認する検査へ修正した。

検証: Nodeで111合戦を390/940pxの計222フレーム生成し、例外0と部隊ID保持を独立確認。関ヶ原・長篠・冬の陣では全員の個別選択と地区切替の時刻/座標不変も確認した。専用Chromeでは関ヶ原・長篠・冬の陣・高天神・本能寺・耳川・木津川口を1400/390/335pxで検査し、地区操作・再生位置・選択・寝返り・模式図の分離を確認した。地形や布陣の史実精度の検証ではない。

実画面と検査の入口は [確認記録](../../data/verification/codex-battle-district-view/README.md)。既存のベクター年代検査ファイルはRuffの整形だけを合わせ、検査の内容は変えていない。

## 地図内の注記の整理

2026-11-07の利用者の決定に従い、地図下部の「点線の軌跡＝推定の動き」の説明枠を除去した。推定の動きの点線、推定配置の破線、出典や内部の根拠区分は維持し、図面を人物名や説明で埋めない。Canvas検査では説明文が再び描かれないことと、線種・個別部隊の選択・地区切替を確認する。

追加確認：専用Chromeで7合戦を1400/390/335px表示し、地区切替と部隊選択、時刻・座標の保持を確認、JavaScript例外0。[確認記録](../../data/verification/codex-battle-map-cleanup/README.md)。
