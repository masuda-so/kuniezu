# 比較湖5件の編集正本と変更しない配信

2026-11-07。CODHのみの合成面では、既存19比較湖のうち十和田湖・田沢湖・猪苗代湖・木場潟・余呉湖の全域が陸となることを確認した。変化の少ない湖を含む補完が必要なため、国土交通省の公式W09-05原本と照合し、既存5湖をGeoJSONの編集正本へ移した。2005年の比較形状であり、戦国期の精密汀線としない。

JGD2000の宣言をXMLで確認し、標準座標変換を通してCRS84へ移した。リング方向の正規化以外に形を変えず、既存の小数6桁座標とも一致。独立担当は5湖とも原本との形状一致を確認した。原本・SHA・規約・処理情報は [入力ノート](../../data/inputs/mlit-w09-2005/README.md) とmanifestへ保持する。独立レビューで見つかったW09個別の利用規約リンクを反映し、一般PDLのみとする初期記録は修正した。

`build-vector-assets.cjs` は `kuniezu/map/physical`・`admin`・`control` のGeoJSONを検査し、`map/build/vector/` へバイト単位で複写する。座標変換・穴埋め・線の削除・平滑化は行わない。`build-map.cjs --vectors-only` と通常ビルドへ接続した。`--vectors-only --check` は出力と正本の一致を確認する。正本と出力の重なり、出力の祖先/子、実パスでの重なり、シンボリックリンク、無関係な出力の上書きを拒否し、検査失敗時は従来の出力を保持する。

検証は、直接編集の値をそのまま配ること、元の正本が不変であること、誤ID・閉じていない環・出力保護・削除済み地物の残存防止、実際の統合CLIのベクター限定モード、公式原本SHA/行名/座標系、5湖の有効性と湖内点の保持を対象とする。原本との全頂点一致を今後の編集制約にはしない。編集正本が実測の史実岸であるとは扱わず、地形と選択の接続は全体地図の切替時に確認する。
