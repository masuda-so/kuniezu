# 史実観察版への修正と検証（2026年10月31日）

## 行軍・戦闘条件の整理

同じ負荷を二重計上しないよう、入力の種類で区分する。以下の係数は設計値で、史料から測定した値ではない。

| 区分 | 現在の扱い | 未実装・要検証 |
|---|---|---|
| 地勢・経路 | 既存の起伏、街道、海路、河川横断を基本所要日数へ反映 | 実際の峠・橋・渡船・道幅とその使用年代 |
| 季節・環境 | 既存の積雪地域と冬季による速度係数を共通化 | 個別日の積雪・降雨・増水・潮位・風。推測した天気を史実に追加しない |
| 補給 | 兵糧を消費し、不足時は速度低下。宿の既存効果を維持 | 現地調達、兵站線、輜重・輸送船、補給拠点の実証 |
| 人員・負荷 | 行軍日数に応じた疲労、兵数による隊列の遅れ | 休息による回復、傷病、疫病、脱落者。待機日を行軍疲労に数えない |
| 指揮・組織 | 既存の武将能力、士気、練度を戦闘式に維持 | 指揮伝達の遅れ・混乱・偽報。能力数値は史実の測定値ではない |
| 兵科・装備 | 既存の兵科と戦法の係数を維持 | 鉄砲の弾薬・再装填、馬の補給、複合編成の比率 |
| 守備施設・攻城 | 既存の城耐久・城地形・渡河を伴う攻城条件を維持 | 各時代の曲輪、土塁、石垣、門、堀の実寸 |
| 情報・政治 | 史実の同盟・従属・離反を年代で反映 | 別ルートでの情報獲得・外交判断は今回停止 |

史実観察中は、推定の速度係数で記録上の到着日や勝敗を変えない。経路内の移動割合と「行軍の条件」の説明に使い、分岐ゲームのバランス調整とは切り分ける。季節変更で駒が逆戻りしないよう、日程上の区間配分は出発時に固定する。
