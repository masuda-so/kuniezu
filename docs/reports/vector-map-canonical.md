# 年代別の編集済み地理正本

2026-11-07。CODH参照面と既存の採用補正を、経緯度の陸・水域・事前導出岸線のGeoJSONへ移した。以後はこれらを直接編集し、通常ビルドはバイト複写だけとする。陸・水域・岸線は一致させて更新し、原本＋差分から正本を上書きしない。5比較湖の旧独立ファイルは重複を避けてwaterへ統合し、元IDと利用条件を保持した。

根拠と原文・SHA・採否・検証は [恒久的な移行記録](../../data/inputs/vector-map-migration/README.md)へまとめた。一時ファイルだけを追跡先にせず、CODH/MLIT原本、既採用の画像正本、既存の地理補正、初回準備コード記録へ結び付けている。陸2203地物・水域584地物・岸線2969線。年代差は宇喜多期の366セル相当だけを1584以後の追加面とし、年ごとの全国複製を作らない。年精度の既存表示仮説を継承したもので、完成日を史実命題として新設していない。

独立レビューで香取の保護陸12セル欠落と岸線role不一致を修正した。八郎潟の矩形移植が生む直線岸は不採用にし、採用済み湖・陸復元・保留・島だけを継承した。岸線も全国前後の一体比較を避け、元セグメントを局所で分類し、表示範囲で選べる線へ分けた。保護70セル、八郎潟4区分、巨椋池8500セル、宇喜多366セルを確認し、各年代の岸線が陸境界から5開口を除いた期待線と一致することを検査した。

Pythonで有効性・bbox・5湖・元マスクの年代・保護面・岸線一致、Nodeで配信バイト一致を検査する。比較ページには正本岸線と日付選択入力を接続し、陸面の輪郭を別に描いて開口を塞がない。本体の表示切替とは別の検証として扱う。

追加の照合ではW09全556記録を点検し、公的資料で1560年以前の存在を確認した自然湖17件を現代比較形状として補完した。湖の存在と2005年の水際は別の情報として保持する。鰻池は本文未確認、御池は対応形状なしのため補完しない。

後世の完成形と判断した、または前身の水面範囲が分からない溜池7件は、輪郭を表示正本から外し原形と採否を保存した。跡には地形効果を持たない未特定の背景を置き、戦国期に乾いた陸だったと主張しない。上堰潟は後世成立の証明がないため削除していない。飯沼・見沼・塩津潟は概略点、椿海は出典付き推定面として別の4地物に分離し、いずれも海陸判定と移動に影響させない。

戦国期の全国実測岸線を確定したとは扱わない。飯沼/見沼の概略面、椿海の推定表示、塩津潟のラベル等は本体接続で区別して継承する。元のラスター表示はまだ削除しておらず、ゲーム本体の塗り・陰影・選択・ズームへ接続して確認する工程が続く。


最終データの比較描画は[1560年](../../data/verification/codex-vector-final-1560/README.md)と[1584年](../../data/verification/codex-vector-final-1584/README.md)に分けて実施した。368地点のCanvas/判定一致と366セルの年代差、操作・停止を確認した。児島湾の拡大像には旧100m採用画像由来の段差・直線が残る。これは保存した採用範囲の一致を示すもので、岸線の形状改善の完了証拠にはしない。単純な平滑化で史料のない水際を作らず、対応史料と照合して別途編集する。

配信検査で推定表示層の座標系表記が `EPSG:4326` だったため、RFC 7946の経度・緯度順を明示する `OGC:CRS84` へ訂正した。座標値は変更していない。元パケットのSHAと訂正後のSHAを移行記録に併記した。
