# CODH参照面の位相処理

2026-11-07。江戸期参照形状を地図の面演算へ使う準備として、海岸・湖沼の派生面処理を追加した。原本・元の属性・時期の意味は変えず、戦国期の実測岸とは扱わない。

Shapely 2.2.0を開発時だけの依存として固定した。[公式API](https://shapely.readthedocs.io/en/stable/reference/shapely.make_valid.html)のlinework方式を使い、原本の線分と頂点から偶奇則で有効な面を構成する。元の重複を除く座標位置が面と残差の合計に全て残ることを検査する。面にならない元の線は別層へ保存し、陸や岸線へ昇格させない。構造方式による穴の推測や、微小なbufferによる座標移動は使わない。

海岸1888行（null2を含む）・湖沼573行を保持。有効だった海岸1857面・湖沼562面のgeometryは不変。無効な海岸29件・湖沼11件のみを派生化し、海岸側21件の残差を別層へ保持した。これは面の数学的有効性の検査で、史実の正誤を40件判定したものではない。

個別参照面に加え、海岸の和集合、湖の和集合、海岸から湖を引いた陸を生成する。原本の版・SHA・クレジット、処理した行・理由・座標位置数・追加交点数、生成物のSHA、Shapely/GEOS版をmanifestへ記録する。出力先は新規ディレクトリのみで、全検査の後に作る。この検証の一時出力はコミットしない。利用者確認に従い、編集正本は改変済みGeoJSONの直接編集とし、本準備器は初回移行・検証用に扱う。通常ビルドで正本を上書きしない。

描画用の陸は2,142の連結成分へ分ける。形状を単純化せず、範囲外の成分を描画時に省略できるようにする。この成分IDは生成版内の行番号であり、地物の恒久IDではない。

検証：有効面/nullの不変、自己交差の交点分割、元座標・属性保持、潰れた線の保持、陸から湖を除くこと、既存出力保護、実入力全件の有効性、成分分割の和集合不変、比較表示でのSHA・原本版照合を8試験で確認した。独立担当は全出力SHA、原本の行/属性/ID、有効形状の不変、修復行の元座標保持、合成陸と `coast − lakes` の差分面積0、陸と湖の交差面積0を確認した。全体試験67件と、比較読込の追加後の専用8件を通過。Ruff・mypyも合格。

`codh_preview.py --surfaces <派生出力> --output <新規ディレクトリ>` でSHAと原本版を検査して比較画面へ接続できる。専用Chromeの実画面で日本・関東・児島湾、狭幅、拡大・ドラッグ、操作終了後の追加RAF要求0を確認した。[検証記録](../../data/verification/codex-codh-topology/README.md)。

型検査で年代補正準備器のCLI/モジュール兼用importが重複定義扱いとなる箇所も修正し、既存の香取海試験と併せて検査する。ゲームの実行時依存・表示・保存は変更していない。実画面の切替は、この参照面へ年代補正と領域・選択を接続した段階で検証する。
