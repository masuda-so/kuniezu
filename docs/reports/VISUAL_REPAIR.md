# 地図表示と伏見城の修正記録

2026-10-31。`docs/reports/MAP_HISTORY_REVIEW.md` の後の訂正。サーバーの起動・停止はユーザーが担当。8000番の既存サーバーに専用Chromeで接続して検証した。ユーザーの通常の保存データには触れていない。非史実ルートは引き続き保留。

## 表示の不具合と修正

- **本州が消える重大な不具合**：`water-evidence.js` の朝鮮半島の旧海岸除去条件が、経度幅と北端だけで本州も除外していた。西端が大陸側にあることも条件に加えた。仙台・東京・名古屋・京都・広島・高知・鹿児島・函館・漢城が陸として残る検査を追加した。前回の「地図検証済み」はこの欠陥を見逃していた。
- **画面を埋める地図**：タイトルと配置図選択は本州中心に背景を拡大。プレイ画面もパネルの下まで地図を敷く。全世界の四隅を小さな枠へ縮める方式を廃止。縦長画面では横方向をドラッグして見る。表示可能域を越える海や白い余白へはパンできない。
- **海・山**：青海波を復元。日本は国土地理院の陰影起伏を色調補正して重ね、朝鮮等はMapzen標高の陰影を継続。どちらも現代の地勢である。日本の陸域を別に保持し、地理院の陰影を海へ塗らない。
- **拡大・縮小時**：新しい倍率の表示域がそろうまで親画像を保持し、詳細画像を区画ごとに継ぎはぎで出す処理を廃止。取得待ちの間は低い解像度が残る。通信なしで未取得の詳細を生成するものではない。
- **上部操作**：320・390・820px幅で和暦・月日・西暦・速度・操作を上端3pxから配置。今回の初期日付では下端106px。西暦を隠す後続CSSを上書きできていなかった問題も修正した。
- **画面外の軍勢**：凸駒を画面内へ無理に引き寄せず、上下左右に隊数のボタンを出す。押すとその方向の隊の実位置へ移動。密集して収まらない隊は一覧へ導く。実際の位置や兵数は変更しない。軍勢の凸駒の影と立体風の下帯を、地図・合戦図ともに除去した。

`road-revision.js` で経路と確認範囲をまとめ、`engine.js` で折点を保つ。

| 区間 | 改訂 | 根拠と限界 |
|---|---|---|
| 美濃への道 | 6点から40点。清洲→稲葉→萩原→起→墨俣→大垣→垂井の順を反映。大垣の城下の屈曲も参照 | [大垣市立図書館の照会回答](https://crd.ndl.go.jp/reference/entry/index.php?id=1000179521&page=ref_view)、[大垣市の景観計画](https://www.city.ogaki.lg.jp/cmsfiles/contents/0000001/1427/keikaku.pdf)5頁の計画区域図、[安八町「歴史の道」](https://www.town.anpachi.lg.jp/0000001524.html)。江戸期の線を参考とする概略値で、1560年の線形を確定したものではない。画面にも「近世線参考」と表示 |

| その他 | 少数地点を大きな曲線へ補間する処理を外す。従来の岸沿い補正は点数が対応する場合に保持 | **全街道を史実どおりに引き直したわけではない**。従来データの直線・粗い線形や年代未照合は残る |

新たに照合した2区間は、折点を曲線へ膨らませず、近くの別道へ端点を自動吸着しない。道筋の経緯度は公開図・通過地から読み移した編集値で、精密測量座標ではない。

## 伏見城

`battle-fushimi.js` を追加。旧図の大きな外郭多角形・一様な環状水堀・重なった四角い曲輪を置換した。

- 主図：[前田義明「伏見城の造営」](https://www.kyoto-arc.or.jp/News/kenkyu/06kiyou-3.pdf)、『研究紀要』6、2000年、27–42頁。**39頁図15**（加藤次郎『伏見桃山の文化史』による城郭復原図）を画像で確認し、本丸・二の丸・松の丸・名護屋丸・山里丸・北側曲輪群、空堀と切岸の関係を描き直した。[書誌](https://cir.nii.ac.jp/crid/1390290701615765760)も確認。
- 城下と水系：[京都市埋蔵文化財研究所の2006年3月11日現地説明会資料](https://www.kyoto-arc.or.jp/news/gensetsu/149%20fusimi.pdf)、**1頁図2**。西側城下と舟入・宇治川の相対位置を参照。
- 照合：[兵庫県立歴史博物館「伏見城曲輪并武家屋敷図」](https://rekihaku.pref.hyogo.lg.jp/database/shiryo/detail/?id=2791)の解説、[京都市歴史資料館「伏見城」](https://www2.city.kyoto.lg.jp/somu/rekishi/fm/nenpyou/htmlsheet/toshi20.html)。資料画像自体はゲームへ転載していない。既存の守将・経過の出典も保持した。
- 曲輪の切岸を短線で描く表現を追加し、堀・城下・丘陵を別に描画。肖像と凸駒を保持。

**完成した復元図ではない。** 参照した復原図には豊臣期・徳川期の時期差があり、[京都府立京都学・歴彩館の照会回答](https://crd.ndl.go.jp/reference/entry/index.php?id=1000293796&page=ref_view)も天守位置の異説を示す。今回の輪郭・地形は資料を整理した編集図で、1600年の実測復元ではない。天守の意匠、町家の棟数、守将の持場、各隊の細かな移動は未確定。これらを精密に見える創作で補ってはいない。街区内の屋根は絵図の記号である。
