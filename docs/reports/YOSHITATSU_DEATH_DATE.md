# 斎藤義龍の没日と旧保存の訂正

既存命題`death-date-saito-yoshitatsu`の永禄4年5月11日を、
[岐阜県文化伝承課の肖像解説](https://www.pref.gifu.lg.jp/page/354743.html)
（2025年4月1日更新、2026年11月10日確認）の人物解説と墨書銘で追加照合した。
共通暦のユリウス通日2291387、ゲームの日付1561-06-23へそろえる。
旧実装の1561-06-20から3日遅らせ、龍興への家督継承も同日にする。
肖像の制作年代、死因・享年・精密な所在を新しく確定したものではない。

没日訂正の前便2人を改訂1、今回は改訂2とし、既知の年表署名の世代を区別する。
前便の修復済み印1があっても今回を飛ばさず、史実観察・居城滞在・軍/旅程不参加・
旧没日から新没日前までの保存に限定して生存と家督を戻す。
未知署名や没日以後の過去は書き換えず、日付・城・部隊・資源・成功件数を維持する。
元イベントに一致する旧日の記録だけを除き、再読込で重複しない。
和平の修復も、実際に公開した没日改訂の世代と旧和平日の組合せだけを認める。

既存の3人と改訂1の旧保存3日分、和平の回帰、実ファイル取込12条件を確認した。
[検査と実画面の証拠](../../data/verification/codex-yoshitatsu-death-date/README.md)。
独立レビューで指摘された不要な成功件数の減算は公開前に除去し、維持を検査した。

DB向けの実装棚卸しも書き出し直し、event:58だけを訂正後の日付と出典へ同期した。
他の実装イベントのID・日付は維持し、史実命題そのものの追加・変更とは区別する。
