# 備中高松の羽柴軍の到着点

岡山県古代吉備文化財センター「備中高松城跡」の本文と陣営配置図を照合した。秀吉の本陣は龍王山から石井山へ移り、5月には完全包囲したと説明される。旧暦6月1日の1582年シナリオ開始時は石井山の本陣代表点に置く。

- 原因：イベントの管理拠点 `bmatsuyama` を、そのまま野外の到着点にも使用していた。予定日を満たしても戦場へ来ていなかった。
- 修正：城内の清水宗治と石井山の羽柴秀吉を別地点に登録。`#hold` への切替時に `historyTitle` を保持し、包囲中にも元の合戦の到着点を参照する。
- 位置：県の公開図の高松城・吉備津神社から二点相似登録した `[133.828068,34.686228]`。約200mの読取幅を持つ図記号の代表点。精密な本陣外郭、個々の将の持場は意味しない。二点に一致することだけで独立精度を主張しない。
- 再現：`node tools/research/register-takamatsu.cjs`。原図・基準点・地理院タイルは `data/inputs/takamatsu-review/`。
- 保存：経路版18。旧版の包囲軍は、予定到着日・大将が一致する一意のイベントだけから元の合戦名を復元する。日付・領土・兵数を保持する。
- 検査：`node tools/checks/takamatsu-arrival.cjs`。開始時と旧保存の修復後が石井山であること、その後30日で山崎へ移ることを確認。日次最大移動24.486km。75km超の飛躍がないという検査であり、全地点の精密な史実照合とは異なる。

今回は包囲開始日の精密な再設定、鳥取から備中への全日程、児島湾の戦国期汀線を確定したものではない。現在の通知日は変更していない。地図と合戦図は共通の本陣点を使う。

出典：岡山県古代吉備文化財センター「備中高松城跡」本文「秀吉の陣」段落・高松城水攻め陣営配置図、https://www.pref.okayama.jp/site/kodai/628728.html （2026-11-02確認）。位置登録の補助：國學院大學古典文化学事業「吉備津神社」緯度/経度欄、https://kojiki.kokugakuin.ac.jp/jinjya/kibitsujinja/ 。

実画面：共有integrationへの署名統合後、起動済み8000番で専用Chrome検証。旧暦6月1日の地図に石井山位置の羽柴軍、合戦図には城内清水宗治と石井山の秀吉が別点で表示されることを実見。保存版18、位置差0、例外0。画像と結果は `data/verification/takamatsu-arrival/`。共有側でも全7×720日と専用到着検査を通過。地図南方の児島湾汀線の粗さは別の継続修正対象。
