# 街道の編集GeoJSONと共通読込

2026-11-08。比較JSと実行時の閉路除去・吸着から、編集済み`kuniezu/map/physical/roads-reference.geojson`を読む方式へ移した。現採用85路線・136,778頂点を保持し、形状の史実格付けは変えない。日本の戦略地図は74路線、海外11路線は歴史文脈・合戦図用として保持する。

`vector-assets.js`でmanifest・サイズ・SHA・CRSを共通検査し、同時読込をまとめる。完了した生データを共有ローダーへ残さず、各利用側が採用済みの表現を保持する。`road-source.js`は全件検査後に索引を採用し、最初の参照時だけ共通のG.PJへ投影する。テンプレートが明示ロードを待つので、経路網の構築が旧形状や未準備データで先行しない。欠落・破損時は既存の起動エラーと再読込へつなぎ、旧線へ黙って戻さない。

通常ビルドは正本をバイト複写し、旧入力から再生成しない。移行前の比較入力84件と、全読込入力のSHA・全路線の比較値・経路網・代表経路を[移行記録](../../data/inputs/road-vector-migration/README.md)に保持した。旧公開JSと旧形式を書き戻す10生成器は、実行依存の解消を確認して退役。元の取得物・採否・地理院・文化庁・OSMの帰属は保持する。伊那街道の資料・粗い経由地・戦役回廊の生成器は存続する。

## 検証

- 全85路線の頂点数・順序・地理座標SHA、経路網56,970点、代表3経路991点と5経過点が移行前と一致。保存のgeometryVersion=24を維持。
- loaderの重複要求・SHA／サイズ／CRS・不正地物・部分採用防止、旧8件の区間・原図・接続検査が通過。
- Djangoページ・静的書出し・GeoJSON位相・編集保持と伊那メタデータ生成の12pytest、Ruff・mypy41ファイルを確認。
- 専用Chromeの1400px／390pxで、東山道・三州・若狭、今川勢の行軍・停止再開・日程保持、破損SHA拒否と再読込を確認。旧比較JS要求0、manifest要求1、道路要求1。画像でも地図と駒を確認。

同じ操作後にGCを行ったJS heapは移行前167.3MB、修正後166.9MB。共有ローダーが読込済み生データを保持する初期案で増えていた約31MBを解消した。これはJS heapの観測であり、Mac全体のメモリや消費電力ではない。

カメラ設定から実際の下地再描画完了までの中央値は、3地点・2幅で移行前121〜244ms、修正後112〜242ms。各条件10標本の観測で、全体のパン遅延解消を証明するものではない。根拠・画像は[実画面要約](../../data/verification/codex-road-vectors/README.md)。

本変更は技術的な正本移行である。江戸・近現代の参考線と戦国期の経路の区間照合、特に東山道・吉蘇路・中山道の時代差や城へのアクセスの審査を、この移行の合格で完了にしない。
