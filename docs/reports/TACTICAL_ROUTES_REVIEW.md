# 戦場内の地点遷移と全国街道

2026-11-01。関ヶ原再点検中に、戦場内の登録地点間にも全国街道の探索が呼ばれていることを確認。松平元康の大高城から丸根砦付近の約0.72kmの地点間が、全国の道路網に寄って約3.39kmの描画経路になっていた。

戦場内は典拠に対応させて登録した地点列を使用し、その間を模式的な直線区間で補間する。細かな実進路を復元したとはしない。全国地図の街道沿い行軍は維持。登録した6移動すべてで、始終点を正確に保持し、登録区間から外れないことを確認。関ヶ原の家康・小早川・脇坂、桶狭間の信長・元康、長篠の勝頼が対象。細かな史実通過経路・時刻を新たに創作していない。

合戦下部の不要な凡例はユーザーの以前の指示に従って両表示形式から除去。再生バーは図内に維持した。戦闘カタログの再構築でresearchBeatsが上書きされる再現性の不具合も修正し、初回の原記録を保持。
