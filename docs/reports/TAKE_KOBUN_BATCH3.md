## 分けたこと・気づいたこと

- 合戦（賤ヶ岳・摺上原）と、開城の語の無い包囲（岐阜城）は `military-event`。和議による退城（二本松）は明け渡しとし、落城の日としない。
- **岐阜城**は稲葉山城の後の名なので、#116 の台帳の場所 `place:inabayama` を使い、別名に「岐阜城」を足した。
- **ゲームの城の対応の食い違いの候補（報告のみ。静的なノード名による。イベント時点の動的な対応は Codex が確かめる）**：
  - 年表の長浜城の出来事は城に `node:odani`（小谷城）を使う。ゲームの `yosho:伊豆長浜城` は伊豆の城で、近江の長浜城とは別。
  - 年表の「松ヶ島城の戦い」は城に `node:kiriyama`（霧山城）を使う。
  - ゲームの `node:ota` は常陸の太田城で、紀伊の太田城とは別。
  - これらには代表の記録を付けていない。
- 第 2 便の候補にしていた島津義久の降伏は、#79 で登録済みだったので外した。新発田城は、綱文の条が報告の日（落城は「是より先」）なので日付の照合の対象から外した。唐沢山城は当たりが無い。
- 人物は既存の ID だけに結んだ（新城弾正・木曾義昌・蘆名義広・貞種は結ばない）。
