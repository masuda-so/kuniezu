# 未導出の郡の雲を金雲にする

利用者の決定（2026-11-13）：持ち主を決められない郡の雲は「絵巻物の金雲のように」。

## 変更

- `kuniezu/static/kuniezu/county-map.js` の `cloudTile()`：白いぼかしの円を重ねた模様を、金のすやり霞に替えた。横に長い角の丸い帯の上の縁に大きさの違う瘤を並べ、両端を丸める。先に全ての雲を濃い金の太い線でなぞってから金で塗るので、重なった雲の外周にだけ輪郭が残る。金箔の細かな粒を雲の上だけに散らす。模様は 512 px の繰り返しで、種を固定しているので毎回同じ形。
- `kuniezu/static/kuniezu/ui.js`：雲の大きさ（`cloudScale`）を約 3 倍にした。元の大きさでは、近畿を見る縮尺で細い縞に見えた。
- 雲は動かない。設計の PR 8（白い雲を流す別の層）は作らない（設計書に追記）。

## 確かめたこと

`GAME_TEST_OUTPUT=data/verification/claude-gold-clouds node tools/checks/county-map-browser.cjs`：PASS。雲の検査は、未導出の郡（試しのキャンバス）に金の画素（赤 >190、緑 140〜215、青 <140）が乗ることに替えた。1560・1582・1600 年、近畿と関東、幅 1400 px と 390 px の 12 枚で、未導出の郡に金雲が出て、家の色の郡と見分けられる。
