# 岩石城の位置を地図に表示する

落城年表の地点と、史実DBの城跡代表点が一致していたが、地図上に常設の目印がなかった。既存の地名注記を使い、岩石城を岩石山に表示する。座標は資料掲載の代表点であり、城域や部隊の位置を示さない。城の管轄・支城ボーナスと切り離した。

- [CODHの地名座標](https://geoshape.ex.nii.ac.jp/nrct-poi/resource/41/410000417400.html)
- [添田町「岩石城跡」](https://www.town.soeda.fukuoka.jp/site/siteibunkazai/1065.html)
- [添田町の落城記録](https://www.town.soeda.fukuoka.jp/uploaded/attachment/1792.pdf)

1560・1587・1615年の地点照会が同じ代表点を返し、落城は既存の旧暦1587年4月1日の年表記録として残ることを確認した。[専用Chromeでの描画確認](../../data/verification/codex-ganjaku-site/README.md) に合格。
