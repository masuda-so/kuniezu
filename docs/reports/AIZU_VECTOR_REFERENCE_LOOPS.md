# 米沢・越後の比較線4閉路を編集正本で除去

旧PR #45の調査と採否を現行GeoJSONへ移す。実行時の補正器は復活させず、改変済み正本を直接編集した。全85路線のうち2路線だけを変え、他83路線の点列と属性を保持する。原比較線は近現代道路であり、戦国期の精密な古道の復元とは区別する。

| 比較線 | 同じ交差点へ戻る区間の現行点列の距離 | 頂点数の変更 |
|---|---|---|
| 米沢街道 | 約14.40km、約30.42km | 1,694→946 |
| 越後街道 | 約20.62km、約4.57km | 1,848→1,442 |

距離は経緯度の点列から球面距離で計測した。旧PRの数値とは、既採用の小さな往復除去と計測法を分ける。4閉路の両端が完全に一致することを確認し、戻り地点までの1,154頂点を除いた。除去後の全辺は変更前にも存在し、新しい直線接続を作らない。各路線の両端、ID、区分、出典ID、歴史的な確認状態は維持する。

## 典拠と適用範囲

旧PR #45の参照先は、[文化庁の会津・米沢街道選定地図](https://www.bunka.go.jp/seisaku/bunkazai/shokai/kinenbutsu/rekishinomichi/pdf/92088301_s084_01.pdf)、[新潟県の会津街道概略図](https://www.pref.niigata.lg.jp/uploaded/attachment/77275.pdf)、[越後街道ものがたり](https://gokujo-aizu.com/pdf/nishiaizu-echigostory.pdf)。今回は旧調査を継承し、閉路の現行点列と適用結果を検証した。これらを新たに閲覧したとの記録や、図の近世の道筋を戦国期の中心線へ格上げする記録は作らない。

`data/inputs/road-adoptions/aizu-reference-loops-2026-11-09.json` に変更前後の点列SHA、復元できる除去座標、グラフ、全319接続の変更前SHAと変更10接続の変更後SHAを保持する。経路の座標全体は複製しない。旧移行基準と東山道の採用記録を上書きせず、可逆差分から照合する。

## 保存と移動

全319接続の実表示経路を比較し、10接続のみ点列が変わることを確認した。移動版を25から26へ上げ、途中位置から新経路へつなぎ直す。到着期限、目的地、兵数、所属、領主と日付を保持する。

版移行で残り1日未満の線を採り直す処理も、実際の正の期間を使う。旧版25の残り0.25日の合成保存を、軍と単独人物の実描画関数で保存時・50%・期限直前・期限・期限後まで検査する。合成fixtureを史実の行軍記録へ混ぜない。

## 担当と受入

以前のCodex自身のG04・移動全般の広い担当記録を保全して解放し、2路線の具体的な範囲へ絞った。G04や移動要望全体を完了にはしていない。2路線の対象全体にも史実回廊の照合が残るため、今回の閉路修正の後は担当を解放し、全路線の史実照合済みとは記録しない。
