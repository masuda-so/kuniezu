# 歴史地図データを地図の土台へ使えるか

確認日：2026-11-02。調査範囲は下表の提供元と実ファイル。1560〜1615年の日本全国の海岸・湖・河川・領主境界・街道を一式で置換できるデータは、この調査では確認できなかった。「歴史地図データは存在しない」という結論ではない。

## 実ファイルを確認して変わった判断

Harvardの紹介論文だけでは非商用限定とも商用可能とも確定できないため、現行の配布APIとREADMEを両方取得した。APIのCC0を見た段階では組込候補だったが、READMEの非商用条件と衝突したため採用を止めた。国形状は検査用の一時領域だけへ展開し、このリポジトリには形状ZIPを含めない。メタデータ・README・座標定義・検査結果・ZIPのSHA-256を `data/inputs/historical-map-candidates/` に保持する。

国立公文書館の規定はページ本文を実取得して確認した。Web検索の取得失敗（403）は資料そのものの非公開や利用不可を意味しない。現在の規定では画像も営利利用・加工・再配布でき、目録のCC0とは別の説明になっている。

「慶長期の国絵図が一切残っていない」とも言えない。取得済みの備前国図は慶長期推定であり、[山口県文書館](https://archives.pref.yamaguchi.lg.jp/document-search/maps/)も防長両国の慶長等の控図の現存を説明している。幕府へ上呈した原本、地方の控図、推定年代の国図を区別する。

## 実装への適用

日本と朝鮮で共通の実座標・描画・品質検査を維持し、入力資料を年代ごとに分ける。古図画像は利用条件を確認して位置合わせし、採用点・未使用の検証点・読図誤差を残す。干拓や河道変更で年代が異なる部分だけを差分として合成する。国郡の行政境界、城の支配域、領主の政治的所属は別のデータとして保持する。

現代標高だけで古湖岸を決めたり、明治の水際や江戸の国境を全期間へ固定したりしない。まず慶長備前国図と干拓年代で児島湾を、迅速測図と利根川・干拓の年代で香取海を照合する。若狭街道は同じく古道系統を確かめ、現在の自転車・歩行経路をそのまま16世紀の道として採用しない。
