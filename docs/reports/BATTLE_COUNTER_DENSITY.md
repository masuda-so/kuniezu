# 合戦図の密集した駒と個別選択

2026-11-07の利用者の要望に従い、隊の位置を動かさずに駒の大きさを調整する。広域図／地区表示、全隊の個別ID、史実・推定の位置と動作、時刻、部隊の向きは変更しない。

## 変更

- 画面内の近隣隊までの距離に応じて駒本体を縮小する。広幅は28pxから最低18px、狭幅は18pxから最低14pxとし、高さも同じ比率で変える。孤立した隊と選択隊は元の大きさを保つ。
- 顔は最低16pxを維持し、広幅の変化を16/18/20/22/24pxに限る。移動するたびに異なる小数の半径で肖像キャッシュを増やさない。旗は別の下限で読める大きさを維持する。
- 選択隊の本体・顔・旗だけを最後に描き、同じ場所の別隊に隠れないようにする。名札の配置探索順とクリック矩形は変えない。退場した隊の透過も保持する。
- 駒の中心に別隊の名札が掛かると、従来は名札が常に優先され、同地点の個別一覧を開けなかった。中心近くは駒を優先し、離れた名札は従来の対象へ開く。
- 選択リストを高さ制限付きのスクロール領域にし、見出しと閉じる操作を上へ置く。部隊数を強調する説明を「部隊を選ぶ」に替え、選択中の隊を枠と押下状態で示す。
- 部隊ボタンのSpaceキーを地図の再生キーが横取りしないようにする。モーダル・ボタン・リンク・編集欄の操作を優先し、通常の地図上の再生／速度キーとEscapeの既存処理は維持する。外部からunit IDで選択した場合も一覧の押下状態を合わせる。

完全に同じ地点の隊は、正の大きさを保って縮小するだけでは分離できない。勝手な横ずらしや統合で処理せず、全員の個別選択を維持する。動きに伴う大きさは現在の距離から求め、停止・巻き戻し・地区切替で不定な位置やサイズを残さない。

## 検査

既存のCanvas fixtureを `tools/checks/fixtures/battle-atlas.cjs` へ切り出し、viewportと密集検査で共有する。実行順や公開APIは変えない。密集検査は実データの全111件×335/940px×5時刻と各地区、計1320フレームで、個別ID・中心位置・サイズ下限・肖像半径の有限性を確認する。388隊の選択、130回の同地点一覧、停止／seekの決定性、退場隊の透過と復元、駒中心に被った別隊名札のクリックを確認した。空のゲームコンテキストによる描画検査であり、史実配置の確認ではない。

専用Chromeの実画面では関ヶ原・長篠・大坂冬／夏・伏見の5合戦を940/335pxで確認。選択後の実画面位置はCanvasの変換行列の丸めを考慮し、0.001px以内で一致を確認する。先の検査で使った画布幅の比率と過小な許容差を修正したもので、地理位置を調整する実装修正ではない。

[実画面の確認記録](../../data/verification/codex-battle-counter-final/README.md)。一覧の固定見出しを一つにまとめた最終版は関ヶ原／伏見の両幅で追加確認した。元のサイズ試作と比較の詳細はローカルの診断として保持し、集計した複数フレームの重なりを固有の部隊数や史実の密度と解釈しない。最近隣探索は二乗の計算量なので、性能改善を達成したという変更ではない。
