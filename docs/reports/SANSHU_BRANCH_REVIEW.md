# 三州街道の支線に見える往復

2026-11-01。ユーザーは「岩村城に本線から支線が向かって見える」と補足した。先に進めていた高遠方面の経由設定調査とは別に扱う。

## 表示線の修正

既存の三州街道の近現代参考線に、(137.708965,35.306391)から出て同じ地点へ戻る約22.405kmの閉路があった。原3149点のうち457点の往復を表示側から除去。本線の両端・原資料は保持。城への史実の支線として登録された線ではない。game/road-display.jsの修正はこの照合済み交差点に限定し、別の道路の閉路を機械的に削除しない。

road-return-audit.cjsで85街道を点検、0.5kmを超える閉路候補は63街道。史実上の環状路の否定を意味せず、交通手段・経由点・吸着・原資料を個別に照合する。JSONはdata/audits/road-return-review.json。抽出時点は今回の表示修正前。

## 別件の新規比較線は不採用

塩尻市の説明で善知鳥峠・小野・辰野・伊那谷の経由関係を確認。高遠側の経由設定を見直した新比較線を取得したが、治部坂付近に約45kmの閉路が残ったため棄却し、公開画面へ全線置換していない。自転車・徒歩比較、方向制約変更でも閉路が残った。自動車の公開サーバーは取得失敗。棄却した入力はaccepted:falseとし、生成ツールも適用を拒否する。data/inputs/sanshu-modern.json。収録19地点は精密な歴史的中心線ではない。

出典：塩尻市「街道を学ぶ 三州街道」https://www.city.shiojiri.lg.jp/soshiki/35/3943.html 。豊田市「足助の歴史」https://hakubutsukan.city.toyota.aichi.jp/bunka/12_asuke/rekisi.html は明治・1930年の道筋付替えを説明する。現国道を16世紀へそのまま遡らせない。

## 検査

sanshu-route.cjsで棄却入力の適用拒否、原データ不変、457点の往復除去、始終点保持を確認。road-displayとmovement-saveも通過。保存経路版6へ更新し、旧保存の時刻・領土・兵数は変更しない。専用Chromeの画像・結果はdata/verification/iwamura-road-correction/。地形描画の共通化方針はdocs/architecture/regional-algorithms.md。
