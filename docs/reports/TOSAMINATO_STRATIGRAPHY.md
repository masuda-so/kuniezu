# 十三湊の飛砂層と古湖岸の照合

榊原滋高（五所川原市教育委員会）の報告を原本で確認した。第54次調査では中世面と近世面の間に約1.2〜1.4mの飛砂層が確認された。隣接する第157次調査の前浜跡と、飛砂層の分布図も確認した。図7の推定湖岸は15世紀中葉まで、図11はGIS地形測量図。1560年時点の湖岸として転記する根拠には使わない。[報告の誌面28〜30頁](https://sitereports.nabunken.go.jp/files/attach/62/62642/139837_1_%E3%81%93%E3%81%BE%E3%81%A4%E6%BD%9F%E6%B9%96%E3%81%A8%E7%A0%82%E4%B8%98%E3%81%AE%E3%82%B7%E3%83%B3%E3%83%9D%E3%82%B8%E3%82%A6%E3%83%A0%EF%BC%9A%E5%8C%97%E5%89%8D%E8%88%B9%E5%AF%84%E6%B8%AF%E5%9C%B02500%E5%B9%B4%E3%81%AE%E8%A8%98%E6%86%B6.pdf#page=32)

台帳には第54次調査の層厚だけを命題として登録した。1450〜1615年は検索用の幅で、堆積の開始・終了日を主張しない。十三湊の地点IDに結び、座標・湖岸の画素は未採用とした。原本はGit外の資料保管庫でSHA-256 `31ca272dbf8a64cbc41f57e8e1d3400e5df54f144486220a87351b671df90e08` を照合できる。

史料台帳を再生成し、出典と年月・地点の索引を検査した。今回の変更は史料入力であり、ゲーム画面の変更は含まない。
