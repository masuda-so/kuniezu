# 天竜川・大井川の比較入力

2026-11-02。城域分割の検証用に、Geofabrik 中部地方 2026-10-31 の OSM 河川中心線を抽出した。実行時の描画・戦国期の河道は変更していない。

入力は `data/inputs/japan-rivers-review/tenryu-oi-modern.json`。天竜川19区間、大井川153区間、計2808点。OSM ID、元の名前、区間 bounds、元ファイルSHA-256、取得URL、作成年、ODbL表示を保持する。日朝共通の既存処理と同じ `fclass=river`・簡略化0.0001度を使う。

名前だけの抽出では他県の同名「大井川」33区間が混入したため、対象範囲（東経137.7〜138.4、北緯34.6〜36.1）で再選別した。最終入力の大井川は東経138.069402〜138.293491、北緯34.765031〜35.633391。天竜川は東経137.789555〜138.053072、北緯34.648907〜36.054553。区間ID重複なし、全座標が有限値、要求名の欠落なしを検査した。

再現用は `tools/geo/select-reference-rivers.py`。`--names` と `--bounds` と `--source-url` を必須にし、同名の別河川を無条件に全国から取り込まない。取得器 `fetch-japan-waterways.py` は地域・スナップショットを指定でき、別日のキャッシュを混用しない。

この入力は現代比較用であり、戦国期の堤防・分流・河口・川幅を確定しない。城域境界の地形コストへ供給する場合も、その境界は史料で確認した政治的境界とは区別する。日本全河川の補完が済んだという意味ではない。

国土数値情報W05も比較候補として確認したが、公開ページの使用許諾が「非商用」のため、今回は再配布する実行時データに採用しなかった。
