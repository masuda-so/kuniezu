# 長久手本戦の局地図

小牧方面の対陣から白山林・檜ヶ根・長久手までを一枚へ詰めた既存図を、戦役の案内と長久手本戦の図に分けた。編集正本は `data/research/conflicts.json`。既存の親9隊・群・経路は保持し、子は池田恒興・森長可・榊原康政・徳川家康・井伊直政の5隊と二つの配置群を表示する。局地図の5隊は全参戦者の人数ではない。

長久手市「長久手古戦場物語」の「6 池田元助」「仏ケ根の決戦」と保存活用計画資料PDFの1頁を再読した。池田元助・永井直勝・安藤直次を関連人物の一覧へ加えたが、記載のない独立隊の座標・兵数・精密経路は作らない。市本文の年齢・出生年の不整合は採用しない。市の保存活用資料は小牧長久手全体と長久手周辺を区別し、塚の建立年代と伝承も述べる。塚の座標を当日の部隊配置とはみなさない。

既存の再生62〜90を子の0〜100へ写し、元経路と元時計を保持して同じ補間を評価する。討死をまとめる説明が池田恒興の討死表示より先に出ていたため、子だけ元時計76相当から80相当へ後送りした。親の文言・時計は変えず、これは史実の時刻の確定ではない。自動表示は1584年5月20日の該当イベントと自家参戦の両条件で接続する。

広域の160×112標高を狭い枠へ拡大せず、国土地理院DEM10Bの原本4枚から局地192×192を生成した。約9.5×9.9m間隔、55〜96m、欠測0。原本URL・SHA・利用条件、生成器と成果物SHAは `data/inputs/nagakute-dem/` に保存した。現代比較標高であり1584年の造成前地表の復元ではない。比較河川は出典付き既存記録から保持し、新規経路を創作しない。

実画面検証で、説明欄の高さが変わってもCanvas親しか寸法監視しておらず、初回とキャッシュ再表示の図幅が異なる問題を再現した。各幅で全経過文と時計ラベルの最大高を一度測って説明欄へ予約し、再生の文章に応じて図が伸縮しないようにした。説明欄も同じResizeObserverで監視し、寸法計算からダイアログのスクロール量を除いた。フォントの読込後と幅変更時には測り直す。940px／335pxで初回・再表示の座標、地理アンカー、幅変更、関連人物の一覧、河川、同日自動表示・翌日拒否・北条拒否を専用Chromeで確認した。

検証：元経路1005標本、部隊・参照・時計・再構築、標高36,864点の独立計算と再生成一致、114場面の地形整合、全場面の密集駒1390フレーム、基本進行・保存・構文のOffline checksに合格。実画面の要約は `data/verification/codex-nagakute-resume/README.md`。歴史上の精密配置や全参加者を確定したという検査ではない。
