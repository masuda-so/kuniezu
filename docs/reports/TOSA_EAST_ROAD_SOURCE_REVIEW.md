# 土佐東街道・室戸半島の路線分離調査

2026-11-02。調査担当はgameを編集せず、入力資料と照合結果のみを追加。

## 判定

現行の「土佐東街道」は歴史的な単一固有路線名と断定しない。高知県の案内では、奈半利と野根を結ぶ山越えの野根山街道と、室戸岬を回る沿岸の遍路道が区別される。参考線の137km閉路を除く際、根拠なく半島の沿岸路をすべて消す方法は避ける。

野根山街道は尾根道約35km。ただし現在の四国のみち整備は1982・1983年度。花折峠の旧道は別役川へ下り、崩壊後に四朗ヶ野峠へ回った。そこからも旧左手ヶ坂〜押野は埋没とされる。したがって現代493号・現整備歩道の線を、そのまま1560〜1615年の本線にしない。

沿岸側は県の2016年みち案内表示シートを比較できる。03入木・06室戸岬・10奈半利を原PDF保存、06を実見。06の赤線は東岸の高岡側から最御崎寺の丘を登り、西岸の坂本・菜生側へ出る。岬先端の車道と寺参道を同じ主線に重複織込みしない。図中には写真や江戸期絵図が重なるため、単純な全画像色抽出にも注意する。

中世以前の宗教者による修行移動と、17世紀後半からの一般民衆による巡礼を区別する。現在の八十八箇所巡回形態を、1560年の確定した全国街道網として扱わない。金剛頂寺には元親の寄進という中世の継続を示す説明があり、沿岸の寺院自体を近代成立として除くこともしない。
