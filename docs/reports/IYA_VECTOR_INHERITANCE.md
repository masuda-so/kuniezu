# 揖屋の干拓地除去と現行ベクターの対応

旧PR44は画像正本へ319画素の湖面復元を行う修正だった。現行正本はベクターなので、
旧PNG変更を再適用する前に、元の修正対象が現行形状でどう扱われるかを確認した。

旧差分の終了列は含まない。319画素の中心を旧投影から実座標へ戻し、製品の
`vector-map.js`の点包含判定で照合した。1560年・1585年・1615年の全てで、
319点は中海の水面内かつ陸地外、周辺対照4点も旧調査時の陸水区分を保っていた。
正本のSHAを結果JSONに記録し、元の差分も比較資料として保持する。

これは旧修正対象の中心点の継承確認であり、画素全域の面積一致や戦国期の
精密な汀線の確定とは区別する。江戸期参照形状の年代上の限界も引き続き扱う。
今回は編集正本の形状・表示コード・年代範囲を変更しない。

検証：`node tools/checks/iya-vector.cjs`、構文・構成・asset stamps・差分検査。
通常配信main `9bc858eb`を専用Chromeで1400px/390px、実倍率2/5.5の4条件で確認した。
319点は全条件で陸地外、JavaScriptエラー0、応答差し替えなし。
湖面が陸色にならないことも画面で確認した。
