# 編集済みGeoJSONの共通描画と位置判定

2026-11-07。経緯度の編集正本を読み、同じ投影で面の描画・位置判定・表示範囲を扱う `vector-map.js` を実装した。形状の合成・平滑化・水面補正は実行時に行わない。穴は外周と内周で判定し、描画時の外周・内周の向きを揃えたnonzero規則で地物間の重なりを和集合として扱い、年代は開始を含み終了を含まない。表示外の面はパスを作らず、作成したPath2Dを再利用する。入力の検査が失敗した場合は既存の面を保持する。

最初の接続先は既存のCODH比較ページ。描画器の重複を避け、比較画面と今後のゲーム接続で同じコードを使う。`codh_preview.py --canonical` は編集済みland/waterを読み、元ファイルの座標・属性を変えない。旧 `--surfaces` との同時指定を拒否する。

Nodeで穴・投影・適用日の境界・画面外省略・パス再利用・入力不変と失敗時の保持を検査。Pythonで比較ページへの編集済み属性・座標の完全保持と安全なJSON埋込み、入力方式の排他を検査した。独立レビューで合成パスの重複部が穴になる問題を修正し、nonzeroで各地物の和集合になることを確認した。パン検査もwheel操作後から独立して比較する形へ修正した。独立Chromeでは368地点の実Canvas塗りと陸判定が一致し、5湖の穴・3地域・パン/ズーム・狭幅・停止時の非再描画・例外0を確認した。[実画面の範囲](../../data/verification/codex-vector-renderer/README.md)を参照。

これは描画器と比較画面への接続であり、ゲーム本体の切替や全地域の史実岸線照合を意味しない。児島湾・香取海の年代候補、八郎潟の採用差分、巨椋池・飯沼・見沼などの採否を確認してから、同じ面を本体の塗り・陰影クリップ・海側選択へ接続する。
