# 大坂冬の陣の戦役と各地の戦闘

候補版、2026-11-10。mainへの反映前。

既存の大坂冬の陣図は、木津川口、今福・鴫野、真田丸、包囲・交渉、和睦を一本の再生で表示していた。戦役の入口を追加し、四つの戦闘を別に案内する。今福・鴫野と真田丸は既存図を使用し、木津川口と博労淵・野田・福島は文章のみ。親の自動再生は除外する。隊位置や兵数、日付の精度は新規追加しない。

出典は大阪府文化財センター『大坂城跡』第2章「位置と環境」印刷9頁。全国遺跡報告総覧公開PDFの抽出本文を読んだ。木津川口から真田丸までの戦闘、和睦、誓書交換を別の日付として記す。PDF画像の該当頁との照合はまだ行っていない。別途目視済みの大阪城天守閣2025年年表でも、今福・鴫野、博労淵・野田・福島、真田丸、和睦交渉、終結を区別している。

出典URLと適用範囲はdata/research/conflicts.json。検査と実画面の証拠はdata/verification/codex-osaka-winter-scope/README.md。全地域の戦闘や部隊配置が確認済みという意味ではない。Claude通信停止を維持しPRは作成しない。

親案内文は和睦専用画面があるように読めない表現に修正した。DB試験1件、広狭の専用ブラウザ、構成・基本検査が通過。独立読み取りレビューで修正必須の問題なし。通常DBは変更していない。
