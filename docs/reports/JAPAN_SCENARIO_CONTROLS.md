# 日本の勢力選択と速度ボタンの状態

## 修正

戦略地図が描く城の共通判定 `vector.strategyCastle` を勢力選択にも使い、日本側の城を持つ家だけを一覧・初期選択・選択確定に通す。「諸家」の一覧と、家が滅亡した後の継続先・選択確定も同じ判定を使う。朝鮮の歴史データや個別合戦図を削除する処理は加えない。対馬は九州の地域に含める。現行史実観察の家臣開始の可否は既存の `G.preList()` に従う。

速度ボタンの `aria-pressed` は実行中の速度または停止中の選択速度に一致させる。一時停止は再生ボタンが表すので、停止しただけで速度の選択を解除しない。日内時刻、日数の速さ、保存形式は変更しない。遊び方の再生位置は「画面下部」、履歴へ戻る操作は「時間軸」、史料の入口は「操作」→「合戦と史料」と、実際の表示へ揃えた。
