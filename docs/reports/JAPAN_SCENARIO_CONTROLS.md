# 日本の勢力選択と速度ボタンの状態

## 修正

戦略地図が描く城の共通判定 `vector.strategyCastle` を勢力選択にも使い、日本側の城を持つ家だけを一覧・初期選択・選択確定に通す。朝鮮の歴史データや個別合戦図を削除する処理は加えない。対馬は九州の地域に含める。現行史実観察の家臣開始の可否は既存の `G.preList()` に従う。

速度ボタンの `aria-pressed` は実行中の速度または停止中の選択速度に一致させる。一時停止は再生ボタンが表すので、停止しただけで速度の選択を解除しない。日内時刻、日数の速さ、保存形式は変更しない。

## 範囲

城数の集計、合戦図の表示範囲、年代別当主の訂正は別対象とする。勢力や城を史料なしに追加しない。元のファイルSHAは ui.js `089f9f7ceb2b28c91948c9a74daa51a709d5182d601c638426df7dbf19a8e9e9`、テンプレート `0dfcd36ff59973e06d048d4aaf852ff968a3d5ff30b0b8939d8b213f02ae9189`。作業基点は main `8a4749cc`。

## 検査

構文、organization、asset stamp、差分検査に合格。実画面は専用Chromeで検査し、結果は `data/verification/codex-japan-scenario-controls/` に保存する。最初のサンドボックス内起動ではChromeが存在しないことを確認して検証プロセスのみ終了し、権限を付けた専用Chromeで再実行した。サーバーの起動・停止は行っていない。

専用Chromeの最終実行は15ケース・速度の広狭操作・保存復元に合格し、実行時例外0件。[実画面の要約](../../data/verification/codex-japan-scenario-controls/README.md)を参照。

`offline.cjs` の全必須回帰に合格。生成監査の差分をローカル証拠へ保管し、作業前の監査ファイルをSHA確認付きで復元した。
