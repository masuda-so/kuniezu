# 本体地図のベクター描画接続

2026-11-07。PR77の編集済み陸・水域・岸線をゲーム本体へ接続した。物理形状を実行時に合成・修正せず、配信manifestのSHAとバイト数を確認してから一括採用する。年代区間ごとにclipを再利用し、塗り・陰影・道路/河川のクリップ・海側選択をそろえる。支配色と陰影の画像は継続する。

輪郭不明の3水域は地名点、椿海は推定表示の別層。未知背景は標高の推論対象から除く。海模様を維持し、旧湖面と新湖面を重ね描きしない。外交の首都間曲線を取り除き、境界だけで表す。朝鮮の城・施設・地名は戦略地図から除外し、内部の史実・合戦データは削除しない。

比較画面とは別に、起動中のDjangoと一時Chromeで検証した。試作時の応答差替えで射影初期化順の不具合を発見し、`G.build()`後の初期化へ修正した。その後、応答差替えなしの実配信でタイトル・1560年シナリオ・広幅/狭幅・回転・全図を確認した。取得失敗は起動オーバーレイと再読込を維持し、部分的な正本を採用しない。

本変更で城の所属・行軍の道筋・史実日時・保存形式は変えない。児島湾の旧格子由来の段差は解消したと扱わず、原図と年代を照合して形状を編集する対象として残す。履歴DBや全国施設・人物の網羅の完了証拠にはしない。

検証の要約は `data/verification/codex-vector-game-renderer/README.md` と `codex-vector-game-source-failure/README.md`。読込順はテンプレートとmodules台帳を一致させ、asset stampも更新する。

海側の街道は別キャンバスへ描いて陸面の和集合を消す方式にし、重なる陸面を偶奇の逆クリップで海へ戻さない。実Canvasの重なりfixtureで陸2点のalpha0・海のalpha255を確認した。旧陸LODの先行生成は止め、街道LODだけを準備する。領域の共有辺が未着の時に旧領域の海岸輪郭を再描画しない。

本体の変更後に `march-clock-browser.cjs` も実行し、停止/再開の同位置・桶狭間の段階移動・地図読込完了・狭幅・光秀の家紋/陣営色を確認した。JavaScript例外0。[検査要約](../../data/verification/codex-vector-march-battle/README.md)。検査用Chrome終了後は一時プロフィールも削除する。
