# 設楽原の局地戦図

長篠の既存素材には長篠城・鳶ヶ巣山・設楽原が混在していた。戦役の入口から三つの局面を案内し、設楽原だけは本戦11隊と既存の4配置群に絞った。城攻防と鳶ヶ巣の新しい図は作らず、元の14隊の素材も変更しない。

親の再生35〜100を子の0〜100へ写し、参陣・射撃・寝返り・討死・退却・可視期間・経過文を同じ時計で変換する。元のpathと時計窓を保持して補間するため、切断区間で緩急の曲線を作り直さない。医王寺から設楽原への窓より前の移動は子へ持ち込まない。これは既存の参考アニメーションの切出しであり、各隊の動きを新たに史実確定したものではない。

標高の元ファイルは共有し、元の経緯度範囲から局地枠へ投影する。河川・部隊も同じ枠を使う。地形の解像度を新たに高めたものではなく、公式図葉・歴史上の戦場境界を確定した枠でもない。背景キャッシュは場面名と範囲を区別し、親子で誤った地形や地名を共有しない。

自動表示は、実イベントキューの発生日と子の開催日が一致し、自家参加の条件を満たす場合だけ設楽原へ接続する。戦役のCanvasは生成しない。時刻不明の旧キューや別日は接続しない。長篠のユリウス暦6月29日を別日へ移動しない。

検証：11隊・2211点の元path一致、時計と参照閉包、50点の標高投影、実際の1575年シナリオ進行でのキュー接続、別日拒否、再構築を検査。113場面の布陣・111の既存地形の検査も合格。専用Chromeの940px／335pxで親子遷移、11隊、地形と連吾川、キャッシュ再利用と幅変更後の位置を確認した。JavaScript例外0件。
