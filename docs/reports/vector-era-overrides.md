# ベクター移行時の香取海補正の保持

2026-11-07。江戸末期CODH原本への移行で既存の年代補正と採否条件を失わないよう、香取海の参照入力と準備器を追加した。新しい歴史上の汀線を確定した変更ではない。

`kuniezu/map/edits/vector/manifest.json` に原本SHA、1560-01-01以上1616-01-01未満という年精度の表示期間、推定という区分、採用featureの組を保持する。準備器は水面1・保護陸1・後世比較岸1・描画禁止切口5の計8featureを、元の座標・属性と同一のまま取り出す。水面の全周を岸として描くことは許可せず、五切口が欠けた入力を拒否する。保護陸には元々独立した年代・精密岸の主張がなく、その不在も保持する。

既存画像の年代差分コンパイラが直下のJSONを走査するため、新契約は `edits/vector/` へ分離した。実コンパイラの小さな一時正本試験にも同じmanifestを置き、従来の生成を阻害しないことを確認する。

検証：境界年、8featureの座標・属性一致、切口/保護陸欠落、SHA相違、精密岸への誤昇格、逆期間、範囲外パス、既存出力保護の12試験。既存province-edits実コンパイラ試験も合格。実行例でGeoJSONを生成した。この段階ではゲーム表示を変更しておらず、新しい実画面の改善を主張しない。

児島湾の旧マスクは旧window行12823に対し、現行宇喜多差分は12031。差792は `rowsDroppedFromV2` と一致する。旧windowへ現在の原点を直接使わず、元の格子との対応を検証する必要がある。1584年の切替は年精度の仮定を保持する。児島湾のマスクは100mの採用範囲であり、ベクター化しても史実の精密汀線にはならない。
