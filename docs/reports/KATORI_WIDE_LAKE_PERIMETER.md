# 外浪逆浦の広い湖面：外周と補正境界を分離

親担当の追加指示に従い、接続検証用の内側帯に代えて、迅速測図で読める外浪逆浦の広い湖面の外周を一周した候補を作成した。`wide-lake-perimeter.geojson` の `uchinasaka-combined-wide-water` が内湖・口部を含む適用候補。`outer-lake-wide-perimeter` は外湖だけの比較用構成要素で、両者を二重適用しない。

**1880年代の比較岸を使った推定復元であり、1560年の確定汀線ではない。** 水面内部だけをつないだ従来の893セルと外周を区別し、湖の幅を復元する。原図の細かな入曲・浅瀬・砂州側を読図し、丸や直線で湖形を置換していない。

水面を横切って補正範囲を閉じる辺は5本あり、全て `water-mask-boundary` として明示した：北浦内、東側水路、南側狭窄河道、西側旧河道、北西の霞ヶ浦側開口。これらは岸でも堤でもない。南端は旧仮切断より先の狭窄部まで延ばし、元の切断線は水面内部へ取り込んだ。

## 実装条件

- 水面の適用には `uchinasaka-combined-wide-water` のみを使い、南東保護陸を優先する。
- 多角形の全周を岸線として描かない。比較図は `outer-lake-comparison-shores` を使い、ゲームの画像由来岸線は5つの補正境界のマスクを除外する。
- マスク幅150mは100m格子の量子化を覆う描画上の余白で、歴史上の川幅ではない。
- 現行陸水判定が補正範囲外で陸のままなら、水系全体の連続性や船の通行が修復済みとは扱わない。今回の成果は湖本体の表現改善である。
- 南端から最寄りの海へ線を作る変更、昭和盛土の標高で古水域を消す処理、根拠のない年次形状切替は加えない。

`wide-lake-overlay.png` は青が読図した水際、桃色が岸にしない補正境界、緑が保護陸。現行北浦との重複、4近傍連結、確認点、保護陸との競合を `wide-lake-verification.json` で検査した。検査は局所100mタイル1枚で実施し、共有・game正本は変更していない。

出典・河道の年代上の制約は `sources.md` と独立採用報告を継承する。[香取市Vol.209](https://www.city.katori.lg.jp/culture_sport/bunkazai/isan/201-210.html)が説明する明治の河道分離を踏まえ、迅速図の出口を現代河道へ無条件に吸着させていない。

検査結果：1,719/1,719セルが4近傍で連続。前回893セルを全て保持し826セル追加。既存北浦82セルと重複、保護陸との競合0、確認5点一致。元の南端切断線101標本は全て新水面内部。


## 隔離ブランチへの実装・検査

`codex/katori-uchinasaka`（基準3395a47）で正本 `provinces.png` に適用した。既存湖区画 `lake:140.55,36.05` を維持し、陸1,637セルを水へ訂正、既存水面82セルは保持した。形状と正本の確認値は `source-application.json`。

新しい仕様として、`game/map_data/shoreline_masks.geojson` に保持した補正範囲の水上辺を、`tools/map/shoreline-masks.cjs` が読み、境界生成時に岸線から除外する。位置はコードに直書きしない。対象はcoast/lakeだけで、領域境・国境は変更しない。縮小段は画素の量子化幅を考慮して除外の余白を追加する。補正外の河道や船の通行まで復元済みという意味ではない。

`build-map.cjs` で正本から再生成後、raster-map・province-editsを実行。`katori-water.cjs` で湖面1719、保護陸70、全段・全年代360220岸線区間を検査した。専用Chromeのfile://候補を3段階ズームで確認し、湖内3地点と保護陸・北岸の分類、JavaScript例外0を確認。証拠は `data/verification/codex-katori-water/`。共有サーバーの起動・停止や共有作業ツリーへの適用は行っていない。

通常再生成: `node tools/map/build-map.cjs`。局所再検査: `node tools/checks/katori-water.cjs`。実画面再検査: `node tools/checks/katori-water-browser.cjs`（既定は当該作業ツリーのfile://、既存HTTPにはGAME_URLを指定）。生成物はGit追跡せず正本と生成器を管理する。
