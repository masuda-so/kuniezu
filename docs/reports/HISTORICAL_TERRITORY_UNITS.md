# 1560〜1615年の領域単位と移行方針

## 現行区分の判定

全国共通で、城にひも付く137区画を歴史上の最小行政区分として使う根拠はない。城は地点・拠点として維持する。日本の支城区画は本城の既存領域を直線距離で分割する（`game/territory.js`）。朝鮮の道は現代行政区の組み替えを含み、道内の区画は拠点距離と人工的な揺らぎで生成する（`tools/geo/korea.py`）。どちらも色を割り当てるための区画としては使えるが、国・郡・村、道・府牧郡県の実際の範囲や、時期別の領有を立証しない。朝鮮の倭城は日本側軍事拠点として登録し、所在する府牧郡県の行政帰属は別に保持する。北辺の軍鎮・明の衛所も同じく行政境界とは別に扱う。

統合側の100m基準版の全域監査（`data/audits/raster-provinces-audit.json`）では新発田が湖、箕輪・古処山が別の城区画に入り、50画素以上の分離成分が278件ある。済州島の大きな成分は順天に帰属し、監査上の距離は約177km。分離成分には島や史実の飛び地もあり得るので、一律に埋めたり削ったりせず、根拠・誤割当・未確認に分類する。画素が一つのIDを持つという意味での網羅性と、史料に照らした地理・領有の網羅性は別々に検査する。

## 原子セルと日付付きの関係

- 空間の最小単位は共通100m格子の行・列。表示用の400m・800mは派生。時期別の海・湖・陸を先に決め、陸のうち行政資料が不足する画素にも未確定の値を持たせる。
- データ編集の最小単位は、根拠が共通して割当を更新できる地片。地片のIDは城名や領主名から独立させる。村や郡県を区切れる場合はそのまとまりを使い、複数の根拠付き境界が交差する箇所だけ分割する。同一地片が時代ごとに別の行政単位に属することを許す。地片IDと画素IDの対応は版付きで管理する。
- 行政所属、領主・知行、軍事占拠、城の管轄を別種の関係として、対象ID・有効期間 `[from,to)`・日付精度・出典・対象地片・確度を持たせる。日付と対象IDから引ける索引を同じ記録から生成し、年代×全対象の全量コピーを避ける。占拠と知行が並存する場合は両方を保持する。同種・同時期の対立証拠も保持し、表示は係争・不明の区分を設ける。
- 城の表示領域は、当日にその城の管轄が確認できる地片の和集合として生成する。島を自動で対岸の城に接続しない。帰属の裏付けがある飛び地は別成分のまま残す。境界の線が不明な場合は既知の集落・河川・峠と範囲を記録し、行政境界を架空の精密線にしない。

## 移行と検証

1. 城ID、城の実座標、既存保存の勢力・人物・部隊・日付は保持。区画の表示は別レイヤーで切り替え、旧区画から新地片への重なりは版付きの監査表にする。面積最大の勢力への自動置換はしない。旧保存をロードし、城主・部隊とイベントキューが変わらないことを比較する。
2. 既存の領土移転イベントは城の状態変更を維持したうえで、当時の記録が支持する場合に限り、対象地片・効力日・関係種別を追加する。城の明渡し日と、周辺の郡や村の知行移転日は独立して照合する。
3. 行軍は街道ノードと城門・渡し・上陸点などの地点IDを到着先とする。地片の中心や城の管轄境界を到着点に使わない。境界を切り替える前後で経路座標と到着日が同じことを確認する。
4. 日本と朝鮮で同じ検査を走らせる。全域の重複・欠落・水上割当・分離成分・拠点位置を集計し、出典付きの行政区と推定区を分けて表示する。初回の比較例は新発田・箕輪・古処山・済州。北辺の境域と海峡を含め、史料の確度に応じた線と色を実画面で確認してから切り替える。

### 新発田の水域判定

基準の `game/geo.js` にある湖0は外周13点で、新発田城の代表点が南縁付近に入る。市の発掘報告第60集は新発田城と城下町を扇状地の北西部に置き、支流を利用した堀と周辺の沼潟を区別する。城の座標を陸へ動かす修正は見送り、湖0の南端を照合する。1721年の干拓前絵図と、発掘報告第164集第10図の干拓直後の古地理を別年代の資料として比較する。ここから戦国期の正確な南岸はまだ確定できない。 [新発田市・発掘報告第60集](https://sitereports.nabunken.go.jp/files/attach/40/40786/90622_1_%E8%8F%96%E8%92%B2%E6%B2%BC%E9%81%BA%E8%B7%A1%E3%83%BB%E5%8F%B5%E4%BB%8F%E5%A1%9A%E9%81%BA%E8%B7%A1%E7%99%BA%E6%8E%98%E8%AA%BF%E6%9F%BB%E5%A0%B1%E5%91%8A%E6%9B%B8.pdf) · [新発田市・紫雲寺潟絵図](https://adeac.jp/histlib-shibata/catalog/ct00000030) · [新潟県・発掘報告第164集](https://sitereports.nabunken.go.jp/files/attach/33/33132/24225_1_%E9%87%8E%E4%B8%AD%E5%9C%9F%E6%89%8B%E4%BB%98%E9%81%BA%E8%B7%A1%E7%A0%82%E5%B1%B1%E4%B8%AD%E9%81%93%E4%B8%8B%E9%81%BA%E8%B7%A1.pdf)

発掘報告第164集の印刷8〜9頁を再確認した。第8図が1645年越後国絵図の復元図、第10図は干拓直後の古地理で、別の時点を示す。本文は1645年図の南側の張り出しについて、住吉・大中島・片桐・俵橋・湖南の集落に対応する可能性を示す。この5地点を現地座標へ照合する候補とし、南岸上の既知点とは扱わない。加治川・胎内川の現河口は付替えの影響を受けるため、固定点に使わない。1721年図は個人蔵の神田家文書1834。市の目録には二次利用の問い合わせが明記されているため、現段階では画像を配布物に含めず、資料番号とIIIF参照先を記録する。 [発掘報告第164集](https://sitereports.nabunken.go.jp/files/attach/33/33132/24225_1_%E9%87%8E%E4%B8%AD%E5%9B%9B%E6%89%8B%E4%BB%98%E9%81%BA%E8%B7%A1%E7%A0%82%E5%B1%B1%E4%B8%AD%E9%81%93%E4%B8%8B%E9%81%BA%E8%B7%A1.pdf) · [市の絵図目録](https://adeac.jp/histlib-shibata/catalog/ct00000030)

町字の図形中心（経度、緯度）で現行の湖0を点検すると、片桐 (139.345016, 38.000594) は内側、湖南 (139.354147, 38.008334) と中俵 (139.359260, 38.014701) は外側、新発田城 (139.326, 37.955) は内側だった。町字中心は岸の測点ではないが、湖0の範囲（北緯37.945〜38.007度）と報告書が挙げる南側の地名群を突き合わせると、城付近の数画素を抜くだけでは湖0の形を説明できない。中俵は幕末の俵橋新田との重なりを示す比較候補。市の町名一覧は大中島と中島を別々に掲載しており、住吉遺跡は現在の住吉町でも住吉の町字中心でもなく、中島字住吉108番地ほか。次の位置合わせでは町字中心を固定点にせず、発掘図に載る住吉遺跡の調査区と中世の微高地を陸側の検証点に使う。 [片桐](https://geoshape.ex.nii.ac.jp/ka/resource/15/152062180.html) · [湖南](https://geoshape.ex.nii.ac.jp/ka/resource/15/152061750.html) · [中俵](https://geoshape.ex.nii.ac.jp/ka/resource/15/152061930.html) · [俵橋新田](https://geoshape.ex.nii.ac.jp/av/resource/K13/K13G06S00613.html) · [新発田市・町名一覧](https://www.city.shibata.lg.jp/_res/projects/default_project/_page_/001/001/253/chikubetsu2.pdf) · [新発田市・住吉遺跡](https://www.city.shibata.lg.jp/_res/projects/default_project/_page_/001/001/555/202103251.pdf)

中世の陸側・水側の判定には、遺跡名だけでなく層序を使う。新潟大学公開論文の図4a・4bは、国土地理院1:25,000「新発田」「稲荷岡」上に野中土手付・砂山中道下・住吉の調査地点を掲載する。図5aと本文は、野中土手付で古墳・平安期の遺構を覆う泥炭質の層を14〜15世紀の潟の堆積物と解釈する。一方、発掘報告第164集では砂山中道下は流入河川がつくった自然堤防上の中世集落。古い遺構があるという理由で野中土手付も陸に分類する扱いは誤りとなる。湖岸案の検証では砂山中道下・住吉を中世の微高地、野中土手付を中世の潟堆積候補として別々に使う。各地点の測地座標と対象時期の地形継続を確認してから採用する。 [新潟大学公開論文、88〜89頁・図4・5](https://niigata-u.repo.nii.ac.jp/record/28031/files/20_81-104.pdf)

全国文化財総覧の住吉遺跡（遺跡番号580、2012〜2013年の調査）の登録点は世界測地系で東経139.339722度、北緯38.000833度。既存の湖0に対して偶奇則で内側、ゲームの投影距離で外周から約347mだった。発掘報告の微高地を町字の中心から分けて再現できる検証点であり、報告書が扱う中世集落の年代とゲーム開始時点の間には差がある。湖岸案の検証では、登録点を一点の測量境界とみなさず、調査区範囲と照合する。 [全国文化財総覧・住吉遺跡](https://sitereports.nabunken.go.jp/en/69863)
