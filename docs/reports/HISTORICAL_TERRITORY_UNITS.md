# 1560〜1615年の領域単位と移行方針

## 現行区分の判定

全国共通で、城にひも付く137区画を歴史上の最小行政区分として使う根拠はない。城は地点・拠点として維持する。日本の支城区画は本城の既存領域を直線距離で分割する（`game/territory.js`）。朝鮮の道は現代行政区の組み替えを含み、道内の区画は拠点距離と人工的な揺らぎで生成する（`tools/geo/korea.py`）。どちらも色を割り当てるための区画としては使えるが、国・郡・村、道・府牧郡県の実際の範囲や、時期別の領有を立証しない。朝鮮の倭城は日本側軍事拠点として登録し、所在する府牧郡県の行政帰属は別に保持する。北辺の軍鎮・明の衛所も同じく行政境界とは別に扱う。

統合側の100m基準版の全域監査（`data/audits/raster-provinces-audit.json`）では新発田が湖、箕輪・古処山が別の城区画に入り、50画素以上の分離成分が278件ある。済州島の大きな成分は順天に帰属し、監査上の距離は約177km。分離成分には島や史実の飛び地もあり得るので、一律に埋めたり削ったりせず、根拠・誤割当・未確認に分類する。画素が一つのIDを持つという意味での網羅性と、史料に照らした地理・領有の網羅性は別々に検査する。

## 原子セルと日付付きの関係

- 空間の最小単位は共通100m格子の行・列。表示用の400m・800mは派生。時期別の海・湖・陸を先に決め、陸のうち行政資料が不足する画素にも未確定の値を持たせる。
- データ編集の最小単位は、根拠が共通して割当を更新できる地片。地片のIDは城名や領主名から独立させる。村や郡県を区切れる場合はそのまとまりを使い、複数の根拠付き境界が交差する箇所だけ分割する。同一地片が時代ごとに別の行政単位に属することを許す。地片IDと画素IDの対応は版付きで管理する。
- 行政所属、領主・知行、軍事占拠、城の管轄を別種の関係として、対象ID・有効期間 `[from,to)`・日付精度・出典・対象地片・確度を持たせる。日付と対象IDから引ける索引を同じ記録から生成し、年代×全対象の全量コピーを避ける。占拠と知行が並存する場合は両方を保持する。同種・同時期の対立証拠も保持し、表示は係争・不明の区分を設ける。
- 城の表示領域は、当日にその城の管轄が確認できる地片の和集合として生成する。島を自動で対岸の城に接続しない。帰属の裏付けがある飛び地は別成分のまま残す。境界の線が不明な場合は既知の集落・河川・峠と範囲を記録し、行政境界を架空の精密線にしない。

## 移行と検証

1. 城ID、城の実座標、既存保存の勢力・人物・部隊・日付は保持。区画の表示は別レイヤーで切り替え、旧区画から新地片への重なりは版付きの監査表にする。面積最大の勢力への自動置換はしない。旧保存をロードし、城主・部隊とイベントキューが変わらないことを比較する。
2. 既存の領土移転イベントは城の状態変更を維持したうえで、当時の記録が支持する場合に限り、対象地片・効力日・関係種別を追加する。城の明渡し日と、周辺の郡や村の知行移転日は独立して照合する。
3. 行軍は街道ノードと城門・渡し・上陸点などの地点IDを到着先とする。地片の中心や城の管轄境界を到着点に使わない。境界を切り替える前後で経路座標と到着日が同じことを確認する。
4. 日本と朝鮮で同じ検査を走らせる。全域の重複・欠落・水上割当・分離成分・拠点位置を集計し、出典付きの行政区と推定区を分けて表示する。初回の比較例は新発田・箕輪・古処山・済州。北辺の境域と海峡を含め、史料の確度に応じた線と色を実画面で確認してから切り替える。
