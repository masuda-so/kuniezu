# 大坂夏の陣と最終決戦の表示範囲

## 問題と変更

既存の「大坂夏の陣」図は、deploymentKind=field、説明が五月七日の主戦場、茶臼山・四天王寺・岡山口の隊配置だった。戦役名で最終決戦だけを見せていたため、戦役の入口を設けた。

編集正本data/research/conflicts.jsonに親「大坂夏の陣」と四つの子を追記。樫井は文章のみ、道明寺と八尾・若江は既存図へのリンク、天王寺口・岡山口は既存夏の陣図を再利用する。新たな兵数、隊位置、移動時刻は加えていない。独立レビューで翌八日の死亡演出の混入が見つかったため、既存の局地戦フィルターで元の演出時計0〜95の範囲へ限定し、96の翌日説明と秀頼の死亡表示を除いた。この数値は史実上の時刻ではない。元の行路を保存し、子時計から元時計へ変換する。親を一つの合戦として自動再生せず、手動の入口から個別図を選ぶ。既存の114図と年表全体のJSON一致を確認した。最終決戦図だけ一つ増える。

## 出典と読んだ範囲

大阪城天守閣『大阪城ゆかりの地マップ 大坂の陣』2025年5月発行、PDF第1頁「大坂の陣年表」。公開URL: https://www.osakacastle.net/pdf/leaflet/yukari-osakanojin_202506.pdf 。2026-11-10取得、SHA256 cae52e7729ef12b2a02f1badac1600dec97aa1984bead30996f70e2520aeb4a5。

第1頁をPNGへ描画して目視した。四月末の樫井、五月六日の道明寺と八尾・若江、七日の天王寺口・岡山口と城の落城、八日の秀頼らの自害と終結を別項目としている。最終決戦の旧暦五月七日を1615年6月3日として子図に付す。採用済みosaka-fall-1615命題とも一致。元の年表イベントは翌八日に終結を扱っているため、その日付を最終決戦の日に書き換えない。

資料の後続ページの個別史跡や精密な布陣は今回の検証範囲外。墓・顕彰碑の現代座標から隊の精密位置を作らない。既存図の各配置を今回全て確認済みとしない。
