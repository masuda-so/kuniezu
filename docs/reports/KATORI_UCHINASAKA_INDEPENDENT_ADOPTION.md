# 内浪逆浦：古水域復元の独立採否

2026-11-04。**湖本体・口部・外水域の内部を、1560〜1615年の推定古水域として採用する。** 現代造成後の陸地を残すより資料と整合する。既存4候補の893セルは全て連続し、北浦の既存水域へ接続する。これは測量済みの戦国期湖岸という意味ではない。

## 根拠と限界

橋本直子（葛飾区郷土と天文の博物館）の[論文『sabo』110・6頁](https://www.stc.or.jp/journal_sabo/pdf/SABOVol.110.pdf)は、中世の佐原〜潮来周辺に内浪逆浦・外浪逆浦などの湖沼があったと明記する。原PDF8頁を実見した。これは1885年図とは独立した湖の存在の根拠で、同時代の測量図ではない。

[潮来町史338頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index350.html)の文禄・慶長期の七軒島、[343頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index355.html)・[348頁](https://lib.itako.ed.jp/statics/digitalArchive/001/HTML/index360.html)の徳島の離洲・湖沼利用は、水面と洲が併存したことを補強する。正保提出図の原図自体は未取得で、町史342頁の年代不明村絵図を正保図とはしない。

1654年以後の堆積だけから「1885年水域は必ず1560年水域に含まれる」とは言えない。[井内・斎藤、1993年、62頁](https://www.kubota.co.jp/urban/data/32.pdf)は小水位変化と堆積速度の地域差を論じる。したがって今回の採用は、古い湖の存在と後世の地形図を組み合わせた明示的な推定復元である。

## 反映する範囲

| 対象 | 採否 |
|---|---|
| 湖本体142・口部140・外水域194・外水域南側518セル | 重複を除く893セルを推定水面内部として採用。外周すべてを確定岸にしない。 |
| 南東の舌状陸70セル、北岸の耕地確認点 | 今回は水域化から除外。洲を残すが16世紀の名称・厳密な島形は断定しない。 |
| 北岸葦原の確認点 | 推定湖縁・湿地扱い。恒常開水面の確定点に数えない。 |
| 外水域南端の斜めの切断線 | **岸として描画禁止。** 続く水面へ接続してから最終描画する。 |

南端の禁止線は **[140.61744690,35.89405652] → [140.61538696,35.89280494]**（迅速図上[468,476]→[456,485]）。比較範囲を閉じただけの水上の辺であり、そのまま岸にすると存在しない堤を作る。`adoption-regions.geojson` に線として収録した。これは正本へ反映する際の統合条件であり、新たな精密汀線の発見待ちを要求するものではない。

現代DEMの盛土標高による旧湖内の陸戻し、日の出地区196ha全域の水没、根拠のない1590/1603年の形状切替は採用しない。南東舌状陸を徳島・大洲と同定していない。

## 検査・引き渡し

100m格子中心の包含判定と4近傍探索を独立に実施：893/893セル接続、保護陸との競合0、確認6点の採否一致、全形状有効。格子は起点Y=-761.604024434064の現行記録を使用（旧記録の行番号から792行変更）。全域画像の展開・ブラウザ・ゲーム正本の編集は実施していない。
