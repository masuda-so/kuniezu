# 東山道の現代比較線の戻り道

2026-11-09。東山道の編集正本から、同じ地点へ戻って本線を続ける約6.508kmの巡回を除いた。分岐元は経緯度138.668234,36.369844。別の場所へ進んでいるように見える参考線の整理であり、戦国期の精密中心線や歴史上の支線の不存在を確定した変更ではない。

対象は `kuniezu/map/physical/roads-reference.geojson` の `road-8856a17b4601`。0始まり4015..4145の始終点は同一点で、4015を残し続く130点だけを除く。元の帰還後の辺をそのまま使うため、新しくつなぐ直線は0本。対象外の点列・他84路線・ID・現代比較の格付けは保持する。

[採否記録](../../data/inputs/road-adoptions/tosando-reference-loop-2026-11-09.json)に前後のSHA、取り除いた全座標、旧比較入力との対応を保持する。旧移行記録は書き換えず、検査がこの明示差分から移行時の点列を復元して照合する。描画時にループ除去を追加せず、編集済み正本を共通readerで読む。

旧比較入力137点に現在の131点が順序を保って含まれる。粗い入力の経由点138.7,36.36を満たす現代比較線の巡回と整合し、独立した根拠付き支線としての登録はない。現行施設点・主城点は閉路内にない。元OSRM生応答の全legsの再読ではないため、生成経緯の完全再現とはしない。

[安中市「道の駅」基本構想](https://www.city.annaka.lg.jp/uploaded/attachment/11011.pdf)印刷4頁は古代東山道・戦国期の争奪・1602年中山道指定を区別する。これはこの巡回を史実本線とする根拠ではない。現代比較線の技術的採否と歴史上の峠道の全区間照合を分け、周辺の歴史的道路を新造・削除したとは扱わない。

保存形状版を24から25へ進める。既存の移行処理で、進行中の軍・単独人物の保存時の日内位置を新経路の始点とし、目的地と到着時刻を維持する。旧形状上にいた場合の位置から道へ戻る接続は保存互換のためであり、新しい史実街道を登録するものではない。待機中・帰還中も検査し、一度更新した保存は再更新しない。

## 検証

- `road-vectors.cjs`：85路線136,648頂点、採用後の道路網56,940点、代表3経路991点を確認。描画・移動の点列同一性、正本非書換え、旧移行記録の復元SHAを検査。
- `tosando-reference-loop.cjs`：新辺0、対象外点列維持、旧24版の実際の旧点列を用いた合成単独移動保存の位置・目的地・到着日、資源・軍・人物・所有状態、冪等性を確認。合成fixtureを史実の人物行程としない。
- `movement-save-position.cjs`：22・23・24版の出陣・帰還・待機と単独人物の位置・到着時刻を確認。
- `movement-save.cjs`：旧線の更新、日付・領土・兵力・日内時刻、非史実保存の拒否を確認。

親担当による専用Chrome検証も通過。root main d2803781へ候補3配信物だけを差し替え、広狭4画面、座標SHA、点列とreader、合成旧保存の位置・着陣時刻、例外0を確認した。[証拠要約](../../data/verification/codex-tosando-reference-loop/README.md)に方法と担当を記録した。構造検査だけで視認性や史実上の全線照合を完了としない。

## CI読込確認値の同期

初回PRのCIでは、ゲーム基本検査は通過したが `Asset version stamps` が `scenario-openings.js` の古い読込確認値を検出した。手元ではこの独立した確認を実行していなかった。最新mainを公開履歴を書き換えず署名マージし、`stamp-assets.cjs` で専用ツリーのテンプレート確認値1件を生成同期した。`stamp-assets.cjs --check`、採用道路・旧保存位置・和睦日付移行の焦点検査を再確認した。
