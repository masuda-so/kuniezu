## 判断の要点

- 掲出日を主たる出来事の日とし、「尋で」や先行する行程の日付を混ぜない（#132 の Codex のレビューの基準）。三増峠は、信玄の上野・武蔵の通過と小田原城下への放火を同じ条に書くが、掲出日は三増峠の戦いに限った。小田原は相模への進入の日で、攻囲は日付にしない。
- 主君・攻められた城の主など、名だけが出る人物（大友義鎮・島津義久・北条氏康の小田原の件）は結ばない。人物の ID が無い者（臼杵鑑速・吉弘鑑理・三好三人衆・一揆の加担者）は結ばない。
- 浅井長政は、既存の命題の人物 ID `person:浅井賢政` に結んだ。
- 新しい台帳の場所：川中島・国府台・休松・三増峠・姉川・三方原・槙島城・延暦寺・四天王寺・木津川口・上月城・高倉山・御館・日向の高城・有岡城・大河内城・備中高松城・堺・若神子・黒駒・上田城・戸次川・韮山城・松井田城・碧蹄館・幸州山城・巨済島・鳴梁・田辺城・小山・浅井畷・大津城・石垣原・長谷堂城・今福・道明寺・八尾若江の 37（座標は主張しない）。
- 耳川は、是日の戦いの起きた高城を出来事の場所とし、追撃の先の耳川は結ばない。
