# 黒田長政の1600年所在記録と行軍表示の接続

確認日：2026-11-03。対象は史実観察、黒田長政の大坂天満での婚儀から関ヶ原出陣まで。

## 修正した不整合

本拠の中津城と管理領域の香春岳を区別しても、1600年開始時の人物 `loc` が姫路のままなので、表示と次の移動の起点に姫路が残っていた。また、8月30日の「東海道の城を家康へ」による清洲への管理ノード変更を、長政自身の清洲到着と同一視できなかった。

既存の `historical-register.js` に `TK.PERSON_LOCATION_ITINERARIES` を置き、同じ人物の史料上の所在と、戦闘・領国管理に使う `loc` を分離した。新規の人物専用モジュールは増やしていない。所在表示中は既存の `G.documentedPerson` / `G.castleGens` の共通経路により姫路の在城兵としても扱われず、清洲に移る管理イベントで地図の位置は変わらない。

## 採用した記録

出典は貝原益軒『黒田家譜』を収める[『益軒全集』巻5、益軒全集刊行部、1911年](https://dl.ndl.go.jp/pid/1023982)。原画像の読図と限定採用は `KURODA_1600_ITINERARY_SOURCE_REVIEW.md` と `data/inputs/kuroda-itinerary-review/` に保持する。家譜は後世の編纂史料であり、同時代の日記と同じ性格ではない。

| 旧暦日付 | 所在・行動 | 原頁 | 接続する所在ID |
|---|---|---|---|
| 1600年6月6日 | 大坂天満の屋敷で婚儀 | 巻9、263–264頁 | `location:kuroda-nagamasa-osaka-tenma-1600` |
| 1600年7月5日 | 伏見を出発 | 巻9、268頁 | `location:kuroda-nagamasa-fushimi-departure-1600` |
| 1600年8月14日 | 先陣諸将が尾張に到着、清洲・名古屋近村に着陣 | 巻10、281頁 | `location:kuroda-nagamasa-kiyosu-arrival-1600` |

巻10、279頁の「宇都宮まで下り、小山へ帰る」という順序は、7月5日と8月14日の間の無日付経由地として保持する。これは282頁の「厚木から再召還された先が小山か江戸か」という異説と別の叙述である。後者の異説はどちらも必経由地にしていない。家康の6月16日大坂発・7月2日江戸着を長政の日程に転用していない。

## 位置と日程の精度

登録済みの `curated/places` の geometry は引き続き未確定とする。描画用には天満地区 `[135.52,34.70]`、伏見方面 `[135.781,34.938]`、清洲近村 `[136.839,35.217]` の代表点を別に保持し、`pointPrecision: regional-display-representative` と明記した。天満の屋敷敷地、伏見の出発門、清洲の城内持場を確定した座標ではない。大阪市の[天満地区の説明](https://www.city.osaka.lg.jp/toshiseibi/page/0000116291.html)は地区の背景説明であり、上記代表点を黒田屋敷跡と同定する資料ではない。

地点間は既存の `G.visualBetween` で街道へ接続する。伏見から宇都宮・小山を経て清洲までの参考線は4,330点、約1,105.918 km。これは戦国期の実測路や全宿泊地の復元ではない。無日付の経由地へ歴史上の日付を割り振らず、表示時計だけで補間する。

6月6日の婚儀から伏見出発までは毎日伏見へ歩いたと見せず、最後の所在観測点を表示し、次の観測日の直前を22 km/日基準の参考移動で接続する。この移動開始日も、天満での連続滞在も、新しい史実命題にはしない。最初の観測以前から続けて遊ぶ場合も、既存の人物移動で最初の代表点へつなぐ。帰還の新しい日付・行程は生成しない。

## 表示・保存・実軍への引継ぎ

- 所在記録は武将の顔と名前で描く。未知の兵数、士気、兵種を補わない。`marchGroupKey` を返さず、近景・遠景とも実軍の縦列に結合しない。UI後段の別方式による近傍統合・横ずらしは、同じ変更に含むM03修正で削除した。
- ツールチップと一覧では、日付付き観測・最後に確認した所在・途中の推定区間を分ける。
- 非史実の分岐フラグがある状態は、所在表示・事前接続・旧保存移行の全てで対象外とする。
- 旧保存では日内の表示位置を保持し、次の確認地点へ既存道路で接続する。移行情報だけを `personLocationDisplay` に追加し、`loc`・所属・兵数・領土・帰路を変更しない。移行区間は史実の所在とは表示しない。
- 8月14日着陣後は清洲近村の最後の観測点を表示し、10月19日に既存の関ヶ原黒田軍が生成されると、その軍へ表示を引き継ぐ。軍の起点は清洲のままで、直前の人物表示位置が `visualTravel` の始点になる。既存兵数を重複生成しない。合戦当日に軍が解散しても、古い清洲の所在表示を復活させない。

## 検査

`tools/checks/person-location-itinerary.cjs` は保存済みのs1600状態を引数に受け取る。シナリオ作成の5,485日を再計算せず、対象の85日だけ進める。CPU負荷を避けるためChromeは起動していない。

確認結果：3観測日の代表点一致、宇都宮→小山の無日付順序、日内停止・日境界の連続性、最初の観測日への接続、8月30日の管理ノード変更で所在が切り替わらないこと、清洲からの実軍引継ぎが通過した。対象区間の最大日次移動は26.378 km。旧保存の日内0.63の位置、既存の全状態フィールドと保存往復も保持した。Canvasの人物表示・画像未着フォールバック・一覧HTMLはブラウザを使わず実行検査し、兵数や士気の混入がないことを確認した。

この検査は1600年の当該所在接続の確認であり、全人物・全期間の歴史的精度や実画面の見栄えを証明するものではない。実画面では顔と所在説明を確認した。範囲と検証器の制約は[行軍・所在の受入記録](CONVOY_AND_LOCATION_ACCEPTANCE.md)を参照。
