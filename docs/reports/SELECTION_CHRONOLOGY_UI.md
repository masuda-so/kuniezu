# 勢力選択と年表の画面遷移

2026-11-07に共有された利用者の決定に従う。勢力を選ぶまでは左側で家を探し、確定後はその列に年表を表示する。「地形図／白地図」は外し、和紙・青海波・地形の陰影を維持する。

## 変更

- 広幅の選択パネルを右400pxから左288pxへ移し、カメラの有効領域も左320pxを除く形に合わせた。年表と同じ左列を使う。狭幅は地図を残した下側のパネルで選択する。拡縮バーは右端へ置く。
- 家のカードまたは地図の城から確定すると既存の初期化・保存・年表へ進む。開始ボタンと自動の三段階案内は除去し、操作説明はタイトルとメニューに残す。
- 地域変更とシナリオ表示は未確定のまま。確定処理は選択中の有効な家だけ受け付け、開始後の二重入力でゲームを作り直さない。
- 選択中の大きなプレビューと二重のスクロールを外し、地域・家のカードを優先する。
- 保存の読込・史実上の所属継承・滅亡時の既存処理は今回変更しない。独立前の家を追加選択可能にしない。プレイ中の選び直し導線も追加しない。
- 地形の切替UI・イベント・旧ブラウザ設定の読込を除去し、従来の既定の描画を使う。標高データや陰影自体は削除しない。

## 検査

`selection-ui-browser.cjs` は起動済み8000に専用Chromeを接続し、候補ファイルをブラウザ内で差し替えられる。全シナリオの広幅・狭幅の選択、地域絞込みだけでは開始しないこと、年表・初期速度・自動保存、二重入力、335px設定画面、手動保存の復元、地図上の城からの確定を確認する。旧白地図設定があっても陰影のある既定表示となることも確認する。

62本の既存ブラウザ検査は開始ボタン／自動案内への依存を新しい家カード操作へ更新。東北の全カード反復は各カードごとに独立した選択画面を準備する。北条・1600年の徳川を明示するケース、保存時計・遅延陰影・二回目のシナリオ開始は目的を維持する。62本すべての実画面試験を行ったという記録ではなく、構文検査と対象を絞った実画面確認を区別する。

実画面の結果は [確認記録](../../data/verification/codex-selection-ui-final/README.md) に残す。地図の史実精度、全UIの受入、滅亡後の選び直しの決定を意味しない。
