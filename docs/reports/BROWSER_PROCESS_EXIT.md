# 検証ブラウザ終了時の待機と後片付け

専用Chromeが起動時に終了しても、検査側がCDPの応答を待ち続ける問題を修正した。
子プロセスのerror/exitだけでなく、CDPパイプのerrorも待機中の要求へ伝え、
終了後の新しい要求を拒否する。既存のfinallyで一時profileを削除する。

`node tools/checks/browser-process-exit.cjs`は、実際のChromeを起動せず、
存在しない実行ファイルと早期終了するNodeを指定して失敗を検査する。
両方とも終了コード1、未処理のerrorイベントなし、新しいprofileの残存0を確認した。
今回の実測は52ms・55ms。これは検査プログラムの実行時間であり、
修正・調査・レビューの工数や、ゲームの起動速度ではない。

クラッシュレポートの機器・個人識別子はリポジトリへ転載しない。
この変更はChrome自体の起動時クラッシュの根本原因を直すものではなく、
検証失敗を明確に終了させるための修正。
