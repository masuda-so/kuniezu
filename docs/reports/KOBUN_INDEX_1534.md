# 綱文の所在目録を 1534 年分作る（2026-11-07、Claude）

利用者の決定（選択式の質問への回答）：全件の背骨に 1534〜1615 年の綱文を使う。史料編纂所には問い合わせない。試しに 1534 年分の所在目録を作る。史実 DB の今の範囲は 1534 年の初め〜元和元年の末（`docs/architecture/history-rdb.md`）。

## 作ったもの

- `data/research/kobun-index/1534.jsonl`：天文3年（1534 年）の綱文 478 条。1 行が 1 本条で、和暦の日付・条・区分・編・冊・頁・データベースの管理番号 `mgno`・日付の精度を持つ。綱文の文面は置かない。
- 史実 DB の取り込み（`kuniezu/history/importer.py`）：記録の種類 `kobun`（綱文の所在）を足し、各条を「未分類」の事象（`kobun-unclassified`）として入れる。移行 `0003_record_type_kobun.py`。試験 `tests/test_history_import.py`。

| 日付の精度 | 件数 |
|---|---:|
| 日 | 461 |
| 月（是月） | 11 |
| 季節（是春・是夏） | 3 |
| 年（是歳） | 3 |
| 合計 | 478 |

全て『史料綜覧』（編9・冊909、695〜720 頁）の条で、『大日本史料』の既刊分はこの年に無い。閏1月の条が 21 ある。

## 取り方と確かめ方

- 史料編纂所「大日本史料総合データベース」の検索を内蔵ブラウザで開き、同じページから和暦の範囲（天文3年1月1日〜12月30日）で引いた。是歳の条は 12月30日より後に並ぶので、12月29日〜天文4年1月1日の範囲でも引いて足した。取得は 6 回の要求（1 回 200 件）。
- 検索結果は同じ条を 2 回ずつ返すので、管理番号 `mgno` で重複を除いた（950 行 → 478 条）。
- シェルから同じ API を引くと 403（拒否）だった。ブラウザ以外からの自動取得を受け付けない設定とみて、回避はしていない。ブラウザで取った所在を書き出し、ブラウザ側と書き出した側の SHA-256 が一致することを確かめた。
- ゲームの暦表（`koyomi.js`）は 1553〜1622 年だけなので、1534 年の日付は西暦の日に直せない。DB では和暦の日付のまま持ち、範囲はその年と翌年に広げて端を主張しない。

## 規模の見込み

1534 年は 478 条だった。範囲の 82 年（1534〜1615）が同じ割合なら約 4 万条になるが、天正期は『大日本史料』の既刊分で条が細かく、年ごとの差は大きいと見込む（数えていない）。

## 限界

- 入っているのは所在だけで、どの条も未分類。読んで事象に分けるのは次の作業。
- 綱文は編纂者が選んだ出来事で、当時の全ての出来事ではない。「綱文に掲げられた出来事」の全件であって、歴史上の全件ではない。
- 綱文の日付は編纂上の掲出日。
