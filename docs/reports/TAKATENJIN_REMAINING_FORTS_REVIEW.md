# 高天神包囲4砦の年代・位置・担当照合

中村砦の開始年1580は掛川市年表の1579年と合わないため、1579年へ訂正した。能ヶ坂・火ヶ峰・獅子ヶ鼻は同年表の1580年と整合し、現行を維持する。月日を根拠なく設定しない。

|砦|採用する開始年|包囲期の担当|座標判断|
|---|---:|---|---|
|中村|1579|大須賀康高|現地案内代表点を維持|
|獅子ヶ鼻|1580|大須賀康高|現地案内代表点を維持。別の市マーカーとの96.33m差を測量誤差とみなさない|
|火ヶ峰|1580|大須賀康高|位置に二説。東砦の代表点を維持|
|能ヶ坂|1580|本多勢|現地案内代表点を維持。官途異同から個人を確定しない|

[掛川市の計画年表](https://www.city.kakegawa.shizuoka.jp/fs/1/7/6/4/6/9/_/10appendix.pdf)の資料編1（PDF3頁）を原図で確認した。担当は[加藤理文の講演資料](https://www.city.kakegawa.shizuoka.jp/fs/6/2/4/3/5/5/_/_____________________________.pdf)4頁を原図確認。築造・改修の年精度と、1581年落城後に包囲拠点として役目を終えることを分け、現行の表示終了1582を個別の廃城日とはしない。

稼働・所属はモデルを1575年から1580年まで連続進行して6砦が徳川方となることを確認した。4砦とも高天神城を攻める側の陣城で、武田方の支城ではない。

資料と採否は[data/inputs/takatenjin-remaining-forts/README.md](../../data/inputs/takatenjin-remaining-forts/README.md)、機械可読の変更案は同フォルダreview.json。調査担当の成果を親担当が `game/site-coordinates.js` と出典・命題台帳へ統合した。6砦の整備年を一命題として保存し、月日を付け足していない。

統合後の実画面確認：UIから1575年シナリオを開始し1578/1579/1580年10月1日へ連続進行。中村砦の稼働はfalse/true/true、1579年の所属は徳川。1580年の詳細画面で1579年整備・役割・出典を確認。結果と画像は `data/verification/siege-placement-batch/`。
