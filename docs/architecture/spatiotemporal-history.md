# 人物・場所・年代の参照台帳

史実の調査成果を、現在のゲーム状態から独立して保存する。史実観察の検証にも、将来の非史実ルートの参照にも同じ資料を使えるようにする。非史実ルート自体は保留のまま。

## 初期実装

- 人物：`data/research/curated/people/`。固定ID、表示名、ゲーム内名、将来の典拠IDを保持。セーブごとに変わる `g.id` を史料の人物IDにしない。
- 場所：`curated/places/`。固定IDと名称を保持。城の改称や、同じゲーム拠点IDの移転と、物理的な場所の同一性を分ける。精密座標は照合なしに登録しない。
- 所在・居所・役職：`curated/locations/`。一記録一ファイル。人物ID、場所ID、関係、年代の精度、出典、該当箇所、確認日、不確かさ、実装対応を保持する。
- 再出力：`node tools/research/export-evidence.cjs`。`people.jsonl`、`places.jsonl`、`location-observations.jsonl` を生成する。別担当者の入力を消さない。

初期登録は武田勝頼、毛利輝元、松平家忠の3名・7件。全436人物の所在台帳が完成したという意味ではない。

## 時間と関係の区別

| 記録 | 表すもの | 表さないもの |
| --- | --- | --- |
| 年の記録 | その年に起きた移転・就任 | 年初から年末までの連続滞在 |
| 旧暦日の記録 | 出典が記すその日の出来事。閏月も区別 | 前後の日の所在 |
| 本拠の年代区間 | その時期の基準となる本拠 | 本人が毎日在城していたこと |
| 城主就任 | 城との職務・支配関係 | 本人の現地滞在の証明 |

年代区間は終了年を含まない形にし、移転年へ旧本拠の情報が自動で伸びないようにする。年精度の記録を1月1日の確定イベントへ変換しない。日付は暦を明示し、西暦のユリウス暦・グレゴリオ暦と旧暦を混在させない。

`recordedAt` は台帳へ確認・記録した日。歴史上の日時とは別。異説は別IDで保持し、単に新しい記事だから正しいと決めない。既存の確認済み命題・資料台帳は引き続き併用する。

台帳の日時は原史料の暦・精度で保持し、ゲームの進行用の日数へ置き換えて保存しない。現在のゲーム内部の30日月による進行値や、1582年以前の西暦換算方式は別の検証対象とする。たとえばユリウス暦7月6日とグレゴリオ暦7月16日が同じ日を指す場合に、10日違う事件として重複登録しない。

## 検索

```sh
node tools/research/query-locations.cjs 武田勝頼 1573
node tools/research/query-locations.cjs 松平家忠 --lunar 1592-2-19
node tools/research/query-locations.cjs 松平家忠 --lunar 1592-2-19 --leap
```

初期データでは、勝頼の1573年は躑躅ヶ崎館への入館記録を返すが、任意の一日にいたと断定しない。家忠の上代への移転は旧暦1592年2月19日の記録として検索できる。1593年の所在は補完せず、該当記録なしと返す。城主・本拠を検索しても `exactPresenceConfirmed` を真にしない。

検査：`node tools/checks/location-store.cjs`。出典不一致、人物・場所の未登録、ID重複、日付・区間の不正、未照合座標の混入を拒否する。年精度と日精度、閏月、空白年の扱いを検査する。

## ゲームへの適用

史実参照台帳を毎フレームの位置表にはしない。記録された出発・到着や入城を参照点として使い、途中の行軍は別の推定経路で補う。経路には元の記録ID・出典ID・推定の区分を保持する。現代道の比較線やゲーム上の速度係数を、新たな史実の根拠へ昇格させない。

まずは家督継承・移封・改称で誤った居所を引き継いでいないかを、この台帳と突き合わせる。実行時の人物位置をそのまま史実台帳へ逆流させない。

## 将来の分岐履歴の設計（機能は未再開）

史実側を `reference`、各プレイの世界を個別の `runId` として分ける。分岐後の記録には、人物・場所の固定ID、ゲーム内日時、行動、原因となった命令・イベント、経路ID、参照した史料IDを保存する。史実の記録は参照用として残し、分岐後の人物を史実の居所へ強制的に戻す根拠にはしない。

毎フレーム全人物を保存するとデータ量と保存負荷が増えるため、行動・所属・居所の変更点と経路を蓄積し、途中位置を再計算する方式を基本案とする。AIが提案した行動と、実際にゲームが採用した結果も分ける。

AIへ渡す情報は、その世界の現在の所在地・同盟・兵站と、出典付きの人物来歴・行動例を組み合わせる。史実の性格や過去の関係を参考にしても、AIの生成した出来事を史実確認済みとして保存しない。この実行履歴の保存・AI連携は今後の実装であり、今回追加したのは史実参照台帳と検索・検査まで。
