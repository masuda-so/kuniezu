# CODH江戸期地理データを用いるベクター地図への移行

## 利用者の決定（2026-11-07）

江戸期地理データセットの海岸線／水域・湖沼・主要街道・宿場を大いに利用し、ベクターでの実装を目指す。従来のラスター維持方針より、この指示を優先する。現在動いているラスター表示を移行完了前に削除しない。この文書は方針と受入条件であり、移行完了の報告ではない。

データセットのライセンスと、CODHサイト本文のライセンスを混同しない。海岸線の同一URL上書き更新もあるため、URLだけで版を識別せず取得日時・SHA-256・公式版表示を保存する。湖沼データセットだけで全国の全湖沼が揃うとは扱わない。

## 入力・年代・描画の分離

1. 公式原本は改変せず取得URL・版・SHA・ライセンスと保持し、人が読む資料ノートをMarkdownで別に置く。
2. 座標系を原本で確認してから共通の経緯度へ変換する。描画ピクセルや現在の画像範囲をDBの位置の正本にしない。
3. 海岸・水域・湖沼・街道・宿場を別の地物として管理し、CODHのID・形状・属性との対応を残す。近くの城へ自動接続しない。
4. 江戸期の基準形状と、1560〜1615年の史料付き補正を別層にする。関東の利根川改修、香取海・椿海・児島湾などを重点比較し、江戸の宿場成立や改修後の街道を戦国期へ自動転用しない。
5. 補正は対象ID・根拠・適用年代・不確実性・形状の版を参照し、時空間DBから年月／地物の両方向へ引く。年ごとの全形状複製は作らない。
6. 領主の支配域・国郡境・城施設・部隊・名札は地形と別に描画する。街道の表示形状と行軍経路を同じ採用データへ接続する。
7. ベクター描画では海岸・川・街道の線幅とラベルを画面縮尺に応じて制御する。標高の陰影は用途が異なり、ベクター化のために削除しない。標高資料を戦国期の実測地形とは扱わない。

## 段階と完了証拠

描画プログラムは、形状の改変を済ませたファイルを読む。CODH原本を読んでから局所的に座標を直す、線を消す、干拓面を合成する処理をゲーム実行時に置かない。年代で形が違う場合も、該当時点の改変済みデータを選んで読む。原本は照合用に保持する。

編集の正本は**改変済みGeoJSONを直接編集する方式**とする（利用者確認、2026-11-07）。正本は `kuniezu/map/` の地理層でGit管理し、CODH原本は照合用に別保存する。通常の配信ビルドは正本の形状を変えずに配信物を作り、原本＋補正定義で正本を上書きしない。準備器は初回移行・検証の補助であり、描画側へ補正の知識を持ち込まない。年代差は形が変わる時点の改変済みデータと適用期間で保持し、年ごとの全件複製は作らない。

- 取得：4データセットの原本、配布版、座標系、属性、利用条件、SHAを記録。
- 小規模試作：関東と児島湾で、形状・穴・複数島・水域と陸の関係・街道接続を現行地図と同縮尺で比較。
- 歴史補正：既存の出典付き補正を入力として移植し、根拠のない自動的な戦国期化を行わない。
- 描画接続：経緯度から画面への変換を城・部隊・ヒット判定と統一。連続ズーム・パン・回転・停止・保存でずれないことを実画面で確認。
- 性能：表示範囲と縮尺に必要な地物だけ扱い、現行版とのメモリ・操作遅延・停止時負荷を比較。ベクターだから常に軽いとは仮定しない。
- 切替：旧表示との位置・年切替・保存互換・出典表示の検証後に既定を切り替え、呼出しがなくなった旧処理だけ整理する。

MapLibre・GeoJSON・ベクタータイルの使い分けや正本の具体的なフォルダは、原本の規模と座標系を確認して決める。現行の配信URLや保存形式を準備なしで変更しない。朝鮮半島を戦略地図へ戻す方針ではない。現在のPR #62は移行までの現行表示の読込通知を修正するもので、移行の完了とは別に扱う。

現時点で4データセット6表現を取得し、公式SHPは開発時だけのPyShpで変換できる。公開マップの線版と公式ポリゴンの全幾何同一性は未確認であり、塗りと岸線は同じ採用面から派生させる。

面の合成に必要な位相処理は [codh_topology.py](../../tools/geo/codh_topology.py) で検証する。有効だった面は変えず、無効な面はlinework方式で派生化し、残差と原本座標位置を保持する。Shapelyは開発時だけで、ゲームに持ち込まない。[検証範囲](../reports/codh-topology.md)と、戦国期の地理的採否を区別する。

共通の面描画と位置判定は `kuniezu/static/kuniezu/vector-map.js` に実装し、まず独立比較画面へ接続する。既存の経緯度投影を受け取り、穴・適用期間・表示範囲を同じデータで扱う。`codh_preview.py --canonical <ディレクトリ>` は編集済みland/waterをそのまま読む。現行ゲーム本体への既定切替や歴史補正全件の移植を、この接続だけで完了扱いにしない。
