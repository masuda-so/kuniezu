# 文書の入口

- [現在の引き継ぎ](../HANDOFF.md)：作業前に読む。
- [残要望と分担](work/README.md)：完了条件、担当の取り方、現在の作業一覧。
- [構成と依存順](architecture/README.md)：どのファイルを編集・生成するか。
- [最新の調査・修正報告](reports/HISTORICAL_RECHECK.md)：古湖岸・人物・合戦の再検査。
- [行軍・駒・読込の報告](reports/MARCH_CLOCK_REVIEW.md)。
- [史料台帳の扱い](../data/research/README.md)。
- [検証手順](../tools/checks/README.md)。

`reports/` は各時点の作業記録です。後の変更で数値・方針が更新されている場合があるため、現行仕様は HANDOFF と work の合意事項を優先します。`history/` は過去の原文を保存しています。
