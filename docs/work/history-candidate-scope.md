# 1534〜1615年の対象候補の収集範囲

2026-11-09の利用者指示に基づく。人物一覧だけでなく、Wikipediaの
「Category:戦国武将」「Category:戦国大名」なども発見の入口に使う。
一覧・カテゴリの収録だけでは、人物の同定、年代、事実、網羅性の証明にはしない。

## 収集と登場の区別

- **候補**：記事・カテゴリ・史料などから発見した対象。期間との関係が未確認でも、
  未判定として保持し、確認済み対象数には含めない。
- **確認した対象と史実**：同定・別名・対象種別・時期・個々の命題を出典へ結び付ける。
  同じ名前だけで統合せず、異名の記事を別人として二重計上しない。
- **ゲームへの登場**：史実DBへの登録とは別に判断する。関連性は未判定を初期値とし、
  未調査を「関係なし」へ読み替えない。

武将・大名に限定しない。農民、商人、僧侶、女性なども身分・性別で一律に除外しない。
実名や事件との関係が出典で確認できる個人は候補に含める。一方、匿名の住民・農民は、
確認できる集団や事件として扱い、人数分の架空人物を作らない。
ゲームへの影響が小さい個人も、登録と画面への登場を分けて判断する。

城・施設・街道・水域・領域・家や集団・事件などの非人物も対象とする。
カテゴリに含まれる作品や後世の研究資料は、当時の施設・人物と混同しない。
既存の対象種別で表せないものを誤った型へ押し込まず、必要な型を検討する。

## 出典と未確認範囲

候補には発見元、ページ識別子、別名・転送先、収集経路、取得日時を残す。
Wikidata識別子がある場合も、同一性や各命題の正しさを自動で保証するものとしない。
詳細な史実は、その根拠となる史料・公的機関等の該当箇所と照合する。

### 国立国会図書館の調査案内

[リサーチ・ナビ「戦国大名・戦国武将を調べる」](https://ndlsearch.ndl.go.jp/rnavi/humanities/sengoku)
（人文総合情報室作成、2026-04-22更新、2026-11-10確認）を資料探索の入口に使う。
人物全般、家系、地域、合戦、特定の家という切り口から、紹介された事典・索引へ進む。
同ページの紹介は書誌と調べ方の根拠であり、未読の書籍本文を確認済みにしない。

別名を含めて検索する。同名異人や通称の継承も確認し、検索語の一致だけで同定しない。
紹介された各資料は対象年代・地域が異なるため、1534〜1615年の全国を一冊で
網羅すると扱わない。利用可能な本文を読めた場合に、版・頁・該当箇所とともに
個々の命題へ結び付ける。書誌のみ確認、本文未読、本文照合済みを分けて保持する。

探索の深さ・取得件数・通信失敗などで走査を止めた場合は、未走査先を保持する。
取得した件数、未走査件数、同定・年代・関連性の未判定件数を分けて報告する。
Wikipediaの一覧やカテゴリを読み終えたことを、歴史上の全対象の収集完了とはしない。

同じ事実を年別に複製せず、変化の発生時点や根拠のある継続期間を記録し、
対象別と年代別の両方向から参照する。候補の対象期間を、本人の生存期間や
施設の存在期間として転記しない。

この文書は収集・採否の基準であり、候補収集器やDBへの反映の完了報告ではない。
