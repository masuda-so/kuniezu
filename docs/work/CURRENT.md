## 現在有効な方針

- 戦略地図の対象は日本。朝鮮半島・明・満州・沿海州への拡張は行わない。朝鮮関連の史実・個別合戦図・年表を保持することと、戦略地図の再実装は区別する。[移行方針](../architecture/replatform-plan.md)、[CODH受入条件](../architecture/codh-vector-map.md)
- 地理の編集正本は`kuniezu/map/`の改変済みGeoJSON。CODHの江戸期原本と戦国期の採用・補正を区別し、通常ビルドでは編集正本を上書きしない。描画側は年代に対応する編集済みデータを無改変で読む。旧画像正本の恒久維持やCK3形式との一致を移行制約にしない。標高・陰影や既採用の古湖岸を削除する指示ではない。
- 作業配分の前に必要に応じて `codexbar usage --provider both --format json --no-credits` で使用率・リセット時刻を確認する。アカウント識別情報や認証情報は報告へ転載せず、無料リセットは利用者の判断に残す。
- 利用者が許可したローカルポートだけを操作する。本担当の検証は8000番で行う。127.0.0.1限定で待受プロセス・作業ツリー・担当を確認し、その他のポートや外部公開へ広げない。検証は専用一時ブラウザを使う。[AGENTS](../../AGENTS.md)、[HANDOFF](../../HANDOFF.md)
- 史実観察を継続し、自由攻城・非史実ルート・プレイ中AI生成は保留。外交は国境のみ。同じ行軍だけ遠景で代表隊、近景で街道上に個別表示し、別の場所へ見える横ずらしはしない。
- 史実の着陣日は推定負荷で遅らせない。史実DBは変更・観測・有効期間を一度保持し、年月と対象から参照する。日別・年別の全状態を複製せず、未記録の所在を創作しない。[時空間参照](../architecture/spatiotemporal-history.md)、[RDB](../architecture/history-rdb.md)
