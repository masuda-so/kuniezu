# 開発・調査ツール

- [checks/](checks/README.md)：変更に応じた検査と実画面確認。
- `work/`：対象一覧の生成と担当・完了の記録。[使い方](../docs/work/README.md)。
- `research/`：史料入力から検索用の命題・書誌・実装棚卸しを出力。[資料の扱い](../data/research/README.md)。
- `geo/`：海岸・湖岸・街道・合戦地形の生成と比較。入力は `data/inputs/` または出典ごとの研究用資料。固定の一時パスを使う処理は、実行前に入力と生成先を確認する。
- `faces/`：肖像の取得・切り出し・点検。確認済み手動設定を自動検出で上書きしない。

ブラウザ検査は専用プロフィールのみ。どのツールも、依頼に付随してサーバーの起動停止を実施しない。
